# 人生就是一场康波——康波周期到底是什么？

> **免责声明**：我以周期天王周金涛的视角和你聊。以下内容基于公开演讲与著作的推断，是思维框架的推演，不代表本人观点。

---

我本来是个研究周期的，半退休的人，这两年被人到处请去讲康波。讲得多了，大家就叫我"周期天王"，也有人叫我"尼古拉斯·金涛"。今天我把康波这件事，从头到尾说清楚。

我有一句名言，叫**"人生发财靠康波"**。什么意思？就是说，我们每个人的财富积累，一定不要以为是你多有本事——**财富积累完全来源于经济周期运动的时间给你的机会。** 这句话听着扎心，但你先别急着反驳，听我把康波讲完。

---

## 一、康波是什么？——一个苏联人发现的长波

康波，全称叫**康德拉季耶夫周期**，是苏联经济学家尼古拉·康德拉季耶夫在1920年代研究英美等国两百年的经济数据时，发现的一个规律：

**资本主义经济存在一种大约60年一轮的长周期波动。**

他当时收集了英国、法国、美国的物价、利率、工资、产量等数据，发现这些指标在长达一百多年的时间里，呈现出清晰的、约50-60年一个循环的波动。1926年他发表了这个发现，后世就以他的名字命名——**康德拉季耶夫长波，简称康波。**

为什么要强调"长"？因为除了康波，经济里还有更短的周期。康波是**最长、最底层的那个周期**，它像地球绕太阳的公转，其他的周期都嵌套在它里面。

这里我要说一句实话：康波理论到目前为止，**仍然是一个统计规律，没有严密的理论体系。** 这句话我在南开大学讲座上说过，今天再说一遍——我不装神弄鬼，康波是从历史数据里看出来的规律，不是写在物理定律里的必然。

---

## 二、康波怎么分？——四阶段：回升、繁荣、衰退、萧条

康波一轮大约60年，内部可以分成四个阶段：

| 阶段 | 大约时长 | 特征 |
|------|---------|------|
| **回升期** | 约15年 | 新技术出现、新产业萌芽、经济开始复苏 |
| **繁荣期** | 约15年 | 新产业全面扩张、经济高增长、资产价格上涨 |
| **衰退期** | 约15年 | 增长见顶回落、产能过剩、债务累积、资产价格高位震荡 |
| **萧条期** | 约15年 | 泡沫破裂、债务出清、经济深度调整、资产价格见底 |

**注意，康波的四阶段，核心驱动力是"技术革命"。**

每一次康波，都是由一次划时代的技术革命点燃的：

| 康波 | 技术革命 | 标志 |
|------|---------|------|
| 第一次康波 | 蒸汽机 | 纺织业、蒸汽动力 |
| 第二次康波 | 铁路+钢铁 | 铁路大建设 |
| 第三次康波 | 电气+化学 | 电力、汽车、化工 |
| 第四次康波 | 石油+汽车+电子 | 福特式生产、石化 |
| 第五次康波 | 信息技术 | 互联网、信息技术革命 |

我们现在，就处在**第五次康波**里——信息技术革命这波康波。

**一句话记住康波**：一次技术革命，点燃一波约60年的经济长波；技术革命是康波的"发动机"，60年是它的"排量"。

## 三、康波60年 = 3个房地产周期 = 6个中周期 = 18个库存周期

这是康波最精彩的地方——**周期是嵌套的。**

我反复讲一个公式：**60年康波，套着3个房地产周期（约20年一个），一个房地产周期套着2个固定资产投资周期（约10年一个，也叫朱格拉中周期），一个中周期套着3个库存周期（约3-4年一个，也叫基钦周期）。**

也就是说：

**60年康波 = 3个房地产周期 = 6个中周期 = 18个库存周期**

为什么要记这个嵌套关系？因为**大周期制约次一级周期的表现**。什么意思？

- 库存周期（3-4年）是"小时针"——它决定每三四年一次的经济小反弹和小回落。
- 中周期（10年）是"分针"——它决定每十年一次的投资大周期。
- 房地产周期（20年）是"时针"——它决定每二十年一次的资产大周期。
- 康波（60年）是"年月日"——它决定你这一辈子的财富机会在哪里。

**当多个周期同向共振的时候，行情会被剧烈放大；当它们一起向下的时候，就是所谓的"万劫不复之年"。** 2018-2019年我说是"四周期共振低点"——康波萧条、房地产下行、中周期下行、库存周期下行叠加在一起，那个位置的杀伤力是最大的。

反过来理解：**你现在看到的每一次涨跌，都不是孤立的，它是几个周期嵌套的合力。**

## 四、我们处在康波的哪个阶段？

这是所有人最关心的问题，我直接给定位。

第五次康波，以信息技术革命为引擎。**信息技术革命1970年代萌芽（硅谷、英特尔、PC），1980-1990年代进入繁荣，2000年前后互联网泡沫达到繁荣顶点，2008年次贷危机标志着第五次康波的衰退中段，2015-2019年前后进入衰退末段、向萧条转换。**

我的框架给出的坐标是：**我们现在处于第五次康波从"衰退"向"萧条"转换的阶段。**

这个阶段意味着什么？

1. **技术的"红利期"接近尾声**——信息技术革命的边际红利在递减，新的、能撑起下一波60年康波的技术革命还在孕育中（当时我判断是"技术真空期"，这一点后来被AI革命打了脸，我认）。
2. **资产价格的狂欢是"回光返照"**——康波衰退期到萧条期之间，往往会出现资产价格的最后一波狂欢，那是泡沫的顶点，不是新周期的起点。
3. **现金为王**——萧条期最正确的姿势，是保住流动性，等资产跌出价值。

**但这里我必须划一条诚实边界**：我做周期定位，也判错过。2019年我让听众"2019年回来买便宜资产"，结果2019年A股直接大涨，方向反了；"2017年中国地产B浪反弹结束"的判断，被棚改货币化拉长了四年。**周期的时间刻度，会被政策和技术革命扰动。** 所以定位给你，时间表你也要自己留个心眼。

## 五、人生发财靠康波——为什么说人生就是一场康波？

这是我最常被问的问题，也是这套理论最"宿命"的部分。

**康波一轮60年，恰好约等于人的自然寿命60年（60甲子）。** 所以你可以把人生和康波对齐来看：

- 你出生在康波的哪个阶段，决定了你这一辈子的财富"气候"。
- 你的一生，会遇到**一次康波、三次房地产周期、六次中周期、十八次库存周期**。
- 而**真正能改变你财富阶层的机会，一生只有三次**——分别对应三次房地产周期的低点，也就是三次"买入便宜资产"的窗口。

举个例子：**巴菲特为什么能成功？** 不是因为巴菲特比你多有本事——**他恰好出生在第五次康波的回升阶段**，他这一辈子赶上的是信息技术革命这波康波最肥沃的上升期。天时给了他机会。

我常说，**煤老板肯定不如我有本事，但天时给了他机会**——他赶上的是资源品的大牛市。这就是康波：**财富不看你多努力，看你出生在周期的哪个位置、抓没抓住属于你的那几次窗口。**

（如果你想算自己的"康波机会日历"：我公开说过的锚点是，40岁以上那代人，第一次机会在2008年，第二次在2019年，最后一次在2030年附近。这三次是那代人的日历——你自己的日历，得按你的出生年份在康波坐标系里推，这个是我按框架推的，不是我的原话。）

## 六、康波与资产：不同阶段，配不同资产

康波不只是用来"算命"的，它直接指导资产配置。**每一个康波阶段，都有它最有利的资产：**

| 康波阶段 | 最有利的资产 |
|---------|------------|
| 回升期 | 股票（新兴产业）、实物资产 |
| 繁荣期 | 股票、大宗商品（需求旺盛） |
| 衰退期 | 现金、债券、黄金（避险） |
| 萧条期 | **现金为王**、黄金、便宜的实物资产（抄底） |

为什么萧条期现金为王？因为萧条期的特征是**货币消灭机制**——资产价格下跌、债务出清、流动性收缩。手里有现金，你就能在别人恐慌的时候，去接那些"便宜到离谱"的资产。

我还给过一个具体的"操作日历"：**2016年、2017年卖掉投资性房地产和新三板股权，买进黄金，休假两年，锻炼身体，2019年回来。** 这就是康波阶段的资产映射落到个人操作——衰退末段卖资产、留现金、持黄金，等萧条低点再进场。

当然，前面说了，具体年份我判错过——**方向（萧条期现金为王）我坚持，时点（2019年低点）我认错。**

## 七、宿命与反抗

讲到最后，我要说康波最"玄"也最"实"的一层。

我2016年有个演讲，标题就叫《宿命与反抗》。我说过一句话：

**"顺周期而行，虽然是宿命，那也是应有之意。逆周期而动，必然遭遇反抗，而且会反抗的更坚定。"**

这句话怎么理解？

- **宿命**：康波的大方向、大级别趋势，是宿命——人力改变不了。60年一个轮回，萧条必然来，谁也躲不过。
- **反抗**：但在宿命的框架内，你可以择时——库存周期级别的小反弹、资产价格跌出来的价值机会，就是"反抗"的窗口。抓住它们，是框架内的"逆势"。

所以康波不是让你躺平认命。**它是告诉你：大方向不可违，但小级别可以择时；趋势是宿命，买卖是自己的。** 我的本意从来不是"认命躺平"，而是"认识规律、顺势而为"——虽然这个度很难拿捏，批评者说得也有道理：能动性在我的框架里，确实被压缩得很小。

## 八、最后的实话

我讲了这么多，最后必须给你几句掏心窝的实话：

1. **康波是统计规律，不是铁律。** 六十年的周期，在人类历史上只完整走过四五个来回，样本太小，谁也说不准这次是不是不一样。
2. **我判错过，而且判错得不少。** 2019年房价低点落空、2017年地产见顶被棚改拉长四年、AI革命打破了我的"技术真空期"假设。**引用我的时候，请同时引用哪些对了、哪些错了，别神化我。**
3. **我的框架有三个盲区：** 低估政策对周期时间刻度的扰动、低估技术革命改变周期路径的能力、框架太大导致任何事都能被装进去解释。
4. **我不是预言家，是个用周期框架思考的分析师。** 我擅长给你周期定位和大类资产方向，不擅长个股买卖点和短线择时——那些你得交给专业的人。

**说白了**：康波是一套"把60年经济史折叠进你一生"的观察框架。它最值钱的不是预测某年某月涨跌，而是给了你一个坐标系——**知道自己在周期的哪个位置，知道哪些机会一生只有三次，知道该进攻还是该保命。** 看懂康波，你看世界的眼光会多一个维度：任何新闻、任何涨跌、任何焦虑，你都会先问一句——**这是周期的哪个阶段在说话？**

周期即人性，人生无非也就是一次康波。**顺周期而行，是应有之意；逆周期而动，必然遭遇反抗。** 至于你选择顺还是逆，那是你的宿命，也是你的自由。
