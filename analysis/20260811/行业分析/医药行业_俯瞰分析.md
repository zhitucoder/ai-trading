## 二、医药产业链：钱从哪来，利润停在哪一段

看懂医药，先看懂它的价值链。医药是一个**“研发→生产→流通→终端支付”的四级链条**，每一段赚的钱完全不同：

```
 上游（卖水人）          中游（制造者）          下游（流通与终端）        支付端（钱从哪来）
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐   ┌──────────────┐
│ 原料药/中间体     │   │ 化学制药(创新+仿) │   │ 医药商业/批发     │   │ 基本医保       │
│ 药用辅料/包材     │→  │ 生物制药(疫苗/血 │→  │ 零售药房         │→  │ 商业健康险     │
│ 科研试剂/耗材     │   │ 制品/单抗/胰岛素)│   │ 医疗服务(医院/    │   │ 患者自费       │
│ CXO(CRO/CDMO)   │   │ 中药            │   │ 眼科/体检/ICL)   │   │ 出海(BD/海外销售)│
└─────────────────┘   │ 医疗器械(设备/   │   └─────────────────┘   └──────────────┘
                      │  耗材/IVD)      │
                      └─────────────────┘
```

### 2.1 每一段赚的是什么钱

| 链条位置 | 代表公司 | 赚什么钱 | 盈利特征 | 风险 |
|---------|---------|---------|---------|------|
| **原料药/中间体** | 新和成、华海、普洛 | 制造加工费 | 低毛利(30-45%)、周期性强 | 价格战、产能过剩 |
| **CXO(卖水人)** | 药明康德、康龙、凯莱英、泰格、昭衍 | 研发/生产外包服务费 | 中毛利(35-50%)、订单驱动、**旱涝保收** | 全球投融资景气度 |
| **科研试剂/耗材** | 纳微科技、奥浦迈 | 高毛利耗材 | 高毛利(60%+) | 国产替代进度 |
| **创新药(品牌)** | 恒瑞、百济、百利天恒 | 专利垄断+品牌 | 高毛利(70-90%)、**研发风险最高** | 临床失败、专利悬崖 |
| **仿制药** | 科伦、人福、石药 | 规模化生产 | 中低毛利，**集采杀价** | 集采出局 |
| **疫苗/血制品** | 智飞、天坛、华兰 | 牌照+大单品 | 高毛利但需求波动大 | 需求崩塌、价格战 |
| **中药** | 白药、片仔癀、同仁堂 | 品牌+消费属性 | 中高毛利、防御性强 | 集采扩围 |
| **医疗器械** | 迈瑞、联影、新产业 | 技术+渠道 | 高毛利(50-65%) | 集采、招标放缓 |
| **医药流通** | 上海医药、九州通 | 配送规模差价 | 低毛利(净利率1-3%)、**以量取胜** | 应收/垫资风险 |
| **零售药房** | 大参林、益丰 | 终端零售差价 | 低毛利、连锁规模效应 | 医保控费、比价平台 |
| **医疗服务** | 爱尔、美年、通策 | 服务费 | 中毛利(40-50%) | 医保支付改革、监管 |

### 2.2 钱怎么分：三句话看懂医药产业链利润分配

1. **越靠研发，越靠品牌，利润越高、风险越大**——创新药研发失败率超90%，所以一旦成功，市场给它70-90%的毛利率作为“风险补偿”（恒瑞毛利率86%、百济87.6%）；而流通、零售没有研发风险，所以只能赚1-3%的辛苦钱。

2. **CXO是“卖水人”：别人淘金它卖铲子**——无论哪家药企研发成功或失败，做研发外包的CXO都能赚到服务费。创新药越火，CXO订单越多（2026H1药明康德在手订单+23.6%），且不承担新药失败风险，是产业链里**确定性最高的环节**。

3. **支付端决定利润天花板**——中国80%+的药品销售靠医保支付，所以**医保是医药产业最大的“甲方”**：集采把仿制药利润打掉、把空间腾给创新药；商保目录、自费（医美/减重/消费医疗）则是不受医保控费的“第二支付池”。**看懂医保政策，就看清了钱在产业链里往哪流**。

### 2.3 产业链视角下的投资启示

- 想赚**确定性** → 找“卖水人”（CXO、科研试剂）和“躺赚”环节（流通、流通龙头）
- 想赚**爆发力** → 找创新药（高研发风险换高弹性，赌单品放量或BD兑现）
- 想赚**稳定性** → 找品牌中药、消费医疗（受集采影响小）
- 想避开**陷阱** → 回避纯仿制药（集采出清中）、需求崩塌的疫苗、价格战的血制品

## 四、医药行业周期：从“医保控费周期”切换到“创新兑现周期”

### 4.1 过去的十年：政策主导的“三杀/三涨”循环

```
2015-2017 鼓励创新、放开定价 → 创新药估值牛市
2018-2019 首批4+7集采 → 仿制药逻辑崩塌，估值暴跌
2020-2021 疫情+器械放量 → 一轮脉冲行情（高点3041）
2022-2024 集采常态化+反腐+医保控费 → 连续三年阴跌（低点1887）
2025至今 集采利空钝化 + 创新药BD出海爆发 → 结构性牛市（创新药/器械/中药分化）
```

**医药的周期本质是“医保支付政策周期”**：集采把仿制药利润打掉，同时把资源腾出来给创新药。当集采利空出尽、创新药开始兑现利润时，新一轮上行就启动了。

### 4.2 当前位置：估值历史低位，盈利拐点已至

- **板块估值**：SW医药生物PE(TTM)约44.5倍，相对沪深300约3.2倍，处于近几年中位水平；中证创新药指数PE约48倍、PB约4.1倍

- **政策底**：生物医药正式升级为**国家新兴支柱产业**；国办9号文理顺药价形成机制，对高水平创新药放开上市定价；2026版基药目录首次纳入16种创新药

## 五、医药行业的六大结构性趋势

### 趋势1：创新药出海（License-out）是当下最大主升浪

- **2026H1中国创新药License-out交易总额约997亿美元**，是2024全年（522亿）的近2倍，接近2025全年（1,357亿）的73%；上半年123笔交易，全球医药交易TOP10中国独占8席
- 交易模式从“卖青苗”升级为“共同开发+利润共享”（Co-Co）、NewCo——中国药企从“供应商”变“合作方”，议价能力实质增强
- 代表交易：恒瑞-BMS 152亿美元（13款早期项目）、信达-辉瑞 105亿美元、海思科-礼来 30.5亿美元、石药-阿斯利康 185亿美元ADC
- **验证指标**：药明康德Q1在手订单同比+23.6%；CXO中报全面预喜（昭衍+885%至1377%、康龙+17%至22%、美迪西扭亏）
- ⚠️ **警惕**：BD总金额≠到账收入，市场已开始用“首付款含金量、买方实力、临床扎实度”筛选，纯讲故事的公司会被抛弃

### 趋势2：全球生物医药投融资回暖，CXO进入新一轮景气

- 2026H1全球创新药一级市场投融资267.5亿美元（+58.5%），国内58.1亿美元（+79.1%）
- 美国Biotech IPO融资45亿美元，是2025同期的5倍；XBI指数涨约20%
- 融资回暖→研发投入增加→CXO订单增厚：**CXO是创新药的“卖水人”，创新药越火，CXO越赚**

### 趋势3：医保支付体系重构——“商保创新药目录”打开第二支付空间

- 2026年医保目录调整引入**预申报机制**，基本医保+商保创新药双目录并行，11月下旬发布
- 2026版基药目录从685种扩至794种，首次纳入16种创新药，为创新药下沉基层打开空间
- 医保省级统筹加速落地，未来2-3年医保支出增速有望企稳回升
- 行业判断：**DRG/DIP控费+商保增量并存，“保基本”压仿制药、“促创新”提创新药**

### 趋势4：GLP-1（减肥药/降糖药）大单品景气延续

- 礼来业绩高增核心驱动即GLP-1减重产品，后续还有orforglipron、retatrutide等重磅管线
- 国内映射：信达、翰森、联邦制药、博瑞医药、歌礼制药等GLP-1/减重管线布局
- 产业链：多肽CDMO/原料药高景气（翰宇药业、昊帆生物、诺泰生物等），带动上游试剂填料（纳微科技核心业务+50%）

### 趋势5：医疗合规重塑行业生态，“真创新”才活得下去

- 2026年5月起医药反腐配套、医药代表管理新规落地，商业贿赂入罪门槛下调
- 结果：从商业到工业，药品/器械/诊断竞争格局大洗牌，**无临床价值的“me-too”药、带金销售的中小药企加速出清，具备真实临床价值的药械占据主位**
- 中药同样分化：中成药集采扩围（昆药预亏3-4亿），但有循证医学、创新能力的龙头反而受益

### 趋势6：医疗器械缓慢复苏，国产替代+出海双主线

- 2025年报+2026Q1：医疗设备、耗材相对稳健，**IVD短期仍承压**（2025年55家IVD企业44家营收下滑、全行业亏损超60亿）；海外业务普遍好于国内
- 腔镜手术机器人国产替代进入渗透早期，国内招标已反超进口
- 国产替代（影像联影、内镜开立）+出海（迈瑞、新产业）是器械两条确定性主线
