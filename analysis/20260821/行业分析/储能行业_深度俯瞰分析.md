## 八、行业风险：五只黑天鹅

1. **价格战反复（最大）**：电芯涨价主要靠碳酸锂成本推动，若碳酸锂回落、或500Ah+产能2026H2集中释放，电芯价格可能再度承压——**“量价齐升”的持续性依赖供需紧平衡**。
2. **市场化收益不及预期**：容量电价虽落地，但“电能量+容量+辅助服务”收益结构的稳定性待验证，辅助服务收入已因市场饱和下滑——**独立储能IRR仍依赖政策落地**。
3. **增速换挡**：基数变大，2030年前累计装机增速放缓（CNESA已提示“增速放缓成为定局”）——**从爆发期进入平稳增长期**。
4. **技术路线替代**：固态/钠电/液流等新路线冲击锂电，长时储能对锂电形成替代——**锂电龙头面临技术迭代风险**。
5. **海外政策与贸易壁垒**：关税/碳关税/本地化要求，海外高毛利订单存政策反复风险；出口退税率下调（9%→6%）压缩利润。

| **集中度** | 电芯CR5约56%、集成洗牌（中车/阳光领先）、PCS稳定 |
| **护城河** | 电芯规模成本 > PCS技术芯片 > 集成品牌项目 > 出海渠道 |
| **盈利画像** | 宁德净利722亿(+42%)、阳光134.6亿(+22%)、海博思创+47%；二线仍修复 |
| **估值** | 电芯21-27倍、PCS 16-33倍、系统集成36倍 |
| **核心风险** | 价格战反复、市场化收益不及预期、增速换挡、技术替代、海外政策 |

**一句话总览**：

储能是中国新能源“从政策驱动走向市场化”的最佳样本，也是当下“量价齐升的确定性赛道”——**2025年新型储能累计装机144.7GW(+85%)、首次占全球51.9%，新增66.4GW连续四年全球第一；2026年电芯涨价28%、碳酸锂+170%、314Ah电芯从0.31涨至0.365元/Wh，从“供过于求”转向“紧平衡”，量价齐升拐点确立**。政策范式完成了历史性切换——“136号文”取消强制配储、2026年容量电价落地，储能从“成本项”变“价值项”，IRR从不足5%回升至8-12%，**市场化用储的内生动力取代行政命令，这才是“超级周期”的真正含义**。但钱依然是分层的：**电芯龙头赚“量价齐升的钱”**（宁德时代净利722亿+42%、毛利率26%、ROE 19.5%——规模+成本壁垒无人撼动），**系统集成赚“份额+出海的钱”**（阳光电源净利134.6亿+22%、海外占比83%享高毛利；中车株洲所国内并网/出货双第一），**PCS赚“技术壁垒的钱”**（时代电气毛利率33.4%、禾望38%，IGBT国产化护城河最深），**二线电池还在赚“修复的钱”**（欣旺达-28%、派能净利仅0.85亿）。**2026-2030年三条主线清晰：国内装机高增（2030年3.7亿千瓦、长时储能占比提升）、量价齐升（500Ah+大电芯迭代+集采放量）、出海与AI增量（海外大储爆发+数据中心备电）**。**买储能，要么买确定性最强的电芯龙头（宁德时代——规模成本+量价齐升双赢），要么买技术溢价最高的PCS（时代电气——IGBT+储能变流器，16倍PE性价比凸显），要么赌出海弹性最大的集成商（阳光电源——全球大储第一+海外高毛利）**。最需要警惕的是：电芯涨价由碳酸锂成本推动，若上游回落或产能释放，价格战可能反复；市场化收益、技术路线替代（固态/液流/钠电）、海外政策都是变量。**这是一门“从政策驱动转向市场驱动、从内卷出清走向量价齐升”的成长课**——储能的确定性在于中国全球52%的装机地位与市场化转型的内生动力，弹性在于电芯涨价与出海高毛利，风险在于价格与政策。
