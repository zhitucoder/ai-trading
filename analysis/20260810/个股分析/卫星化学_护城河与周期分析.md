## 二、卫星的护城河是什么？一条"原料脱钩"的降维打击

卫星化学最特殊的地方，在于它的原料——**乙烷**。它不烧油、不烧煤，而是把美国页岩气里的乙烷，用船运到中国来裂解成乙烯。这带来一个近乎"作弊"的优势：

**它的原料价格与美国天然气（亨利港指数）挂钩，与原油价格基本脱钩。**

这个"脱钩"是关键。全球烯烃市场的主流是**石脑油路线**（用石油裂解），烯烃售价跟着油价走；而卫星用乙烷（跟天然气走），成本是一条独立的曲线。

```
油价上涨 → 石脑油路线成本暴涨 → 全行业烯烃价格被推高
         → 但卫星的乙烷成本不动（跟天然气挂钩）
         → 售价涨、成本不涨 → 价差走阔 → 暴赚

油价回落 → 石脑油路线成本下降 → 烯烃价格跟随回落
         → 卫星的乙烷成本依然不动
         → 售价跌、成本不动 → 价差收窄 → 利润承压
```

**所以卫星和宝丰其实是"同一个剧本、不同的原料"**：宝丰赚"油价−煤价"的价差，卫星赚"油价−天然气（乙烷）价"的价差。**它们都在赚"油和其他能源原料之间的价差"，而油价是定价端，乙烷/煤是成本端。**

2026H1 的爆发就是这么来的：中东冲突推高布伦特原油站上 80 美元/桶，石脑油路线成本暴涨，而卫星的乙烷价格稳定在 20-25 美分/加仑的历史低位——**油气价差拉到历史高位，直接变成利润。**

## 三、护城河有几层？三层，且都在加厚

### 第一层：成本优势（结构性，最扎实）

乙烷裂解vs石脑油裂解，成本优势体现在四个维度：

| 维度 | 乙烷裂解（卫星） | 石脑油裂解（主流） |
|---|---|---|
| 单程收率 | 77%-85% | 30%-35% |
| 综合能耗 | 比石脑油低20%-30% | 基准 |
| 百万吨装置投资 | 30-50亿 | 80-100亿 |
| 碳排放强度 | 0.8-0.95吨CO₂/吨乙烯 | 显著更高 |

**原料便宜+收率高+能耗低+投资省**，四重叠加让乙烷路线成为全球乙烯产业"轻质化转型"的优选方案。**关键点：油价处于中高位时（如当前），乙烷路线的成本优势被放大到极致**；只有在油价极低（低于40美元/桶）的极端情况下，石脑油才可能反超。

### 第二层：供应链壁垒（排他性，最难复制）

这是卫星护城河"排他性突出"的一层，也是宝丰没有的：

- **北美乙烷源头**：与美国能源巨头 Energy Transfer 长期合作，锁定出口仓储设施
- **专属船队**：自建 VLEC 超大型乙烷运输船队，锁定稀缺远洋运力；美国合资 Orbit 码头（出口能力约18万桶/日）
- **国内独一份**：**国内少有实现"乙烷进口-储运-裂解"全链条自主可控的民营企业**

**这条供应链不是花钱就能复制的**：新建码头要 5-6 年、VLEC 船队全球就那么多、美国出口设施有排他协议。**对手要复制卫星的原料渠道，可能比建一套装置还难。**

### 第三层：一体化协同（正在加厚）

C2（乙烷-乙烯）+ C3（丙烷-丙烯酸-丙烯酸酯）双产业链：

- C2：乙烷裂解制乙烯，两套125万吨/年装置（合计250万吨）
- C3：国内规模较大、全球第二的丙烯酸及酯产业链
- 高端新材料：POE胶膜、新戊二醇、高分子乳液、芳烃联合装置等

**多产品矩阵对冲单一产品周期**，产业链协同摊薄成本。2025年丙烯酸总产量"三年连增"，产品结构向高附加值持续升级。

**护城河结论**：成本优势（结构性）+供应链壁垒（排他性）+一体化协同（成长性）三层叠加，且都在加厚——**卫星的护城河不是"挖好了等着"，而是"越挖越深"。**

## 四、但周期属性也真实存在：两轮"腰斩"的教训

护城河再深，也挡不住产品价格周期。看卫星的两次大波动：

### 第一轮：2021年高点→2022年腰斩

- 2021年：油价上行+C2/C3价差走阔，净利冲到60.1亿
- 2022年：**油气价差收缩**（油价回落+需求疲软）+ 聚丙烯、丙烯酸等产品价格下行，净利跌到30.6亿（-49%）

### 第二轮：2025年下滑

- 2025年：净利53.1亿（-12.5%），主要因聚丙烯价差收窄、乙烯装置检修

**看这两个周期，能理解卫星的"周期心电图"**：

```
2021年 油气价差走阔 → 净利60.1亿（峰值）
2022年 价差收缩+需求弱 → 净利30.6亿（腰斩）
2023年 修复 → 净利47.9亿
2024年 继续改善 → 净利60.7亿
2025年 部分产品价差收窄 → 净利53.1亿
2026H1 油价暴涨+价差新高 → 净利60~70亿（历史新高）
```

**周期属性结论**：卫星的盈利受"油气价差"强周期影响，单年净利可以在30亿到70亿之间大幅摆动（超过2倍）。**它绝不是无周期的"类公用事业"，而是周期弹性很大的化工龙头**——只是它的周期弹性方向（油价涨→赚）和大多数化工股（油价涨→成本涨→亏）相反，这本身就说明护城河在起作用。

## 五、这轮爆发，量占多少？价占多少？

2026H1 净利60~70亿，拆开看：

### 价的部分（周期驱动，占大头）

- 中东冲突推高油价，乙烷成本稳定，油气价差拉到历史高位
- **这部分占利润增量的60-70%**，油价回落就会回吐

### 量的部分（护城河驱动，可持续）

- 两套125万吨/年乙烯装置稳定满产
- 新戊二醇（2025年8月投产）、高分子乳液、芳烃联合装置等产能爬坡
- **这部分占30-40%**，是可重复、可持续的增长

**关键判断**：卫星2026年的爆发，**"价差红利"是大头**。一旦油价从80美元高位回落，盈利会明显回落，但不会回到2022年的30.6亿——因为：
1. 产能规模比2022年更大（新戊二醇等投产）
2. 海外高成本乙烯产能（欧洲/日韩）在集中退出，全球供给格局改善
3. 乙烷供给持续宽松，原料成本优势反而在扩大

**这轮是"周期+成长"共振，不是单纯的周期。** 但要清醒：价差红利会随油价回落而缩水。

## 六、核心矛盾：油价是"双刃剑"，但卫星是"单刃"的

**对大多数化工企业，油价是"双刃剑"**（涨了成本涨，跌了售价跌）；**对卫星，油价其实是"单刃的"**：

- 油价涨 → 石脑油路线成本涨 → 烯烃售价涨 → 卫星乙烷成本不动 → **赚差价**
- 油价跌 → 石脑油路线成本降 → 烯烃售价降 → 卫星乙烷成本也不动 → **少赚但不亏**

**卫星的风险不在油价涨跌，而在两点**：
1. **乙烷价格上涨**：如果美国天然气价格大涨（如极寒天气、需求爆发），乙烷成本上升，价差收窄
2. **烯烃自身过剩**：如果聚烯烃/丙烯酸产能集中投放导致价格中枢下移，即便乙烷便宜，售价也上不去

**这决定了卫星的估值逻辑**：它不该按"周期股"给很低的PE，也不该按"纯成长股"给很高的PE，而是介于两者之间——**成本护城河决定盈利下限（40-50亿），油气价差决定盈利上限（70-100亿），估值应该在两者之间寻找平衡。**

## 七、三个警惕信号

护城河不是永久的，盯三件事：

### 信号1：美国天然气/乙烷价格大涨

乙烷成本是卫星的生命线。若亨利港天然气价格大幅上行（极寒、需求爆发、出口受限），乙烷成本上升，价差被压缩。**这是最需要警惕的**——它直接侵蚀护城河的根基。

### 信号2：烯烃产品过剩

聚丙烯、丙烯酸等若产能集中投放，产品价格中枢下移。**当前海外高成本产能（欧洲3700万吨、日韩多套装置）在退出，短期供给改善，但国内新增产能仍在释放。**

### 信号3：油价极端下跌

**只有油价低于40美元/桶的极端情况**，石脑油路线成本才可能反超乙烷。卫星可通过国产乙烷或长协锁价对冲，但极端低油价下成本优势会阶段性弱化。

## 八、总结：一条"越挖越深"的护城河，配一次"看得见的周期"

把话说透：

**卫星化学的护城河是A股化工里排在前列的**——乙烷"原料脱钩"的定价模式（成本跟天然气、售价跟油价），加上**国内唯一民企全链条自主可控**的供应链壁垒（北美源头+专属船队+Orbit码头），让它在油价上行期享受"别人涨成本、它涨利润"的独特红利。**十年净利17倍的增长，不是周期能解释的，是护城河推动的成长。**

**但它的周期属性同样真实**——2022年从60亿腰斩到30亿，2025年又下滑12%，盈利随油气价差大起大落。**这是典型的"成长中的周期股"：护城河决定下限（40-50亿），周期决定上限（70-100亿）。**

**当前的判断**：
- 若用"护城河视角"看：海外高成本产能退出+乙烷供给宽松+高端新材料放量，盈利中枢持续抬升，当前的估值并不贵
- 若用"周期视角"看：油气价差已处历史高位，油价从80美元回落后，价差红利会缩水

**我的倾向是：卫星比宝丰更接近"成长股"**——因为它的护城河（供应链排他性）比宝丰（成本优势）更难复制，且海外产能退出是"结构性"利好而非"周期性"利好。**但它的盈利弹性仍然高度依赖油气价差**，这是所有"轻烃裂解"企业的宿命。

**对这类公司，正确的姿势是：在乙烷价差回落、市场用周期股定价时，用护城河的视角寻找买点；在油气价差历史高位、市场情绪亢奋时，清醒地知道"价差红利会均值回归"。** 护城河让它穿越周期，周期让它锦上添花——这就是卫星化学的全部真相。
