## 二、护城河在哪里？三层结构

宝丰的护城河不是单一壁垒，而是三层叠加：

### 第一层：成本优势（最核心的一层）

**煤制烯烃路线的本质是"用煤替代石油"**。煤和油的价差，就是它的利润来源：

- **原料便宜**：中国"富煤贫油少气"，动力煤（5000大卡鄂尔多斯约421元/吨）vs 石脑油/乙烷，原料成本低一个量级
- **技术先进**：内蒙古项目采用DMTO-Ⅲ三代技术，醇烯比2.66（每吨烯烃耗甲醇2.66吨），比宁东二期（2.88）低8%
- **单吨成本低**：内蒙项目比宁东低约1000元/吨（运费省405+人工省260+配送省120+醇耗低等）

**这个护城河是"结构性"的**——不依赖景气度，只要煤价低于油价的比价关系存在，煤制路线就有天然成本优势。2018年油价高位时毛利率46.9%，2023年行业寒冬时仍能赚30.4%，就是最好的证明。

### 第二层：规模壁垒（正在加厚）

- 内蒙古300万吨/年项目（2025年4月全面达产）是全球单厂规模最大的煤制烯烃装置
- 总烯烃产能520万吨/年，居国内煤制烯烃行业第一
- 后续还有宁东四期、内蒙古二期等扩产规划

**规模的意义**：摊薄单位折旧和管理费用；对上游煤炭、下游客户有议价权；新进入者要复制这个规模，需要数百亿资本开支+多年建设周期。

### 第三层：政策准入（最稀缺的一层）

**国家对现代煤化工产能从严从紧控制**——新增煤化工项目审批收紧，必须在煤炭资源丰富地区，还要过水资源、能耗、环保指标。**这意味着：存量产能=稀缺牌照**，新进入者很难再拿到入场券。这层护城河比成本优势更"排他"。

**护城河结论**：成本优势（结构性）+规模壁垒（正在加厚）+政策准入（稀缺性）三层叠加，宝丰的护城河是真实且在变深的。

## 三、周期属性有多强？三种价格，三种命运

再好的护城河，也挡不住产品价格周期。宝丰的盈利受三个价格影响：

### 价格1：烯烃价格（聚乙烯/聚丙烯）

下游是塑料制品、包装、农膜，需求随宏观周期波动。2020-2022年油价上行推高烯烃价格，2022-2023年需求疲软+供给过剩，烯烃价格回落——这是2022-2023年净利下滑的直接原因。

### 价格2：煤炭价格（成本端）

煤是主要原料，煤价上涨压缩毛利。2021-2022年煤价暴涨（动力煤一度超1500元/吨），毛利率从45%+砸到32.9%——这是2021年净利见顶后下滑的另一个原因。

### 价格3：油气价差（核心变量）

**中东地缘冲突推高油价时，油制路线成本暴涨，煤制路线相对优势扩大，价差走阔→暴赚；油价回落时，价差收窄→盈利回落。** 2025-2026年的暴增，本质就是"油价高位+煤价低位"的价差红利。

### 为什么油价回落会直接冲击宝丰的利润？——一条完整的传导链

很多朋友会困惑：宝丰烧的是煤，不用油，油价跌了它的成本还更低，为什么反而伤利润？这里的关键在于：**烯烃（聚乙烯/聚丙烯）的"定价权"在油制路线手里，而不是煤制路线手里。**

石油化工是全球烯烃的主流工艺，全球约七成聚烯烃来自油制/气制路线。**烯烃的市场价格 = 跟随"油制路线的成本"定价**，具体传导链条如下：

```
油价上涨 → 油制烯烃成本暴涨 → 全行业烯烃价格被推高（跟着油价涨）
         → 但宝丰的煤制成本几乎不动（烧煤，不烧油）
         → 售价涨、成本不涨 → 价差走阔 → 利润暴涨

油价回落 → 油制烯烃成本下降 → 全行业烯烃价格跟随回落（跟着油价跌）
         → 但宝丰的煤制成本依然不变
         → 售价跌、成本不动 → 价差收窄 → 利润被压缩
```

**打个比方**：宝丰就像"用煤价买原料、按油价卖产品"的套利者。煤和油是两条独立的成本曲线，宝丰赚的是"两条曲线之间的价差"。**油价上行时，卖价被油制路线顶上去，而成本锚定在煤价上，价差越拉越大；油价回落时，卖价跟着油走跌，成本却不降，价差就被两头挤压。**

所以宝丰盈利的"真实驱动"不是烯烃绝对价格，而是**"油制烯烃成本 − 煤制烯烃成本"的价差**：

- **油价越高、煤价越低 → 价差越大 → 暴赚**（2021年、2025-2026年就是这种状态）
- **油价越低、煤价越高 → 价差越小 → 少赚**（2023年煤价高位+油价回落，价差被挤压）

这也能解释为什么2022年公司毛利率从45%砸到32.9%——那一轮是**煤价暴涨（成本端）**和**油价回落+需求疲软（价格端）**同时发生，价差被两端挤压，双杀。

**结论**：油价回落对宝丰不是"省了成本"，而是"压低了售价"——因为它的产品定价权不在自己手里，而在油制路线手里。**只要油价下跌的幅度大于煤价，宝丰的价差就收窄，利润就受损。这是理解宝丰周期属性的核心。**

### 三个价格其实是"两个价差"

把三个价格整合一下，宝丰的盈利可以用一个公式理解：

```
利润 ≈ 烯烃售价 − 煤制成本 − 期间费用
    ≈ （油价定价的烯烃市场价）−（煤价定的生产成本）− 费用
    ≈ 油气价差 − 费用
```

**所以真正的周期变量只有一对：油气价差。** 烯烃价格和煤炭价格单独看没有意义，看的是"油和煤的比价关系"——这才是决定宝丰赚多赚少的核心。

**看这个波动，就能明白宝丰的"周期心电图"**：

```
2018年 油价高位 → 净利37亿
2020年 疫情冲击 → 净利46亿（煤制抗跌）
2021年 煤价暴涨+烯烃上行 → 净利70.7亿（价差最阔）
2022年 煤价高位+需求回落 → 净利63亿（成本侵蚀）
2023年 行业过剩+煤价高 → 净利56.5亿（周期低谷）
2024年 煤价下行 → 净利63.4亿（修复）
2025年 油价暴涨+内蒙达产 → 净利113.5亿（量价双击）
```

**周期属性结论**：宝丰的盈利受"煤价-油价价差"强周期影响，单年净利可以在56亿到113亿之间大幅摆动（近2倍）。**它绝不是无周期的"类公用事业"，而是周期弹性很大的化工龙头。**

- 中东冲突推高油价，煤制烯烃价差走阔
- 这部分是"周期红利"，**油价回落就会回吐**

**2026H1预告净利93~102亿（+62.65%~78.4%）**，Q2单季56.4~65.4亿，创历史新高——**这轮爆发是"量价共振"：内蒙古达产的量增 + 油价高位的价差，两个引擎同时发力。**

**关键判断**：量的部分约贡献30-40%（内蒙项目达产爬坡），价的部分约贡献60-70%（价差走阔）。**这意味着：一旦油价回落，盈利会明显回落，但不会回到2023年的56亿——因为520万吨的产能规模比2023年（300万吨级）大得多，量的护城河已经垫高了利润下限。**

## 五、核心矛盾：护城河抬高的下限，vs 周期决定的上限

**宝丰现在处在一个"剪刀差"时刻**：

- **护城河在抬升盈利下限**：产能从300万吨扩到520万吨，即便价差回落到2023年水平，盈利中枢也从56亿抬升到70-80亿量级
- **周期在决定盈利上限**：当油价高位+煤价低位时（如2025-2026），价差红利可以把盈利推到110-150亿
- **估值却按"周期股"定价**：1736亿市值、2026E PE约11倍，市场没按"成长股"（20倍+）给价，而是按"周期股"打折

**这就是宝丰的核心投资逻辑：** 市场在"周期股"和"成长股"之间犹豫。如果你认为护城河让盈利下限持续抬高，那11倍PE低估了；如果你认为这轮价差是周期的盛宴，那盈利回落时11倍也不便宜。

## 六、护城河会被侵蚀吗？三个警惕信号

护城河不是永久的，需要盯三个信号：

### 信号1：烯烃产能过剩

2020-2022年高景气催生的油制/煤制烯烃项目，2025-2027年集中投产。若聚烯烃供给过剩，产品价格中枢下移，**即便煤制成本优势仍在，价差也会被"产品价格下跌"压缩**。这是最需要警惕的。

### 信号2：煤价反弹

**成本优势依赖低煤价**。若动力煤价格大幅反弹（产地收紧、政策因素），而烯烃价格跟不上，毛利空间被挤压。2021-2022年煤价暴涨已经演示过一次（毛利率45%→32.9%）。

### 信号3：技术路线颠覆

**乙烷裂解（卫星化学）等路线如果大规模放量，且油价不高，煤制路线的成本优势会相对弱化**。不过当前油价高位，煤制仍是成本洼地；长期看，只要"富煤贫油"国情不变，煤制路线的存在价值就还在。

## 七、总结：是护城河里的成长股，还是周期的舞者？

把话说透：

**宝丰能源的护城河是真的，且在变深**——成本优势（结构性）+规模壁垒（520万吨国内第一）+政策准入（审批收紧），三层叠加让它的盈利下限在持续抬升。**从2016年17亿到2025年113亿，十年6.6倍，这不是周期能做到的，是护城河推动的成长。**

**但它的周期属性也是真的，且弹性很大**——盈利随"煤价-油价价差"大起大落，2021年70.7亿→2023年56.5亿→2025年113.5亿，单年波动近2倍。**这是典型的"周期成长股"：底层是护城河（决定下限），表层是周期（决定上限）。**

**当前的判断**：
- 若用"护城河视角"看：内蒙达产抬高盈利下限至70-80亿，11倍PE低估了它的成长性
- 若用"周期视角"看：这轮价差红利（油价高位+煤价低位）是周期的馈赠，油价回落时盈利会回吐

**我的倾向是：宝丰介于"成长股"和"周期股"之间，更接近"护城河不断加厚的周期成长股"**——它的长期价值来自护城河（成本+规模+准入），短期弹性来自周期（价差）。**对这类公司，正确姿势不是用"成长股"或"周期股"的单一标签套它，而是：在周期低谷（盈利60亿以下、估值打折）时，用护城河的视角买入；在周期高峰（盈利翻倍、价差最阔）时，清醒地知道"盛宴总有尽头"。**

**护城河让它在周期低谷亏不死，周期让它在景气高峰赚更多——这就是宝丰能源的全部真相。**
