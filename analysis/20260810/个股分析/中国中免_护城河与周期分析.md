## 二、护城河在哪里？三层结构

### 第一层：牌照垄断（政策壁垒，排他性强）

**免税业是特许经营行业，牌照=入场券**。国务院批准的特许经营权，全国就这几张：

- 全牌照经营企业仅中国中免、深免、珠免、中出服、王府井等少数几家
- **中免以约78.7%市场份额占据主导**，是行业龙头

**这层护城河的"硬"在于**：不是靠竞争赢来的，是政策给的"特许权"。新进入者拿不到牌照，天然无法复制。**这是中国中免最深的护城河。**

### 第二层：规模与渠道（正在加厚）

- **离岛免税**：海南占免税市场约65%，中免海南市占率持续提升（2025年+1pct）
- **机场渠道**：北京（首都+大兴）、上海（浦东+虹桥）机场免税店，2026年陆续开业/转场
- **市内免税**：中标深圳、广州、西安、福州4家，大连焕新开业
- **海外**：收购DFS大中华区（港澳9家门店），新加坡樟宜、香港国际机场开业
- **数字化**：3800万会员，会员复购率提升

**渠道网络是"第二张牌照"**——离岛+机场+市内+海外+线上五位一体，竞争对手即便拿到牌照，也复制不了这个渠道密度。

### 第三层：品牌与供应链（护城河的"粘合剂"）

- **LVMH集团、Miller家族增发H股，成为战略股东**——品牌资源深度绑定
- **1200+品牌直采**，成本比同行低10-20%
- **中免健康自有品牌**、独家/首发/联名产品，提升毛利

**品牌和供应链让"牌照"真正变现**——有牌照但没品牌议价力的公司，只能吃牌照租金；中免靠品牌绑定+直采成本，把牌照价值最大化。

**护城河结论**：牌照垄断（政策壁垒）+规模渠道（第二牌照）+品牌供应链（变现能力）三层叠加，**中国中免的护城河是A股消费板块里最深的之一**。

## 三、但护城河"靠政策"，周期"看消费"——两大软肋

再深的护城河，也挡不住两件事：

### 软肋1：政策是双刃剑

**牌照是政策给的，政策也能调整**。免税的"基因"是"政策红利"：

- 政策加码（品类/额度/次数扩容）→ 行业空间打开 → 中免受益
- 政策收紧（额度限制/品类调整）→ 行业收缩 → 中免承压

**2021-2024年的"免税熊市"，本质是代购冲击+消费疲弱+场景单一三重压制**——不是牌照不值钱了，而是牌照背后的"消费场景"（出境游+海南离岛）被压缩了。

### 软肋2：消费周期决定弹性

**免税是可选消费，对居民消费意愿高度敏感**：

- 收入预期差、"有钱不敢花" → 高端免税品首当其冲（2024年社零疲弱，中免净利-36%）
- 出境游分流 → 高端消费流向境外（韩日免税）
- 消费信心修复 → 中免率先受益（2026Q1海南+28%）

**这就解释了中免的"周期心电图"**：

```
2021年 海南离岛爆发 → 净利96.5亿（峰值）
2022年 疫情+消费弱 → 净利50.3亿（腰斩）
2023年 报复性消费 → 净利67.1亿（反弹）
2024年 消费疲弱+代购 → 净利42.7亿（再降）
2025年 需求低迷+商誉减值 → 净利35.9亿（四年低点）
2026H1 封关+新政+回流 → 净利31.1亿（+19.5%，反转）
```

## 五、护城河会被侵蚀吗？三个警惕信号

### 信号1：政策红利兑现节奏

**免税本质是"政策依赖+牌照垄断"**。政策的边际放松（品类/额度/次数）直接决定行业空间。若后续政策加码不及预期，或市内免税向本地居民开放的节奏放缓，行业空间受限。

### 信号2：消费复苏持续性

**"924"后消费信心能否延续是关键**。2026年5月社零一度转负、6月回升，消费复苏有波折。若居民收入预期反复、可选消费意愿不足，高端免税品首当其冲。

### 信号3：竞争格局

**跨境电商（品类丰富度"跨境>离岛>口岸>市内"）、有税专柜对免税的分流**，以及王府井等持牌方在部分区域的分流。中免78.7%市占率虽高，但并非垄断无忧。

- **护城河决定下限**：牌照垄断+322亿净现金（2026Q1现金353亿-有息负债31亿），即便消费再弱，中免也"死不了"
