## 二、化工周期的原因：为什么化工品价格会大起大落？

化工的周期本质是**产能周期**，其核心传导链是：

```
化工品价格上涨 → 利润暴涨 → 企业扩产 → 产能集中投放 → 供给过剩 → 价格下跌 → 利润亏损 → 产能出清 → 供给收缩 → 价格回升（新一轮）
```

### 为什么化工的周期特别"剧烈"？

**1. 扩产周期长且"扎堆"**

化工装置从立项到投产要3-5年，且行业"扩产跟风"严重——景气好的时候大家都上马，结果几年后产能集中释放，直接打崩价格。上一轮（2020-2022年）高景气催生的大量项目，在2023-2025年集中投产，是本轮化工"产能过剩、PPI连续38个月负增长"的直接原因。

**2. 需求相对刚性、供给弹性大**

化工品的下游需求（地产、纺服、家电、汽车）相对平稳，但供给端会因为"扩产/停产/检修"剧烈波动，所以价格主要由供给端决定——**供给多则贱，供给少则贵**。

**3. 原料成本传导**

化工品的价格还受原油、天然气、煤炭等原料价格影响。油制、煤制、气制（轻烃）路线的成本差异，决定了不同企业在大宗商品涨价时的相对竞争力。
