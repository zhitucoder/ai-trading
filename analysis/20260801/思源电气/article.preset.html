0. 公司速览

思源电气 = &quot;电力设备里的民营黑马&quot;。它是少数能在国网招标中和央企（西电/平高/许继）抗衡的民营企业，做GIS开关、变压器、继电保护。近年靠出海+数据中心+超级电容三大新引擎，营收两年翻倍。

一句话：这是一家&quot;从国内电网红海杀出，靠出海打开第二曲线&quot;的民营设备龙头——成长靠的是海外和AIDC，风险也在海外。

一、资产质量分析

资产结构：轻资产、高应收、无商誉雷

三大特征：

1. 应收账款81.8亿，占总资产27%——营收增长的&quot;代价&quot;

应收从2023年的43.4亿飙到2025年的81.8亿（+88%），与营收高增同步。电网设备行业下游（国网/海外客户）账期长，营收增长越快，应收膨胀越猛。这是行业特性，但要注意回款质量。

2. 货币资金49.3亿+交易性金融资产28.4亿=现金储备约78亿

现金充足，几乎无有息负债（短期借款仅3.6亿）——财务底子非常干净。

3. 商誉5.4亿，占比低

来自小并购，占总资产1.8%，无重大减值风险。

4. 轻资产，固定资产29亿占10%

设备制造以组装为主，扩产靠资本开支（2025年开关6亿+变压器4.8亿扩产），轻资产+高周转。

资产质量评分

总结：资产质量&quot;现金厚、应收重&quot;。现金+理财约78亿、几乎零负债，财务底子极干净；但应收账款81.8亿占总资产27%、占营收38%，是营收高增的代价——它赚的是&quot;账面上的钱&quot;，回款是最大变量。

二、利润质量分析

营收利润双高增，但2026H1净利率下滑

这是电力设备板块最漂亮的成长曲线：

1. 营收两年翻倍（124.6亿→215.4亿，+73%），净利+103%

2023-2025年营收CAGR约31%，净利CAGR约42%——利润增速快于营收，规模效应+产品结构升级（高毛利变压器、开关占比提升）。

2. 毛利率稳定在30%左右

2025年毛利率30.8%，比央企同行（西电/平高约20%）高10个百分点——民企的管理效率+产品力溢价。用公式拆开看：

核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用
核心利润率 = 核心利润 / 营业收入 × 100%

思源2025年核心利润约59.6亿（215.4-149.1-10.3-5.8），核心利润率27.7%——绝对值高、利润率也高，电力设备里难得的高质量利润。

3. 海外毛利率35.2% &gt; 国内29.1%——出海提升利润质量

海外收入58亿（+86%），毛利率35%比国内高6个百分点。出海的单越做越多，整体利润率越往上走。

4. 2026H1净利率下滑至13.8%（-1.4pct）——短期扰动

2026H1营收108亿（+27%）、净利14.87亿（+15%），净利率下降。原因：

  • 确收规则变化：港股上市审计调整，设备业务从"开票确认"改为"验收确认"，海外订单确认延迟
  • 汇兑损失超1亿：人民币升值侵蚀海外应收
  • 低毛利项目：储能、EPC业务占比提升

这是节奏问题，不是趋势问题——公司预计Q3起高毛利海外订单密集确收，利润率将回升。

利润质量评分

总结：利润质量是思源最强的维度。毛利率30%+、核心利润率27%+，是电力设备里利润率最高的民营龙头。2026H1的净利率下滑是"确收节奏+汇兑"的短期扰动，不是经营恶化——它的利润是真实的高质量利润，靠产品力+海外结构，不靠投资收益。

三、现金流分析

经营现金流：从暴增到趋缓，2026Q1转负

现金流比利润差——这是思源需要正视的问题：

1. 2025年经营现金流22.3亿，只有净利的68%

净利32.6亿，但现金只回来22.3亿——差额10亿被应收账款占用了（应收从57.6亿增至81.8亿，多占用24亿）。利润高增的同时，钱压在客户账期里。

2. 2026Q1经营现金流-4.8亿

营收+41.6%，但现金流转负——营收增长靠&quot;垫资&quot;支撑，应收继续膨胀（2026Q1仍有78亿）。

3. 历史看：2023-2024年现金流很好（141%、118%）

说明正常年份思源的现金流质量不错，2025-2026年的恶化主要是海外业务放量带来的回款周期拉长（海外客户账期更长）。

现金流评分

总结：现金流是思源的隐忧。2025年现金流只有净利的68%、2026Q1转负，主要被81.8亿应收账款占用——出海放量的代价是回款周期拉长。虽然现金储备厚（约78亿）、零负债，但&quot;利润涨、现金跟不上&quot;的趋势需要盯紧。

四、偿债能力分析

负债率47%，几乎零有息负债

偿债能力极强：

1. 有息负债仅4.2亿（短借3.6+长借0.6）vs 现金49.3亿——净现金45亿

2. 负债率47%看似不低，但主要是&quot;经营负债&quot;

  • 应付账款58.3亿——欠供应商的货款，不用付利息，是产业链话语权
  • 合同负债（预收）——客户预付的定金

3. 无重大财务压力：财务费用几乎为零（2025年为负）

偿债能力评分

总结：偿债能力非常强。有息负债仅4.2亿、净现金45亿、财务费用为零——这是典型的&quot;不缺钱&quot;的成长型公司。47%的负债率里大头是应付账款（欠供应商）和预收款，都是"好负债"。它用别人的钱（供应商+客户）做自己的生意，资金效率高。

六、成长的核心驱动力是什么？

这是理解思源电气最关键的一节。它的成长不是偶然，而是三重驱动力的共振：

驱动力1：全球电网投资大周期（行业β）

电网设备是&quot;卖铲子&quot;的——全球在疯狂扩建电网。

  • 国内：国网"十五五"固定资产投资预计4万亿（较"十四五"增长40%），特高压、配网、抽蓄三线推进
  • 海外：欧美电网老化+新能源并网+数据中心用电暴增，全球电网设备供不应求，电力变压器供应短缺预计持续到2030年
  • 核心逻辑：全球电力需求（尤其AI数据中心）爆发，但电网建设滞后——这个&quot;欠账&quot;要几十年还，电网设备的需求是长期、确定性的

数据佐证：2025年思源海外收入58亿（+86%），2026年海外订单预计+50%以上，全球市占率仅约2%——成长空间巨大。

驱动力2：出海打开第二曲线（公司α）

思源从&quot;国内电网红海&quot;杀到&quot;全球高端市场&quot;，这是它最核心的差异化。

  • 2025年海外收入58亿（+86%），占比从20%升至27%
  • 海外毛利率35.2%，比国内高6个百分点——出海的单，利润更厚
  • 成功切入北美顶级电网运营商供应链，7月对美变压器出货已从每月2-3台增至10台
  • 北美变压器年产值目标90-100亿

核心逻辑：国内电网设备竞争激烈（央企主导），但海外市场（尤其北美）供给短缺、认证壁垒高、利润丰厚——思源作为少数能通过海外认证的中国民企，吃到了&quot;供给稀缺&quot;的红利。

驱动力3：AIDC数据中心+超级电容（新增长曲线）

AI数据中心是电网设备的新需求引擎。

  • AIDC：AI数据中心自建电源+变电站，对变压器、断路器需求暴增，且涨价能力强、利润空间大
  • 超级电容：48V超级电容供不应求，供应台达（一供），电网侧/车载/AIDC三大场景需求放量——正在成为新的业绩增量
  • 业务扩张：2026年新签订单目标375亿（+30%），营收目标270亿（+25%）

七、什么会让它不再成长？

再好的成长也有天花板，思源的成长有三道&quot;刹车&quot;：

风险1：海外执行与地缘风险（最大的不确定性）

  • 贸易壁垒：海外收入占比快速提升，若美国/欧洲对中国电力设备加征关税、设置壁垒，出海逻辑受冲击
  • 地缘冲突：2026Q2海外部分交付受地缘政治影响（航运受阻），交付节奏不可控
  • 汇率风险：海外应收以美元为主，人民币升值直接造成汇兑损失（2026H1汇兑损失超1亿）

刹车逻辑：思源的高增长高度依赖海外，一旦海外市场对中国设备设限或需求逆转，第二引擎熄火，成长将大幅减速。

风险2：应收账款膨胀与回款风险（财务刹车）

  • 应收账款81.8亿（占营收38%），2025年现金流只有净利的68%、2026Q1转负
  • 如果海外客户回款周期持续拉长、或个别客户坏账，现金流会进一步恶化
  • 成长越猛，垫资越多——这是"用现金换增长"的模式，有天花板

风险3：竞争加剧与毛利率下行（行业刹车）

  • 央企（西电/平高/许继）加大海外布局，海外高端市场的&quot;供给稀缺&quot;红利可能被瓜分
  • 储能、EPC等低毛利业务占比提升，整体毛利率有下行压力（2026H1已下滑至13.8%）
  • 若全球电网设备短缺缓解（预计2030年后），涨价红利消失，利润率回落

风险4：AIDC/超级电容需求不及预期（新业务刹车）

  • 若AI资本开支见顶、数据中心建设放缓，AIDC和超级电容的增量逻辑证伪
  • 超级电容虽是增量，但基数小，短期难撑起增长

风险5：国内电网投资节奏（行业β刹车）

  • 若国网"十五五"投资不及预期、招标节奏放缓，国内基本盘增长降速

八、专家诊断：六维汇总

综合评分：8.0/10 —— 电力设备最优质民营龙头，成也出海、险也出海

思源电气是电力设备板块&quot;利润质量+成长性&quot;双优的民营龙头——毛利率31%、净利+57%、营收两年翻倍，靠的是"全球电网大周期+出海+超级电容"三重驱动。它的财务底子极干净（净现金45亿、零负债），利润质量行业顶级。

用张新民的框架说：思源&quot;底子&quot;干净（净现金）、“面子”好看（净利+57%）、“日子”还行（现金流68%）——但&quot;生意&quot;高度押注海外。 它的成长逻辑是&quot;用国内电网打底，用海外高毛利订单放大利润，用AIDC和超级电容接棒&quot;——成也出海（高毛利高成长），险也出海（汇率、贸易、地缘）。

九、投资建议

看好的理由

  1. 利润质量顶级：毛利率31%、核心利润率28%，民营设备龙头
  2. 出海第二曲线：海外收入+86%、毛利率+6pct，北美突破
  3. 全球电网大周期：国网4万亿+海外短缺到2030，需求确定
  4. AIDC+超级电容：新增长引擎，供不应求
  5. 财务干净：净现金45亿、零有息负债

值得担忧的地方

  1. 海外执行/地缘：贸易壁垒、汇率、地缘冲突影响出海
  2. 应收账款81.8亿：现金流只有净利68%，垫资重
  3. 毛利率下行：低毛利储能/EPC占比提升
  4. 估值高：股价156元，PE约29倍（2026E）
  5. 竞争加剧：央企出海，供给稀缺红利被瓜分

投资建议

&quot;看海外订单兑现，盯应收和汇率&quot;策略：

  • 核心跟踪四个指标：
    1. 海外新签订单（预计2026年+50%）——出海成长的先行指标，订单在则成长在
    2. 应收账款周转——81.8亿应收能否有效回收，现金流的关键
    3. 季度毛利率——高毛利海外订单确收能否提升利润率（Q3是验证点）
    4. 人民币汇率——升值则汇兑损失扩大，侵蚀利润
  • 估值锚：股价156元，机构预测2026年净利42-45亿（PE约29倍）、2027年60亿（PE约20倍）。对高成长龙头，29倍PE合理但不算便宜
  • 操作上：成长逻辑（全球电网+出海）是真实且长期的，但短期受&quot;确收节奏+汇率&quot;扰动。Q3高毛利订单密集确收是验证点——若毛利率回升、海外订单兑现，成长延续；若海外受贸易壁垒或需求逆转，成长降速。好公司也要好价格，回调到20倍PE附近配置价值更优

风险提示：海外贸易壁垒、汇率大幅升值、应收账款坏账、竞争加剧、AIDC需求不及预期，均可能让高成长降速。思源电气是&quot;成也出海、险也出海&quot;的标的——它的成长靠全球电网大周期和海外突破，它的风险也在海外。看得懂出海的逻辑，更看得懂出海的险，才能赚到它的钱。
