## 一、费雪是谁？为什么今天还要学他？

菲利普·费雪（Philip A. Fisher，1907-2004）是成长股投资的奠基人。他的弟子叫 Warren Buffett——巴菲特说他的投资哲学中 **"85% 来自格雷厄姆，15% 来自费雪"** 。但如果你仔细看巴菲特 1970 年代之后的操作（重仓可口可乐、GEICO、苹果），那 15% 的影响力远不止这个数字。

费雪的核心贡献是两个：

1. **定性分析框架**：15 个问题系统评估公司质量
2. **Scuttlebutt 情报收集法**：不是坐在办公室看报表，而是走出去和人聊

这两者的结合，构成了成长股投资的底层操作系统。

## 二、15 点框架：一张表看懂

费雪把选股问题拆成 15 个具体问题，分为 4 个维度。我整理了一个速查表：

| 维度 | 问题 | 核心考察点 |
|------|------|-----------|
| **市场与产品** | Q1 市场潜力 | 产品/服务的销售能否在未来数年显著增长？ |
| | Q2 开发决心 | 管理层是否持续开发新产品/工艺？ |
| | Q3 研发效率 | R&D 投入的产出效率是否匹配公司规模？ |
| **人与组织** | Q4 销售组织 | 销售能力是否高于行业平均水平？ |
| | Q5 利润率 | 利润率是否足够且有改善空间？ |
| | Q6 利润维护 | 公司正在做什么来维持/改善利润率？ |
| | Q7 劳工关系 | 员工满意度和人事关系是否良好？ |
| | Q8 高管团队 | 高管之间的关系是否默契，决策高效？ |
| | Q9 组织深度 | 中层管理者是否足够优秀？ |
| **财务与控制** | Q10 成本控制 | 成本分析和会计控制是否到位？ |
| | Q11 竞争优势 | 是否有行业特有的长期竞争优势？ |
| | Q12 长短期平衡 | 公司是短期导向还是长期导向？ |
| **文化与诚信** | Q13 融资需求 | 未来是否需要大量股权融资稀释股东？ |
| | Q14 坦诚沟通 | 管理层在顺境和逆境中是否坦诚？ |
| | Q15 管理层诚信 | 管理层是否有无可置疑的正直？ |

**关键理解**：这 15 个问题不是打勾清单。费雪强调的是**系统性地了解一家公司**——从产品到人、从财务到文化。

## 三、最容易被忽视的问题：Q4 销售组织

15 个问题中，Q4（公司是否有高于平均水平的销售组织？）可能是最容易被跳过的——尤其是对技术背景的投资者。

费雪的原话：

> "一个公司如果开发了优秀的产品但没有好的销售组织，它可能永远无法将技术优势转化为市场优势。"

举例：当年 Xerox 施乐拥有革命性的复印技术，但因为销售策略失误，被 Canon 和 Ricoh 后来居上。技术领先不等于商业成功。

在 A 股市场，这个问题尤其值得关注。许多科技公司研发投入很高，但<strong>产品-市场-销售</strong>的转化路径不清晰。当你分析一家公司时，不要只看它的研发数据——问自己：**它的东西怎么卖出去的？卖给谁？为什么客户选它而不是竞争对手？**

## 四、Scuttlebutt 情报收集法：费雪最锋利的工具

费雪说的 Scuttlebutt（饮水机闲聊）不是真正的闲聊，而是一种系统化的**实地调研方法论**：

### 情报源金字塔

```
          ★ 竞争对手
         ★★★ 前员工
        ★★★★★ 客户
       ★★★★★★★ 供应商
      ★★★★★★★★★ 行业专家
     ★★★★★★★★★★★ 公司内部人（合规范围内）
```

### 核心技巧

1. **提开放性问题**：不要问"你们公司文化好吗"，要问"你们最近的重大项目是怎么决策的"
2. **三角交叉验证**：客户说的和供应商说的对得上吗？前员工和现任说的矛盾吗？
3. **关注细节**：费雪会问 "你们竞争对手最近三个月有什么变化？" —— 细节比大方向更有价值
4. **长期跟踪**：一次访谈不够。费雪对一家公司会持续跟踪数年

### A 股版本的 Scuttlebutt

在 A 股市场做 Scuttlebutt 可以简化为：

| 渠道 | 能问什么 |
|------|---------|
| **公司公告/年报** | 管理层讨论、风险因素、研发进展 |
| **互动易/上证e互动** | 观察管理层对投资者问题的响应质量 |
| **券商研报** | 行业专家观点、上下游调研纪要 |
| **行业展会** | 同行怎么评价这家公司 |
| **招聘网站** | 团队扩张速度和薪酬水平 |
| **知乎/雪球** | 前员工和高管访谈记录 |

你不需要面面俱到，但**至少要有 3 个独立的信源交叉验证**。

## 五、费雪 vs 格雷厄姆：两种投资哲学

| 维度 | 格雷厄姆 | 费雪 |
|------|---------|------|
| 核心策略 | 低估价值投资 | 成长股投资 |
| 关注重点 | 当前资产和利润 | 未来增长潜力 |
| 持有期限 | 价格回归即卖出 | 长期持有（"买入并持有"） |
| 分析方式 | 定量为主（PB、PE） | 定性为主（管理、产品） |
| 仓位管理 | 分散（30+ 只） | 集中（少数优秀公司） |
| 卖出条件 | 价格达到内在价值 | 公司基本面恶化 |

**但两者不是对立的。**

巴菲特把两者完美结合了：用格雷厄姆的安全边际做保护，用费雪的成长股框架选好公司。

**我自己的用法**：
- 先用定量指标筛选（格雷厄姆的过滤器）
- 再用 15 点框架做定性评估（费雪的放大镜）
- 最后用 Scuttlebutt 方法交叉验证（费雪的手术刀）

## 六、费雪框架的局限性（诚实地说）

没有框架是完美的。费雪方法有几个明显的短板：

### 1. 极度依赖判断力

15 个问题大多需要主观判断。同样一家公司，A 投资者可能给 Q8 打 8 分，B 投资者可能打 4 分。这意味着**经验积累**是这个方法的瓶颈。

### 2. 对散户门槛高

Scuttlebutt 方法的原型需要大量行业人脉和调研时间。机构投资者的优势巨大。

**折中方案**：散户可以用上文提到的"A 股版 Scuttlebutt"替代——看互动易、研报、招聘数据。

### 3. 不适用于所有行业

费雪的方法是给**成长型制造业和消费品公司**量身定做的。对于金融股（银行、保险）、周期股（钢铁、煤炭）、初创科技公司，需要修正框架。

### 4. 容易高估管理质量

费雪对管理层的信任度加了很多分。在 A 股国有企业的场景下，管理层评估尤其困难——你很难判断 CEO 的决策是主动战略还是执行国家安排。

## 七、实践：用费雪框架分析 A 股的三步法

我建议用这样的流程：

### Step 1：定量粗筛（5 分钟）

用数据排除明显不合格的公司：
- 营收增长率 < 10%（连续 3 年）
- 毛利率逐年下降
- 负债率 > 70%
- ROE < 10%

### Step 2：15 点评分（30 分钟）

针对粗筛通过的公司，逐一回答 15 个问题。每个问题打 1-5 分：
- 1-2 分：严重不合格
- 3 分：中性/不确定
- 4-5 分：优质

**总分 ≥ 50 分**（满分 75）才算通过。

### Step 3：Scuttlebutt 验证（持续进行）

- 看最近 3 期的管理层讨论
- 读 3 篇以上不同券商的深度研报
- 如果条件允许，在互动易上问一个开放性问题
- 加入雪球/股吧讨论组观察投资者情绪

我的经验是：**Step 1 能筛掉 80% 的公司，Step 2 能再筛掉 15%，最终适合深度持有的也就剩 5%。**

---

## 八、总结

费雪的投资哲学可以用一句话总结：

> **买入你足够了解的好公司，然后什么也不做。**

这句话包含了三层意思：

1. **"足够了解"** = 15 点框架 + Scuttlebutt，不是半瓶醋的了解
2. **"好公司"** = 拥有可持续竞争优势、优秀管理层、良好成长性的公司
3. **"什么也不做"** = 长期持有，让时间成为朋友

每次我在分析一只股票时，如果发现自己对上面三条中的任何一条没有把握，我就知道自己还需要继续研究。
