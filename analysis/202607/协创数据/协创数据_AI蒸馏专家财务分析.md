# 协创数据：3年净利涨9倍，股价涨24倍——十倍股藏在AI算力的浪潮里

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

协创数据（300857），云计算基础设施服务商，核心业务是服务器存储和数据存储解决方案。这两年踩中了AI算力爆发的最大风口。从2023年营收46.6亿暴增到2025年122.4亿，净利润从2.9亿飙升到11.5亿。

**2021年至今股价从15元涨到最高355元，涨幅23.7倍。** 在A股所有十倍股中排名第27位（按涨幅排序）。

2025年营收122.36亿，净利润11.52亿。毛利率19.2%，净利率9.4%。

**金融性负债从17.12亿暴增到117.75亿！** 一年增加了100亿借款。这就是协创数据高速扩张的"燃料"——借钱投入固定资产（服务器、数据中心设备）。

有息负债率49.4%——在我分析过的所有公司中排名第二高，仅次于金石资源（39%）...实际上49.4%比金石资源还高！

长期借款从4.10亿飙升到74.83亿（+1727%）。这些钱主要用来建设数据中心和采购服务器设备——对应固定资产从5.6亿膨胀到92.8亿。

**造血占比（六维核心指标）：**
- 造血来源 = 109.36 + 25.96 = 135.32亿
- 输血来源 = 117.75 + 17.88 = 135.63亿
- **造血占比 = 135.32 / (135.32 + 135.63) = 49.95% → 均衡型**

正好在50%的分界线上——一半靠自己（经营性负债+利润积累），一半靠外部（借款+股东入资）。

## 三、利润表分析——爆发式增长的秘密

### 3.1 三年轨迹

| 项目（亿元） | 2023年 | 2024年 | 2025年 |
|:---|:---:|:---:|:---:|
| 营业收入 | 46.58 | 74.10 | **122.36** |
| 营收增速 | — | **+59.1%** | **+65.1%** |
| 营业成本 | 40.26 | 61.24 | 98.82 |
| **毛利润** | **6.32** | **12.86** | **23.54** |
| 毛利率 | **13.6%** | **17.4%** | **19.2%** |
| 销售费用 | 0.19 | 0.32 | 0.61 |
| 管理费用 | 0.89 | 1.34 | 1.46 |
| 财务费用 | 0.004 | -0.09 | 3.17 |
| **营业利润** | **3.16** | **7.87** | **12.45** |
| **净利润** | **2.86** | **6.87** | **11.52** |
| 净利率 | 6.1% | 9.3% | **9.4%** |

**三年营收CAGR 62%，净利CAGR 100%。** 净利增速远高于营收增速——规模效应在释放。

**毛利率连续三年提升：** 13.6%→17.4%→19.2%。在营收高速增长的同时还能提毛利率——说明产品有竞争力，不是靠降价抢份额。

**财务费用从-0.09亿变成3.17亿：** 借款增加了100亿，利息支出自然大幅上升。2025年仅利息就是3.17亿，占净利润的27.5%。

### 3.2 核心利润

核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用

**核心利润 = 122.36 - 98.82 - 0.61 - 1.46 = 21.47亿**
**核心利润率 = 17.5%**

核心利润率17.5%——在制造业中属于中等偏上水平。但比天孚通信（51%）、安集科技（50%）、新易盛（46%）低很多。

## 五、三大匹配检查

### 匹配①：固定资产→营收

2023年：46.58/3.81 = **12.2**（产能极高效——轻资产阶段）
2024年：74.10/5.57 = **13.3**（仍高效）
2025年：122.36/92.83 = **1.32**（骤降——重资产阶段）

2025年固定资产暴增20倍，但营收只增了65%。新投入的产能还没有完全释放。等在建工程27.59亿投产后，营收还有增长空间，但匹配效率在短期内会继续偏低。

### 匹配②：营收→核心利润

核心利润率**17.5%**——属于"中转化"。

### 匹配③：核心利润→OCF

11.00/21.47 = **0.51**——现金实现"中偏弱"。

**综合诊断：** 匹配①从高效骤降到低效（扩张期特征）、匹配②中等、匹配③偏弱。典型的"借钱扩张期"——资产的产能效应尚未完全释放，现金被存货和应收占用。

## 六、六维度综合诊断

### 维度一：资产质量 —— ★★★☆☆

总资产238亿，固定资产93亿占39%。资产结构在从"轻"到"重"的转型期。在建工程28亿还有待释放。货币资金24亿对比短期借款43亿——流动性偏紧。

### 维度二：利润质量 —— ★★★★☆

三年净利CAGR 100%，毛利率持续提升，2026Q1还在加速。利润质量好——增长不是"昙花一现"。

### 维度三：现金流质量 —— ★★☆☆☆

OCF 11亿是净利润的0.96倍——勉强及格。但扩张完全靠借款，自主造血能力不足。

### 维度四：偿债能力 —— ★★☆☆☆

有息负债率49.4%，借款118亿是现金24亿的5倍。2025年利息支出3.17亿，占净利润的28%。如果利率上升或银行缩贷，偿债压力会很大。

### 维度五：成长性 —— ★★★★★

三年营收CAGR 62%，净利CAGR 100%。2026Q1营收+193%、净利+344%——增速在A股属于顶级。

### 维度六：风险 —— ★★☆☆☆

核心风险：高负债率（49%）、借款远大于现金、利息支出快速上升、固定资产大幅扩张后的产能消化。一旦AI算力需求放缓，营收增速下降叠加高额利息，利润会快速收缩。

---

## 七、综合诊断

协创数据是典型的"高弹性高杠杆"十倍股——上涨时弹性极大（3年23.7倍），但也意味着在行业下行时跌幅同样剧烈。和海光信息、寒武纪同属一个类型。

**用六维框架做个总结：**

| 标签 | 结果 |
|:---|:---|
| 资产结构 | **中→重资产**（39%固资，扩张期） |
| 资本结构 | 均衡型（50%） |
| 杠杆 | **高杠杆（49%）** |
| 毛利率 | 中毛利（19%） |
| 现金流 | 现金正常（OCF/净利0.96） |
| 成长性 | **爆发增长（CAGR 100%）** |
| 三大匹配 | 产能骤降（扩张期） + 中转化 + 现金偏弱 |
| **综合评级** | **中等偏良**（高成长+高杠杆的对冲） |

**好的方面：** 三年营收CAGR 62%、净利CAGR 100%、毛利率持续提升、2026Q1还在加速（+344%）。

**不足的方面：** 有息负债率49.4%、借款118亿是现金的5倍、利息吃掉28%的利润、OCF勉强覆盖净利。
