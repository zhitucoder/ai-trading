# 金石资源：萤石龙头毛利率18%，借款30亿是现金的5.5倍——矿企的苦日子

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

金石资源（603505），中国最大的萤石（氟化钙）矿企，萤石资源储量全球前列。萤石是氟化工的源头——从制冷剂到锂电池电解质（六氟磷酸锂），整个氟化工产业链都离不开它。

但和之前分析的公司完全不同：它不是高毛利的科技公司，也不是爆发式增长的光模块企业——它是一家**重资产、高负债、低毛利**的矿业公司。和天孚通信、新易盛那種"轻资产、高毛利"形成了两个极端。

2025年营收38.88亿，净利润3.62亿（归母3.26亿）。毛利率17.8%，净利率9.3%。有息负债率39%。

用我分析中国铝业时的话说：**矿企的宿命就是高投入、慢回报、看天吃饭。**

和光模块三剑客（有息负债率0%）相比，金石资源的杠杆率高得惊人。

**借款29.54亿 vs 现金5.46亿——现金只够覆盖借款的18.5%。** 净负债（借款-现金）24.08亿。

**为什么借这么多钱？** 矿业公司需要不断勘探、开矿、建选厂——这些都是烧钱的事。萤石矿的开采周期长、前期投入大。金石资源这几年在扩大产能，资本开支很大。

经营性负债20.09亿（主要是应付账款），说明在产业链上还有一定的占款能力。但主要资金来源还是靠借款。

利润积累10.64亿，比股东入资8.45亿略高。但增速太慢了——2024年10.92亿，2025年10.64亿，还下降了——因为2025年利润积累的速度跟不上分红/其他调整。

## 三、利润表分析——低毛利、高费用、薄利润

### 3.1 三年轨迹

| 项目（亿元） | 2023年 | 2024年 | 2025年 |
|:---|:---:|:---:|:---:|
| 营业收入 | 18.96 | 27.52 | **38.88** |
| 营收增速 | — | **+45.1%** | **+41.2%** |
| 营业成本 | 12.40 | 21.73 | 31.94 |
| **毛利润** | **6.56** | **5.79** | **6.94** |
| 毛利率 | **34.6%** | **21.1%** | **17.8%** |
| 销售费用 | 0.08 | 0.10 | 0.15 |
| 管理费用 | 1.16 | 1.45 | 1.78 |
| 财务费用 | 0.35 | 0.72 | 1.13 |
| 投资收益 | 0.64 | 0.86 | 1.56 |
| **营业利润** | **4.56** | **3.00** | **4.24** |
| **净利润** | **3.76** | **2.55** | **3.62** |
| 归母净利润 | 3.49 | 2.57 | 3.26 |
| 净利率 | 19.8% | 9.3% | **9.3%** |

营收从18.96亿增长到38.88亿（两年翻倍），但净利润从3.76亿降到3.62亿——**营收翻倍，利润原地踏步。**

为什么？

**毛利率下降是核心问题。** 毛利率从34.6%暴跌到17.8%，三年降了17个百分点。

什么意思呢？2023年每卖100块钱萤石产品能赚34.6块毛利，2025年只能赚17.8块。萤石价格在下跌或者成本在上升——更可能是两种情况同时发生。萤石价格在2022年见顶后持续走弱，而采矿成本（人工、能源、环保）在持续上升。

财务费用从0.35亿飙升到1.13亿——多借了钱，利息自然多了。

投资收益1.56亿是个亮点——占营业利润的37%。但这部分不是主业赚的，是投资赚的。如果扣掉投资收益，核心业务的盈利能力更弱。

结果就是：营收翻倍，但净利率从19.8%跌到9.3%，净利润原地踏步。

### 3.2 核心利润

核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用

**核心利润 = 38.88 - 31.94 - 0.15 - 1.78 = 5.01亿**
**核心利润率 = 12.9%**

核心利润5.01亿，是净利润3.62亿的1.38倍。差额约1.39亿主要来自：财务费用1.13亿、所得税0.52亿、投资收益1.56亿（增加了利润）、少数股东损益0.36亿。

核心利润率12.9%——和天孚通信（51%）、新易盛（46%）相比差距巨大。矿业公司的利润空间就是这么薄。

## 五、关键风险

### 风险1：毛利率持续下降

毛利率从34.6%到17.8%，三年跌了一半。萤石价格受下游需求（制冷剂、新能源）和供给（新增矿山）的双重影响，如果价格继续下行，利润会进一步压缩。

### 风险2：高负债率

有息负债率39%，借款29.54亿，现金只有5.46亿。如果遇到行业下行期，利息支出会持续侵蚀利润，资金链压力不小。

### 风险3：增收不增利

营收翻倍但利润原地踏步。营业成本增速超过营收增速是核心原因——是成本控制问题还是行业周期问题，需要专业判断。

### 风险4：财务费用快速上升

从0.35亿到1.13亿——三年翻了三倍。如果利率上升或继续增加借款，财务费用还会上升。

### 风险5：利润依赖投资收益

2025年投资收益1.56亿占了37%的营业利润。扣掉投资收益，核心业务利润更薄。

## 六、六维度综合诊断

### 维度一：资产质量 —— ★★☆☆☆

总资产76亿，固定资产+在建35亿占46%，采矿权7亿。资产"重"但符合矿业特征。货币资金仅5.46亿，相对于30亿借款明显偏低。

### 维度二：利润质量 —— ★★☆☆☆

毛利率17.8%偏低，净利率9.3%。毛利率三年降了17个百分点。营收翻倍但利润原地踏步——利润质量在恶化而非改善。

### 维度三：现金流质量 —— ★★★☆☆

OCF 1.34亿是NP 3.62亿的0.37倍——现金转化效率低，但比2023年（0.08倍）有改善。2026Q1 OCF 1.53亿，趋势向好。

### 维度四：偿债能力 —— ★★☆☆☆

有息负债率39%，借款30亿是现金5.46亿的5.5倍。净负债24亿。在目前盈利水平下，偿债能力偏弱。如果行业景气下行，可能出现偿债压力。

### 维度五：成长性 —— ★★★☆☆

营收两年翻倍（+45%/+41%），增速不错。但利润不增长，"伪成长"嫌疑。矿企的成长性取决于萤石价格和储量，不确定性较高。

### 维度六：风险 —— ★★☆☆☆

毛利率持续下滑、高负债率、增收不增利、财务费用上升、利润依赖投资收益。多重风险叠加。

## 七、综合结论

金石资源的财务质量整体评级为**中等偏弱**。和今天分析的其他公司（新易盛、天孚通信）相比，差距是全方位的。

**好的方面：**
1. 萤石行业龙头地位，资源储量有优势
2. 营收两年翻倍，下游需求（新能源、氟化工）在增长
3. 2026Q1现金流改善明显
4. 销售费用率极低（0.4%）——矿企客户关系稳定

**不足的方面：**
1. 毛利率从34.6%跌到17.8%，三年腰斩——核心盈利指标在恶化
2. 借款30亿是现金5.46亿的5.5倍——财务杠杆偏高
3. 营收翻倍但利润不增长——增收不增利
4. 有息负债率39%，利息支出1.13亿持续侵蚀利润
5. 投资收益占营业利润37%，主业盈利能力偏弱

**用我的话讲：面子在恶化（毛利率持续下降），日子有点紧（借款高现金少），底子不算厚（利润积累增长缓慢）。**

金石资源是一家典型的矿业公司——资源有价值，但变现过程漫长、成本高、周期波动大。它的投资逻辑不在财务报表上（报表呈现的更多是行业的艰难），而在萤石资源储量和新能源（氟化工）需求增长的长期故事上。
