# 中际旭创：3年营收涨8倍，净利破百亿——AI光模块"卖铲人"的黄金时代

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

中际旭创（300308），全球最大的光模块供应商之一，核心产品是高速光模块（400G/800G/1.6T），用于AI数据中心的光互联。它是这轮AI基建浪潮中最大的"卖铲人"之一——英伟达、谷歌、亚马逊等云厂商的数据中心，都离不开它的光模块。

和天孚通信（300394）对比：天孚做的是光器件（上游零件），中际旭创做的是光模块整机（更下游、规模更大）。一个做零件、一个做整机——天孚毛利率54%更"肥"，中际旭创营收382亿比天孚大7倍多。

2025年营收382.40亿，净利润115.80亿（归母107.97亿）。毛利率42.0%，净利率30.3%，ROE约41%。经营现金流108.96亿。

从资本结构看：造血（经营性负债+利润积累）= 115.56+205.96 = 321.52亿，占比71%；输血（金融负债+股东入资）= 8.11+92.18 = 100.29亿，占比22%。造血占总负债+权益的71%。

这是一个教科书级别的资本结构——企业靠自身经营能力赚钱、靠利润积累扩张，几乎不需要借钱。

**固定资产70.81亿，占总资产15.6%。** 光模块生产需要投入大量自动化封装和测试设备，这个规模合理。

## 三、利润表分析——爆发式增长的秘密

### 3.1 三年轨迹

| 项目（亿元） | 2023年 | 2024年 | 2025年 |
|:---|:---:|:---:|:---:|
| 营业收入 | 107.18 | 238.62 | **382.40** |
| 营收增速 | — | **+122.6%** | **+60.3%** |
| 营业成本 | 71.82 | 157.96 | 221.66 |
| **毛利润** | **35.36** | **80.66** | **160.74** |
| 毛利率 | **33.0%** | **33.8%** | **42.0%** |
| 销售费用 | 1.25 | 1.99 | 2.26 |
| 管理费用 | 4.34 | 6.80 | 7.61 |
| 财务费用 | -0.84 | -1.44 | 1.83 |
| 投资收益 | 3.23 | -0.33 | 3.79 |
| **营业利润** | **24.94** | **60.50** | **135.97** |
| **净利润** | **22.08** | **53.72** | **115.80** |
| 归母净利润 | 21.74 | 51.71 | 107.97 |
| 净利率 | 20.6% | 22.5% | **30.3%** |

三年营收从107亿到382亿，涨了3.6倍。净利润从22亿到116亿，涨了5.3倍。2026Q1营收195亿（同比增长192%），全年可能冲击700亿——增长还在加速！

最值得关注的变化是**毛利率从33.0%飙升到42.0%**——三年涨了9个百分点。为什么？产品结构升级。AI数据中心对光模块的需求从400G到800G再到1.6T，速率越高、单价越高、毛利越厚。中际旭创在享受"量价齐升"的双重红利。

**销售费用率仅0.6%**——和天孚通信一样，产品供不应求。不需要销售团队。

**管理费用率从4.0%降到2.0%**——规模效应明显。营收涨了3.6倍，管理费用只从4.34亿涨到7.61亿。

### 3.2 核心利润

核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用

**核心利润 = 382.40 - 221.66 - 2.26 - 7.61 = 150.87亿**
**核心利润率 = 39.5%**

核心利润150.87亿，是净利润115.80亿的1.3倍。差额主要来自：财务费用1.83亿、投资收益3.79亿、资产减值损失、少数股东损益7.82亿、所得税20.20亿。

利润率39.5%在制造业中是极高的。每100块钱营收扣除所有经营成本后，还剩39.5块钱——这在A股制造业中属于前5%的水平。

2026Q1经营现金流33.68亿（净利润63.17亿），比值0.53——有所下降，但考虑到营收194.96亿（比2025年一季度翻了近3倍）带来的应收账款和存货占用，这个偏离属于可接受范围。

两者都是AI光模块产业链的优质标的，但中际旭创更依赖下游大客户采购节奏（营收波动更大），天孚通信的技术壁垒更高（毛利率更稳定）。

## 六、六维度综合诊断

### 维度一：资产质量 —— ★★★★☆

总资产453亿，现金110亿占24%，存货127亿偏高但符合行业特征。商誉19亿需要关注但占比不大。整体资产结构健康。

### 维度二：利润质量 —— ★★★★★

毛利率42.0%，净利率30.3%，核心利润率39.5%。利润全部来自主营业务。毛利率三年提升9个百分点——产品结构持续升级。销售费用率0.6%说明产品供不应求。

### 维度三：现金流质量 —— ★★★★★

经营现金流108.96亿，是净利润的0.94倍。现金从51亿增加到110亿。现金流覆盖经营、投资、还债后还有大量结余。

### 维度四：偿债能力 —— ★★★★★

有息负债率1.8%，几乎可以忽略。现金110亿远覆盖总负债137亿。短期借款从14亿降到3亿——还在主动降杠杆。偿债能力满分。

### 维度五：成长性 —— ★★★★★

三年营收CAGR 89%，净利润CAGR 129%。2026Q1营收同比+192%。在A股所有行业中属于顶级。AI光模块的需求增长至少还有2-3年的景气周期。

### 维度六：风险 —— ★★★☆☆

最大风险：AI光模块需求的持续性。英伟达的GPU出货节奏直接影响光模块采购。如果AI资本开支退潮，中际旭创的营收可能断崖式放缓。此外，127亿存货和62亿应收账款在行业下行时可能形成双杀。

## 七、综合结论

中际旭创的财务质量整体评级为**优秀**。三年营收涨3.6倍、净利涨5.3倍，毛利率提升9个百分点，OCF超百亿，有息负债率仅1.8%——这种财务指标组合在A股极其罕见。

**好的方面：**
1. 营收382亿、净利116亿——AI光模块"卖铲人"的头号赢家
2. 毛利率从33%到42%——"量价齐升"逻辑正在兑现
3. 经营现金流109亿，现金110亿——造血能力极强
4. 有息负债率1.8%，几乎零债务风险

**不足的方面：**
1. 存货127亿占营收33%——如果需求放缓，跌价风险高
2. 商誉19亿——来自历史并购整合
3. 营收波动风险——高度依赖AI数据中心资本开支周期

**用我的话讲：面子非常好看（利润破百亿），日子非常宽裕（现金流百亿），底子极其扎实（造血是输血的三倍）。**

但和天孚通信一样，财务质量优秀不等于投资风险低。中际旭创的财报反映的是**AI基建浪潮的最高潮**。只要AI军备竞赛继续，它的好日子就能继续；如果潮水退去，它的财务面会以同样快的速度反转。这个问题，三张报表回答不了。
