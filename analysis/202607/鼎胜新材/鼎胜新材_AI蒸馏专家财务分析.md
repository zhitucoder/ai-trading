# 鼎胜新材：263亿营收净利5亿，毛利率9%——电池箔"赌周期"的薄利扩张

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

鼎胜新材（603876），国内电池铝箔龙头。主要产品是电池箔（锂电池正极集流体）、容器箔（食品包装）和空调箔。客户包括宁德时代、比亚迪等头部电池厂。

铝箔行业的本质是**加工制造**——从上游电解铝厂买铝锭（或铝板带），加工成不同规格的铝箔，赚取加工费差价。毛利率天然薄（9-16%），利润对铝价波动和下游需求高度敏感。

2022年是鼎胜新材的峰值年——营收216亿、净利13.8亿（毛利率16.2%）。之后毛利率持续下滑，2025年营收263亿但净利仅5.1亿（毛利率9.0%）。

**用一句话概括：营收在涨、毛利在降、利润大幅波动——典型的周期型加工制造业。**

**鼎胜新材的五年可以用''一波三折''来形容：**

**2022年峰值：** 电池箔供不应求，毛利率冲到16.2%，净利13.8亿。当时新能源汽车销量爆发式增长，电池厂抢购铝箔，加工费高企。

**2023-2024年下行：** 竞争对手扩产、供需关系逆转，毛利率从16%暴跌到9%，净利从13.8亿缩水到3.0亿——**一年时间利润缩水80%。**

**2025年企稳：** 营收263亿创历史新高，但毛利率仅9%，净利5.1亿。营收涨了但利润没涨。

### 3.2 核心利润

核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用

**核心利润 = 263.03 - 239.30 - 1.80 - 3.19 = 18.74亿**
**核心利润率 = 7.1%**

核心利润18.74亿，是净利润5.14亿的3.6倍。差额约13.6亿主要来自：财务费用0.87亿、投资收益亏损1.03亿、资产减值损失（估计数亿）、所得税1.40亿。

核心利润率7.1%在制造业中偏低——每100块营收只有7块钱的经营利润。

## 五、三大匹配检查

### 匹配①：固定资产→营收

263.03 / 72.23 = **3.64**

每1亿固定资产支撑3.64亿营收。对于铝箔加工行业来说，这个效率属于中等偏上。

### 匹配②：营收→核心利润

核心利润率**7.1%**——属于"弱转化"。毛利率本来就低（9%），扣除费用后利润率更薄。

### 匹配③：核心利润→OCF

12.72 / 18.74 = **0.68**——"现金实现中"。OCF 12.72亿虽然只有核心利润的68%，但考虑到存货和应收占款，这个水平在制造企业中不算差。

**综合诊断：** 匹配①中等、匹配②偏弱、匹配③中等。和云天化（匹配①0.95/②20%/③1.65x）相比全方位落后——鼎胜新材的资产效率和盈利能力都不如云天化。

## 六、六维度综合诊断

### 维度一：资产质量 —— ★★★☆☆

总资产235亿，现金49亿占21%，流动性尚可。固定资产72亿占31%，是典型的重资产制造企业。存货42亿和应收39亿合计占资产34%——营运资金占用偏高。

### 维度二：利润质量 —— ★★☆☆☆

毛利率9%、净利率2%、核心利润率7%。营收263亿但净利仅5亿——典型的"大营收小利润"。利润高度依赖铝箔加工费的水平，2022年净利13.8亿和2024年净利3.0亿的差距说明利润波动极大。

### 维度三：现金流质量 —— ★★★★☆

OCF 12.72亿是净利润的2.47倍。虽然利润薄，但现金流还算扎实——主要原因是折旧和摊销等非现金支出较大。**利润是薄的，现金是实的。**

### 维度四：偿债能力 —— ★★★☆☆

有息负债率24.9%，借款58.57亿。现金48.92亿不足以覆盖全部借款。经营性负债占比高（56%）是好事，但金融性负债近60亿——每年利息0.87亿，相当于净利的17%。

### 维度五：成长性 —— ★★★☆☆

营收从182亿增长到263亿（5年+45%），增速不算慢。但净利润从13.8亿跌到5.1亿——**有营收增长无利润增长**。电池箔行业进入成熟期，产能过剩+价格战是增长的主要制约。

### 维度六：风险 —— ★★☆☆☆

主要风险：①铝箔加工费持续低迷、②竞争对手扩产加剧价格战、③借款59亿的利息负担、④存货41亿的跌价风险、⑤铝价波动对毛利率的影响。

## 七、综合诊断

鼎胜新材是一家典型的**周期型加工制造企业**——赚的是加工费的辛苦钱，利润随行业景气度大幅波动。

**大的方面：**
1. 营收263亿、OCF 12.7亿——经营规模扎实，现金流含金量高
2. 造血占比65%——靠产业链占款能力维持经营
3. 电池箔龙头地位——在宁德时代、比亚迪等客户的供应链中有一定话语权
4. 2026Q1净利+127%——利润弹性开始释放，可能是周期底部的信号

**不足的方面：**
1. 毛利率9%、净利率2%——极度薄利，营收的含金量很低
2. 借款59亿、利息0.87亿——债务负担不轻
3. 净利从13.8亿到3.0亿到5.1亿——波动剧烈，缺乏稳定性
4. 应收39亿+存货42亿——营运资金占用大
5. 行业产能过剩——竞争对手（南山铝业、常铝股份等）都在扩产

**用六维做个总结：**

| 维度 | 结果 | 评价 |
|:---|:---|:---:|
| 资产质量 | 重资产+高应收+高存货 | ★★★☆☆ |
| 利润质量 | 毛利率9%、净利率2%、波动剧烈 | ★★☆☆☆ |
| 现金流质量 | OCF/净利2.47x，含金量尚可 | ★★★★☆ |
| 偿债能力 | 有息负债率25%、现金<借款 | ★★★☆☆ |
| 成长性 | 营收增长但利润不增 | ★★★☆☆ |
| 风险 | 加工费下行、产能过剩、高负债 | ★★☆☆☆ |
| **综合** | **中等** | |

**AI蒸馏专家标签：** 重资产（31%）+ 造血型（65%）+ 中杠杆（25%）+ 低毛利（9%）+ 现金牛（OCF/净利2.47x） + 增收不增利 — **综合：中等**

鼎胜新材是一家"看天吃饭"的公司。2022年行业景气时赚13.8亿，2024年低谷时赚3亿——五年间利润差了4.6倍。对于周期型公司，核心不是看它过去赚了多少，而是判断当前的周期位置——2026Q1净利+127%能不能持续，决定了这家公司是"底部反转"还是"昙花一现"。
