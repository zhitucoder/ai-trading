# 北方华创：营收393亿净利54亿，存货286亿——半导体"一哥"的增长烦恼

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

北方华创（002371），中国最大的半导体设备平台型企业。产品线覆盖刻蚀、薄膜沉积、氧化扩散、清洗、检测等主要半导体制造环节，是国内半导体设备品类最全的公司。

和盛美上海（专注清洗设备）不同，北方华创是"全能选手"——产品线最宽，营收规模最大。用我的话说，盛美上海是做"专科"的，北方华创是做"三甲综合医院"的。

2025年营收393.53亿，净利润54.09亿。毛利率40.1%，净利率13.7%。

但有一个关键问题需要正视：**营收增长32%，但净利润下降了5%。** 这种"增收不增利"在制造业是一个危险信号。

## 三、利润表分析——增收不增利

### 3.1 三年轨迹

|:---|:---:|:---:|:---:|
| 营业收入 | 220.79 | 298.38 | **393.53** |
| 营收增速 | — | **+35.1%** | **+31.9%** |
| 营业成本 | 130.05 | 170.51 | 235.71 |
| **毛利润** | **90.74** | **127.87** | **157.82** |
| 毛利率 | **41.1%** | **42.9%** | **40.1%** |

| 管理费用 | 17.52 | 21.11 | 34.33 |
| 财务费用 | -0.18 | 0.60 | 2.29 |
| **营业利润** | **44.48** | **65.27** | **58.02** |
| **净利润** | **40.33** | **56.94** | **54.09** |
| 归母净利润 | 38.99 | 56.21 | 55.22 |
| 净利率 | 18.3% | 19.1% | **13.7%** |

关键变化：

**营收增长32%，但净利润下降5%。** 为什么？

看费用：销售费用从10.85亿到16.36亿（+51%），管理费用从21.11亿到34.33亿（+63%）。两项费用增速都远超营收增速（32%）。

同时，毛利率从42.9%降到40.1%（-2.8个百分点）。在营收增长的情况下毛利率下降——说明产品结构在变化，低毛利产品占比在提升，或者整体产品在降价。

结果就是：营收增加了95亿，但毛利润只增加了30亿，费用增加了19亿，最后营业利润反而从65亿降到了58亿。

### 3.2 核心利润

核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用

**核心利润 = 393.53 - 235.71 - 16.36 - 34.33 = 107.13亿**
**核心利润率 = 27.2%**

核心利润107.13亿，是净利润54.09亿的1.98倍。差额53亿主要来自：研发费用（估计40-50亿）、资产减值损失、财务费用2.29亿、所得税4.36亿、少数股东损益-1.13亿。

核心利润率27.2%，比天孚通信（51%）和中际旭创（39.5%）低不少，反映了半导体设备行业竞争更激烈、费用更重的特点。

## 四、关键风险信号

### 风险1：增收不增利

营收增长32%但净利下降5%，这是最核心的问题。毛利率下降、费用率上升，挤压了利润空间。半导体设备行业的竞争正在加剧。

### 风险2：存货高企

存货286亿，占总资产32%，占营收73%。一旦需求放缓，减值风险极大。

### 风险3：杠杆率上升

长期借款从39亿增加到130亿（+233%）。公司正在通过加杠杆来支撑扩张。2025年利息费用从0.6亿升到2.29亿。

### 风险4：商誉和无形资产暴增

商誉从0.38亿飙升到23.86亿——2025年进行了大规模并购。并购的整合效果和商誉减值风险需要跟踪。无形资产105亿也需要关注减值。

### 风险5：现金流持续低于利润

OCF/净利比三年平均约0.4。存货和应收持续占用资金，现金转化效率低。

### 风险6：利润增速远低于营收增速

行业进入"内卷"阶段。营收还在增长，但利润已经在下滑。如果行业周期下行，利润可能面临更大压力。

## 六、六维度综合诊断

### 维度一：资产质量 —— ★★★☆☆

总资产898亿，现金173亿占19%，现金充裕。但存货286亿占比过高（32%），无形资产105亿和商誉24亿也需要关注。资产规模大但质量参差。

### 维度二：利润质量 —— ★★★☆☆

毛利率40.1%，核心利润率27.2%——产品本身能赚钱。但"增收不增利"（营收+32%、净利-5%）是核心问题。利润质量在恶化而非改善。

### 维度三：现金流质量 —— ★★☆☆☆

OCF 21.33亿，是净利润的0.39倍。和盛美上海一样是行业通病。但2026Q1的OCF从-17.29亿改善到+7.48亿，方向上是对的。

### 维度四：偿债能力 —— ★★★☆☆

有息负债率14.8%（从6%跃升），长期借款增加90亿。现金173亿覆盖总负债458亿——短期没问题，但杠杆上升趋势需要关注。如果利润持续下滑，债务压力会越来越大。

### 维度五：成长性 —— ★★★☆☆

营收CAGR约33%，增速不错。但利润不增长甚至下滑，成长的质量存疑。真正健康的增长应该是利润随营收同步增长，而不是"赔本赚吆喝"。

### 维度六：风险 —— ★★☆☆☆

多重风险叠加：增收不增利、存货高企、商誉暴增、杠杆上升、现金流低于利润。半导体设备竞争加剧，利润空间被压缩是长期趋势。

## 七、综合结论

北方华创的财务质量整体评级为**中等偏好**。作为中国最大的半导体设备平台，它的规模和行业地位毋庸置疑。但当前财务状况存在几个不能忽视的问题。

**好的方面：**
1. 营收393亿，是中国半导体设备公司的绝对龙头
2. 毛利率40.1%尚可，核心利润107亿说明经营基本面还是扎实的
3. 现金173亿，短期资金链无忧
4. 2026Q1 OCF明显改善（+7.48亿 vs 去年同期-17.29亿）

**不足的方面：**
1. **增收不增利**——营收+32%但净利-5%，这是最大的问题
2. 存货286亿占营收73%——资金沉淀严重，跌价风险高
3. 长期借款从39亿暴增到130亿——杠杆在快速上升
4. 商誉从0.38亿飙到24亿——2025年大规模并购带来整合风险
5. 净利润率从19.1%降到13.7%——盈利能力在恶化

**用我的话讲：面子还过得去（龙头地位、营收高增长），日子有点紧（现金流只有利润的四成），底子在加杠杆扩张的路上（长期借款大增）。**

北方华创和盛美上海身上有同一个行业烙印——半导体设备行业的"高存货、长周期、慢回款"特征。这个特征在经济上行期问题不大，但在行业增速放缓时，存货跌价和现金流压力会集中爆发。当前两家公司都出现了增速放缓和现金流偏弱的信号，需要警惕。
