# 华虹宏力：总资产1000亿，营收173亿——晶圆代工"老二"的六维财务诊断

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

华虹宏力（688347），中国大陆第二大晶圆代工厂，仅次于中芯国际。工艺覆盖55nm到28nm（以成熟制程为主），主要服务国内芯片设计公司。

和中芯国际一样——重资产、高折旧、低毛利率、靠大额融资活着。但华虹比中芯国际更"惨"——中芯国际2025年净利72亿，华虹却还在亏损。

2025年营收172.91亿，合并净亏损8.07亿。不过**母公司（归母）净利润3.77亿**——因为把12亿亏损"分配"给了少数股东。

## 二、资产负债表重构——千亿资产的"巨人"

### 2.1 右边结构

| 项目 | 2025年末（亿元） | 占比 |
|:---|:---:|:---:|
| 经营性负债 | ~130.47 | 13.0% |
| 长期借款 | **195.90** | **19.6%** |
| 金融性负债合计 | **195.90** | **19.6%** |
| 股本+资本公积 | **400.31** | **40.0%** |
| 利润积累 | 36.44 | 3.6% |
| **少数股东权益** | **179.34** | **17.9%** |

**造血占比（六维核心指标）：**
- 造血来源 = 130.47 + 36.44 = 166.91亿
- 输血来源 = 195.90 + 400.31 = 596.21亿
- **造血占比 = 166.91 / (166.91 + 596.21) = 21.9% → 输血型**

10份钱里只有2份是自己赚的，8份靠融资和借款。和华虹宏力一样，中芯国际也是输血型（33%）。这是晶圆代工行业的共同宿命——每一座晶圆厂投资200-500亿，靠自身利润根本攒不够。

少数股东权益179.34亿占权益的28%。这是因为华虹宏力的核心子公司（华虹半导体、华虹制造等）有大量战略投资者参股。

## 三、利润表分析——合并亏损，归母微利

### 3.1 三年轨迹

| 项目（亿元） | 2023年 | 2024年 | 2025年 |
|:---|:---:|:---:|:---:|
| 营业收入 | 162.32 | 143.88 | **172.91** |
| 毛利率 | **26.9%** | **17.5%** | **18.7%** |
| 营业利润 | 11.78 | -9.89 | -6.52 |
| 净利润（合并） | 8.47 | **-10.32** | **-8.07** |
| 归母净利润 | 19.36 | 3.81 | 3.77 |
| 少数股东损益 | -10.89 | -14.13 | -11.84 |

**最值得关注的是"归母为正、合并为负"的结构。** 2025年合并亏损8.07亿，但归母净利3.77亿——11.84亿的亏损被少数股东"吸收"了。这不是正常的经营表现，而是子公司亏损大于母公司本部的信号。

### 3.2 核心利润

核心利润 = 172.91 - 140.54 - 0.78 - 8.48 = **23.11亿**
核心利润率 = **13.4%**

但营业利润是-6.52亿——核心利润和营业利润差了约30亿，主要来自资产减值损失和折旧（晶圆厂的高额折旧被摊入营业成本）。

## 五、三大匹配检查

### 匹配①：固定资产→营收

172.91 / 324.39 = **0.53**

每1亿固定资产只产生0.53亿营收。和中芯国际（0.49）属于同一水平——"产能低效"是晶圆代工行业的常态。

### 匹配②：营收→核心利润

核心利润率**13.4%**——"弱转化"。毛利率18.7%本身就低，再扣除管理费用和折旧后，利润空间极小。

### 匹配③：核心利润→OCF

50.65 / 23.11 = **2.19**——"现金实现强"。但这是折旧堆出来的，不是经营效率改善带来的。

**综合诊断：** 匹配①②③的结果和中芯国际几乎一模一样（0.49/10.7%/2.79x）——重资产行业的财务特征高度一致。

## 六、六维度综合诊断

### 维度一：资产质量 —— ★★★☆☆

总资产1000亿，现金353亿占35%，账上不缺钱。但固定资产324亿+在建工程待完成，资产很重。商誉不详但比例不高。

### 维度二：利润质量 —— ★★☆☆☆

合并口径连续两年亏损。毛利率18.7%在行业中偏低。归母净利3.77亿是靠少数股东"背锅"才为正——不是真正的盈利。

### 维度三：现金流质量 —— ★★★★☆

OCF 50.65亿，合并亏损但现金流充裕。折旧贡献了大部分现金流。在晶圆代工行业中属于正常水平。

### 维度四：偿债能力 —— ★★★☆☆

有息负债率19.6%（仅指长期借款，短期借款基本为零）。现金353亿覆盖长期借款196亿有余。但造血占比仅22%，长期偿债能力依赖再融资。

### 维度五：成长性 —— ★★★☆☆

营收从162亿降到144亿再回升到173亿——波动大但趋势不好。2026Q1营收46.3亿（+18%），正在缓慢复苏。

### 维度六：风险 —— ★★☆☆☆

核心风险：合并亏损持续、行业产能过剩（成熟制程）、少数股东承担大量亏损不可持续、巨额折旧持续侵蚀利润。和中芯国际一样的风险，但华虹的规模更小、抗风险能力更弱。
