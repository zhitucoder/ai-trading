# 汇顶科技：账上59亿现金几乎零负债，毛利率42%——从指纹识别龙头到"现金牛"的转型

> 分析日期：2026年7月 | 数据基准：2025年年报 + 2026Q1

---

## 一、基本画像

汇顶科技（603160），曾经A股最牛的指纹识别芯片公司。2019年是十倍股明星，市值一度超千亿。但随着智能手机市场饱和+竞争加剧，2020-2022年业绩大幅下滑。

现在的汇顶科技正处于**转型期**——从单一的指纹识别芯片向IoT芯片、安全芯片、触控芯片等多元化方向拓展。

但2026年一季度营收9.69亿（-8.95%），净利润1.17亿（-40%）——转型的阵痛还在持续。截至7月底未发布2026年中报业绩预告，通常随8月半年报一起披露。

2025年全年营收47.36亿，净利润8.37亿。

这家公司的最大亮点不在增长而在**财务安全**——账上59亿现金类资产，有息负债率仅0.9%。

## 二、资产负债表重构——A股最"干净"的报表之一

### 2.1 右边结构

| 项目 | 2025年末（亿元） | 占比 |
|:---|:---:|:---:|
| 经营性负债 | ~16.24 | 14.7% |
| 短期借款 | 1.05 | 0.9% |
| 长期借款 | **0** | **0%** |
| **金融性负债合计** | **1.05** | **0.9%** |
| 股本+资本公积 | 26.49 | 23.9% |
| 利润积累 | **71.97** | **65.1%** |
| 少数股东权益 | 0.00 | 0.0% |

**造血占比：**
- 造血来源 = 16.24 + 71.97 = 88.21亿
- 输血来源 = 1.05 + 26.49 = 27.54亿
- **造血占比 = 88.21 / (88.21 + 27.54) = 76.2% → 造血型**

利润积累71.97亿是股东入资26.49亿的2.7倍——公司历史上赚的钱远超股东投入的钱。

### 2.2 左边结构

| 项目 | 2025年末（亿元） | 占比 |
|:---|:---:|:---:|
| 货币资金 | **34.93** | **31.6%** |
| 交易性金融资产 | **24.13** | **21.8%** |

对于一家年营收47亿的公司来说，净现金58亿相当于1.2年的营收。现金充裕到"不知道往哪花"的程度。

营收增长缓慢（3年CAGR仅3.6%），但利润在恢复。毛利率稳定在40%以上——芯片设计公司的典型特征。

**核心利润 = 47.36 - 27.37 - 1.81 - 1.80 = 16.38亿**
**核心利润率 = 34.6%**
