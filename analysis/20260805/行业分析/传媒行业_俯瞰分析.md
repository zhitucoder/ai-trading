# 传媒行业俯瞰分析 — 张新民视角

> **免责声明**：我以张新民教授的财务报表分析框架来俯瞰这个行业。以下分析基于公开财务数据（2023-2025年年报及2026年一季报）和公开行业数据（中国音数协、国家新闻出版署、灯塔专业版等），所有数字均可追溯至年报、季报和行业统计。分析归分析，买卖是你自己的决策。

## 一、传媒行业：一门"内容+流量+IP"的生意

传媒行业覆盖的生意很多样：游戏、影视、广告、出版、广电、数字媒体、潮玩IP。但它们有一个共同点——**卖的是"内容"和"注意力"**。

从财务视角看，传媒行业有几个独特的属性：

1. **轻资产、高毛利（内容端）**：游戏、影视、出版的核心资产是IP和版权，不是厂房设备——一旦做出爆款，毛利率可以到60-90%（游戏）；但内容有"赌爆款"的属性，波动极大。
2. **广告是"经济的温度计"**：广告营销是顺周期行业，企业敢花钱打广告=经济预期好。
3. **政策是最大变量**：游戏版号、内容审查、教辅政策，任何一个政策变化都直接改变行业格局。
4. **AI正在改写游戏规则**：AI长片获证、AI漫剧起量、GEO重塑营销——传媒是AI应用落地最快的行业之一。

**看传媒行业，第一张表看子板块分化（游戏景气 vs 影视低迷），第二张表看商誉和现金流（爆款游戏攒现金、烂影视留商誉）。**

## 二、整体格局：2025年复苏，2026年分化

| 维度 | 2025年 | 2026年至今 |
|------|--------|-----------|
| 板块表现 | 申万传媒+27.17%（跑赢沪深300） | 年初至今约-25%（大幅回调） |
| 业绩 | 前三季度营收3874.8亿创历史新高，归母+37.12%反转 | Q1游戏、广告业绩突出，影视院线大幅下滑 |
| 估值 | PE约27-38倍（5年56-68%分位） | PE低于2018年以来均值（7月） |

**核心判断**：2025年传媒在DeepSeek带动的AI行情+游戏复苏下大涨，2026年高位回调。但**回调不等于基本面恶化——是"主题退潮、业绩分化"**。游戏板块2026H1持续高景气（客户端游戏+27.92%、小程序游戏+36.01%），影视院线则因高基数大幅下滑（2026票房-35%）。

## 三、六大子板块全景：冰火两重天

### 1. 游戏：全行业最亮眼的板块

| 指标 | 2025年 | 2026年 |
|------|--------|--------|
| 板块营收 | 1149.19亿（+23.0%） | 2026Q1：321.55亿（+20.34%） |
| 板块归母 | 136.84亿（**+222.16%**） | 2026Q1：53.74亿（+54.32%） |
| 毛利率 | 68.52%（+2.12pct） | 70.76%（+3.74pct） |

- **版号常态化**：2026年1-7月发放1147款（7月197款创年内新高）——供给端持续释放。
- **市场增长**：2026Q1游戏市场971.72亿（+13.38%）；客户端游戏H1 452.88亿（+27.92%）、小程序游戏316.57亿（+36.01%）。
- **出海强劲**：6月38家中国发行商进全球前100，收入20.6亿美元占41.6%。
- **AI降本增效**：AI在研发、素材、买量全流程提效。
- **中报预告**：世纪华通、巨人网络、恺英网络、吉比特利润同比增。

**游戏是传媒里基本面最扎实的板块——版号常态化+出海+AI提效三驱动，业绩确定性最高。**

### 2. 影视院线：爆款依赖症，高波动

| 指标 | 2025年 | 2026年 |
|------|--------|--------|
| 板块营收 | 392.82亿（+9.93%） | 2026Q1：79.86亿（**-43.42%**） |
| 板块归母 | -10.54亿（收窄58%） | 2026Q1：1.15亿（**-95.13%**） |

- 2025年靠光线《哪吒2》爆款拉动（光线归母16.72亿，同比+472%）。
- **2026年票房1-7月203.13亿（-35.20%）**——高基数+内容供给不足，影视是最典型的"看天吃饭"板块。

**影视是"赌爆款"的生意——一年一部哪吒就能改变一家公司的利润表，没有爆款就是深亏。财务上波动极大，不适合用线性思维。**

### 3. 广告营销：体量大、毛利薄

| 指标 | 2025年 | 2026年 |
|------|--------|--------|
| 板块营收 | 1753.18亿（+7.62%） | 2026Q1：448.82亿（+17.08%） |
| 板块归母 | 15.77亿（**-55.55%**） | 2026Q1：22.28亿（+50.97%） |
| 净利率 | 0.92% | 5.05% |

- **蓝色光标**（营收686.93亿）一家占板块近40%营收，但净利率仅0.7%——营销代工的宿命。
- **分众传媒**是例外：营收127.59亿、归母29.46亿、净利率23%、经营现金流72亿——**广告里的"茅台"**（梯媒垄断）。
- AI重塑：GEO（生成式引擎优化）成为新赛道，蓝色光标BlueAI平台。

**广告板块"大而薄"——除了分众这种垄断型梯媒，大部分营销公司是"替客户花钱赚1-2%服务费"的苦生意。**

### 4. 出版：防御性红利

- 2025年营收1310.82亿（-8.55%）、归母132.59亿（+3.47%）——**营收降、利润增**（教辅+税收优惠）。
- 中南传媒、凤凰传媒：营收120-136亿、归母15-18亿、负债率34-36%、零借款——**典型的高股息防御资产**（但2026Q1业绩承压，归母-15%）。
- 出版板块估值最低，靠分红和教辅稳定性防御。

### 5. 广播电视：持续亏损

广电（有线电视）用户流失、收入下滑，板块归母延续亏损——**夕阳行业，被互联网和流媒体替代。**

### 6. 数字媒体：芒果的"独苗"地位

芒果超媒（138亿营收、12.27亿归母）是A股长视频平台代表，但2025年归母-32%（广告承压+内容成本），2026Q1进一步下滑——**长视频的盈利模式依然艰难。**

## 五、财务共性：传媒的"三条财务铁律"

### 1. 轻资产高毛利，但"爆款依赖"造成利润波动极大

游戏、影视、内容制作的核心资产是IP和创意——**一旦做出爆款，毛利率60-90%、利润率惊人（光线哪吒2、恺英传奇系列）；一旦没有爆款，就是亏损**。万达电影2024年归母-9.4亿、2025年5.14亿的过山车就是明证。**传媒股的利润，不能看一年，要看产品周期（2-3年）。**

### 2. 商誉是传媒的重灾区

传媒历史上并购频繁（影视公司收购明星工作室、营销公司收购代理商），**商誉减值是这个行业利润表的"黑洞"**。万达电影商誉39.32亿（占总资产17%）、蓝色光标17.6亿、三七15.78亿——**一旦并购标的业绩不达预期，商誉减值会直接击穿利润**。看传媒股，第一件事先看商誉占净资产的比重。

### 3. 现金流两极分化：游戏/广告龙头"印钞"，营销/影视"看天"

- **游戏龙头**（三七、恺英、吉比特）：经营现金流20-35亿，现金流≈归母的1.2-1.6倍——**现金牛**。
- **分众传媒**：经营现金流72亿，是归母的2.4倍——**广告里的印钞机**。
- **影视/营销**：万达、蓝色光标现金流波动大，靠并购和借款维持。

## 六、AI变量：传媒是AI落地最快的行业

2026年传媒的AI主线已经从"概念"走到"落地"：

1. **AI影视**：国内首部获证AI长片《奇谭：纸刃渡荒墟》上线爱奇艺（7月）——AIGC全流程制作走通"备案-审核-发行"全链路，**AI内容从技术验证进入商业化落地**。
2. **AI漫剧**：头部AI漫剧播放量7亿+，阅文、番茄开放IP版权库+AI降本——**"AI+IP"双轮驱动的新赛道**。
3. **GEO营销**：信息获取从"搜索"转向"AI生成答案"，GEO（生成式引擎优化）成为广告新战场——**重塑营销行业的流量逻辑**。
4. **AI游戏**：AI在研发、素材、买量全流程提效，交互式AI游戏（昆仑万维Matrix-Game等）探索中。

**AI对传媒的财务意义**：短期是"降本增效"（内容制作成本下降），中期是"新商业模式"（AI漫剧、AI长片、GEO广告），长期是"重构产业链"（内容供给门槛大幅降低）。**有IP储备、有内容场景、有流量的公司，是AI应用的核心受益者。**

## 七、风险与结论

### 风险清单

1. **政策风险**：游戏版号、内容审查、教辅政策——政策一变，格局全变。
2. **商誉减值**：万达39亿、蓝色光标17.6亿、三七15.78亿——并购泡沫的"还债期"。
3. **爆款依赖**：影视/游戏业绩高度依赖单款产品，产品周期错位就是业绩悬崖。
4. **AI落地不及预期**：AI长片/漫剧/GEO的商业化仍在早期，若进度低于预期，主题退潮。
5. **消费复苏不及预期**：广告、电影、付费内容都是消费敏感行业。
6. **估值分化**：板块PE 27-38倍，游戏/数字媒体偏高，出版低估值防御。

### 俯瞰结论

**传媒行业2026年处于"业绩分化+AI变革"的十字路口。**

从财务视角俯瞰，子板块的优劣非常清晰：

1. **游戏是最硬的板块**：版号常态化（1147款）+出海（占全球41.6%）+AI降本增效，2026H1客户端游戏+27.9%、小程序游戏+36%，中报预告全线增长——**业绩确定性最高，吉比特/恺英核心利润率46-54%是A股制造业都羡慕的水平**。
2. **广告看分众**：整个广告板块净利率不到1%，但分众一家净利率23%、现金流72亿——**垄断型梯媒是广告里唯一的"印钞机"**。
3. **影视是"赌爆款"**：2026票房-35%是行业现实，光线靠哪吒2一年赚过去五年——**高波动、高赔率，不适合稳健资金**。
4. **出版是防御性红利**：营收降利润增、零借款、高分红——**低估值防御，适合收息**。

**说白了**：传媒是A股"分化最极端"的行业之一——**同一个"传媒"标签下，有净利率54%的游戏公司（吉比特）、净利率0.3%的营销公司（蓝色光标）、亏钱又有39亿商誉的影视公司（万达），还有躺着分红的出版公司（凤凰）**。看这个行业，不要看"传媒"两个字，要看具体公司的产品周期、商誉和现金流。而AI正在给这个行业加杠杆——**有IP和场景的公司会被AI放大，没IP纯代工的公司会被AI淘汰。**

**四条主线供参考**：游戏（业绩确定，世纪华通/三七/恺英）、分众（广告印钞机）、IP+AI（光线/中文在线/华策）、出版（防御红利）。记住传媒的铁律——**轻资产高毛利是优势也是陷阱，商誉是地雷，爆款周期决定利润，现金流才是真试金石。**
