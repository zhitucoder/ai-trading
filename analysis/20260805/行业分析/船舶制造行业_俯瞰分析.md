# 船舶制造行业俯瞰分析 — 张新民视角

> **免责声明**：我以张新民教授的财务报表分析框架来俯瞰这个行业。以下分析基于公开财务数据（2023-2025年年报及2026年一季报）和公开行业数据（工信部、克拉克森、VesselsValue等），所有数字均可追溯至年报、季报和行业统计。分析归分析，买卖是你自己的决策。

## 一、船舶制造：一门"先收钱、后造船"的重周期生意

造船业有三个必须理解的核心属性：

1. **超级重周期**：从接单到交船要2-3年，全球造船产能10年一个轮回。2021年启动的本轮上行，是2008年金融危机后最大的一波。
2. **先收钱后造船**：船东下单先付预付款（合同负债），船厂用客户的钱买钢板、租船坞、慢慢造——**合同负债（预收船款）是造船企业资产负债表上最核心的资产来源**。
3. **低毛利高波动**：造船毛利率普遍只有7-12%（高附加值船型例外），船价、钢价、汇率任何一个波动，都会剧烈放大或压缩利润。

**看造船行业，第一张表要看合同负债——它告诉你未来2-3年有多少"已锁定的收入"在等着交付；第二张表看新接订单——它告诉你周期是在上行还是见顶。**

**我直接告诉大家这张表的读法——五家公司代表五种不同的"造船生意"：**

### 1. 中国船舶（600150）：国家队"航空母舰"
- 2024年吸收合并中国重工后，整合了江南造船、外高桥造船、大连造船、武昌造船等核心船厂，是全球最大的造船上市公司。
- **合同负债1966.53亿**——账上压着近2000亿的船东预付款，是所有玩家中最多的；存货749亿（在建船舶）也是最多。
- 2026Q1核心利润率飙到14.7%（vs 2025全年9.7%），**高价船进入密集交付期，利润率正在跳升**；2026H1预告归母92-110亿（+143.56%~+191.21%）。
- **定位**：行业龙头的"压舱石"，规模最大、确定性最高、利润弹性正在释放。

### 2. 松发股份（603268）：民营"黑马"
- 恒力重工借壳，接单全球第五、中国第四，手持订单全球第二。
- **核心利润率15.2%全行业最高**（VLCC/LNG/FLNG高附加值船型+发动机自产）；2025年归母26.55亿超额完成重组预测135%；2026H1预告约36亿（**+456.33%**）。
- **但负债率80.9%也是全行业最高**、合同负债261.54亿、2025年经营现金流-14.58亿——高杠杆、高弹性、高预期。
- **定位**：行业里弹性最大的"民营黑马"，赚得多、欠得多、涨得猛。

### 3. 中船防务（600685）：军工+支线箱船
- 黄埔文冲（军辅船+支线集装箱船全球领先）+ 参股广船国际（投资收益贡献）。
- 核心利润率6.8%（行业最低档，船型结构中民船占比高）、2026H1预告+50%~69%。
- **定位**：三家总装船厂里最"稳"的一个——增速没前两者猛，但负债率61.3%居中、有军工底。

### 4. 中国动力（600482）：卖"发动机"的
- 全球船用发动机龙头（中船集团旗下），船用发动机占船舶成本约20%，是核心零部件。
- **核心利润率12.4%、2026Q1达14.3%**；**经营现金流115.71亿全行业最强**——卖发动机的现金流比造船好得多（不垫那么多资）。
- 双燃料发动机（环保转型）高价值量、高壁垒，还受益AIDC缺电下的燃气轮机需求。
- **定位**：产业链上"卖铲子"的角色——不赌船价、赚确定的配套钱，现金流质量最好。

### 5. 亚星锚链（601890）：小配套
- 锚链/系泊链龙头，**核心利润率22.0%全行业最高**（小而美的配套生意），负债率32.5%最低。
- **定位**：行业景气的"影子受益者"，盘子小但利润率最高。

## 四、财务共性：合同负债是订单的"镜子"

把五家的资产负债表放在一起，造船业有四个财务报表特征，我用框架总结如下：

### 1. 合同负债（预收船款）——订单饱满的资产负债表镜像
- 中国船舶1966.53亿、中国动力440.02亿、松发261.54亿、中船防务207.64亿——**头部船厂的合同负债动辄几百亿上千亿，占负债的一半以上**。
- 这是造船业最健康的负债：**船东的钱提前锁定了未来2-3年的收入**。合同负债越高，意味着排产越满、未来收入越有保障。
- A股船舶板块整体合同负债1967亿元（2025年报，+15%）、存货1065亿元（+13%）——**全行业都在"订单爆满、备料开建"的状态。**

### 2. 存货（在建船舶）——正在"下饺子"的证据
- 中国船舶存货749亿、中船防务85亿、松发52亿——**存货里主要是建造中的船舶**，存货增长意味着在手订单正在密集开工。

### 3. 经营现金流滞后——"订单越火、现金流越紧"
- 2025年中国船舶经营现金流77.67亿（营收1519亿，覆盖率仅0.5）、中船防务-3.22亿、松发-14.58亿——**利润是记账的（完工百分比法）、现金要等交付**。
- 例外是中国动力（115.71亿）和亚星锚链——**配套企业不垫船资，现金流远好于总装厂**。
- 看造船股现金流，要盯"交付回款节奏"，2026Q1松发转正+39.96亿就是交付放量的信号。

### 4. 负债率高是"假象"
- 中国船舶64.4%、中船防务61.3%、松发80.9%——**表面高负债，实则大半是船东预付款（合同负债）**，金融负债占比普遍只有8-20%。真正借银行的钱不多。

## 五、周期判断：超级周期的"量价齐升 + 业绩兑现"阶段

### 周期位置：上行中段，尚未见顶

| 指标 | 当前水平 | 含义 |
|------|---------|------|
| 新船价格指数 | 185.44点（2026年7月） | 历史峰值96.79%分位，高位运行 |
| 手持订单覆盖率 | 4.1年 | 历史高位，排产排到2030年 |
| 二手船价格指数 | 204点（连续13个月上行） | **运力供需仍紧，新造船订单有支撑** |
| 2026Q1全球新签订单 | 1758万CGT（+40%） | 油轮驱动，需求仍在放量 |
| 2026H1中国新接订单 | +173.1% | 景气加速而非见顶 |

**我的判断**：本轮造船超级周期处于"量价齐升→业绩兑现"的过渡阶段——2021-2024年是接单高峰期（价格上行、订单爆发），2025-2027年是**交付高峰期**（高价船陆续下水、利润表开始兑现）。**2026-2027年是造船股业绩弹性最大的两年**：前几年接的高价单（2023-2024年船价最高时接的），正在变成2026-2027年的交付收入。

### 但必须记住的周期风险

1. **船价不可能永远涨**：新船价格指数已在96.79%分位，2025年全球新接订单-24%（高基数回落），若船价见顶回落，2027-2028年接的单利润会变薄。
2. **产能重启潮**：全球造船产能加速重启（中国多家船厂扩建、恒力盘活STX），供给端在缓慢恢复——本轮周期后半段的产能红利正在被摊薄。
3. **交付验证**：恒力重工、新时代造船等新势力，大规模交付VLCC/LNG的经验尚未经过完整周期验证。
4. **汇率与钢价**：订单多为美元计价，人民币升值、钢价上涨会侵蚀利润。
5. **美国301调查**：美国对船舶行业的贸易调查，是悬在全球造船业头顶的政策利剑。

## 六、俯瞰结论

**船舶制造行业，当前是全球制造业里景气度最高、确定性最强、但周期属性也最浓的行业之一。**

用张新民框架俯瞰这个行业，结论可以用三句话概括：

**第一，行业处于超级周期的"利润兑现期"。** 2026H1中国新接订单+173%、手持订单占全球71%、排产排到2030年、新船价格指数96.79%分位——**过去几年接的高价单正在变成2026-2027年的利润**。中国船舶2026H1预告+143%~191%、松发+456%、中船防务+50%~69%，头部船厂业绩全面爆发。**这是行业景气度最直接的证据。**

**第二，竞争格局"一超多强、国进民进"。** 中国船舶集团（国家队）手持订单全球第一，恒力重工（民营）全球第二——**央企靠整合（吸收合并中国重工），民企靠盘活（收购STX大连）+高附加值卡位**。A股能买到的主要是五张牌：中国船舶（稳）、松发股份（猛）、中船防务（军工+稳）、中国动力（卖铲子、现金流最好）、亚星锚链（小而美）。

**第三，财务报表的语言高度统一：合同负债是订单的镜子，经营现金流是周期的温度计。** 全行业合同负债1967亿（+15%）、存货1065亿（+13%）——**报表在告诉你"订单爆满、正在下饺子"**；而经营现金流的滞后（总装厂普遍垫资）提醒你——**利润的含金量，最终要看2026-2027年交付回款能否兑现**。

**说白了**：造船是"接单时最兴奋、建造时最煎熬、交付时最丰收"的生意。当前行业正处在"建造期的煎熬刚过、交付期的丰收刚开始"的节点——**2026-2027年是造船股业绩弹性最大的窗口**。但周期的铁律是"没有只涨不跌的价格"：新船价格已在历史96.79%分位，产能重启潮已启动，美国301调查悬而未决。**享受景气的同时，永远记得：造船股最危险的时候，不是船价涨到顶的时候，而是市场把它当"成长股"定价、忘记它是周期股的时候。**

**看这个行业，盯四个指标：新船价格指数（周期位置）、手持订单覆盖率（景气延续性）、经营现金流回正节奏（利润含金量）、双燃料/绿色船型占比（结构性升级）**。四个指标向好，造船就是未来两年A股最值得拿的周期赛道之一。
