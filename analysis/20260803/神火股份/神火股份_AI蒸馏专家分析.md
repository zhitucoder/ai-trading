## 六、第五维：成长性——核心驱动力拆解

> 用户特别关注：成长的核心驱动力在哪？神火的答案是——**双引擎错峰发力 + 吨铝利润扩张 + 高股息红利属性。**

### 6.1 成长驱动之一：电解铝——供给天花板锁死，利润再分配（主引擎）

神火有约170万吨电解铝产能（其中云南神火90万吨水电铝），**对铝价弹性极高**。2026H1毛利率从20%跳到36%，主引擎贡献了绝大部分利润增量。

### 6.2 成长驱动之二：煤炭——第二利润池，错峰对冲（防守引擎）

这是神火区别于所有纯铝厂的地方。煤炭产能约800万吨/年，2025年煤价下行时拖累了业绩（归母从43.1亿降到40.1亿），但2026年**煤价高位运行、供需紧平衡**，煤炭重新贡献正贡献。更重要的是，**煤铝错峰**——2022年煤铝双牛它赚75.7亿，2024年煤弱铝强它还能赚43.1亿，2026年煤铝双强。双引擎让它的业绩波动比单引擎的铝厂更“抗揍”。

### 6.3 成长驱动之三：成本端——自备电+云南水电电价下移（利润逻辑）

神火的成本优势是“双保险”：
- **新疆自备电厂**：煤电联营，电力成本锁定；
- **云南神火90万吨水电铝**：绿电+低价，且云南推进新能源电价市场化改革、绿电装机扩张，**当地电价整体趋于下行**——调研中公司明确表示这是重要利好。

此外公司合资持有部分氧化铝权益产能、稳定供应渠道，对冲原料波动。

### 6.4 成长驱动之四：铝箔深加工——从“卖铝”到“卖箔”（升级逻辑）

神隆宝鼎新能源电池铝箔是神火的第四极。铝箔环节盈利远高于电解铝，且受益于新能源电池、储能需求爆发。这是神火从“周期商品”向“新材料”延伸的期权。

### 6.5 成长驱动力小结

```
神火成长的核心驱动力 = 电解铝（价格×成本双击） + 煤炭（第二利润池） + 双源电力（成本锁定）
                      + 铝箔深加工（升级期权） + 高股息（红利属性）
```

**这已经不是一个单纯押注铝价的标的，而是一个“煤电铝箔”四轮驱动的组合资产。** 和云铝“极致单点+极致资产负债表”的风格不同，神火的成长逻辑是“多元化对冲+高弹性+红利回报”——用煤的稳定垫底，用铝的弹性进攻。
