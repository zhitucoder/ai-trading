## 二、分析逻辑与方法（数据怎么算的）

本报告采用"AI蒸馏专家·战略视角财务报表分析"框架（张新民教授框架），核心思路是**不看比率看质量、先重构再算账、打通三张表**。所有数据来自项目MySQL数据库（`ai_trading`，源：通达信）＋公司公告交叉验证。计算方法如下：

**① 核心利润**（本框架核心指标，首次出现必须附公式）：
```
核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用
核心利润率 = 核心利润 / 营业收入 × 100%
```
> 含义：剔除投资收益、政府补助、财务费用、资产减值、营业外收支等非经营项目后，**经营活动本身的真实盈利**。核心利润与净利润差距越大，利润中非经营成分越多。

**② 核心利润→净利润的拆解**：以营业利润为枢纽，把"核心利润"到"归母净利"之间的每一层损耗（研发费用、税金及附加、财务费用、投资/减值、所得税、少数股东损益）列出来，回答"赚的钱去哪了"。

**③ 资产负债表重构**：按战略视角把报表从"流动/非流动"重排为——
- 左边（两大能力）：**经营资产** vs **投资资产**
- 右边（四大动力）：**经营负债｜金融负债｜股东入资｜利润积累**
- 并据此划分**造血（经营负债+利润积累）**与**输血（金融负债+股东入资）**

**④ 三个匹配测试**：固定资产↔营业收入、营业收入↔核心利润、核心利润↔经营现金流，逐一验证三张表是否互相印证。

**⑤ 关键口径说明**：总股本取 `stock_shares_dfcf`（东财F10，8.879亿股）；净现金=货币资金+交易性金融资产-短期借款-长期借款；ROE=归母净利/平均归母权益（年报加权口径14.67%）。**本项目ads_*预计算表已排除数据损坏行，可直接使用。**

## 三、六维分析

### 维度一：资产质量分析（底子）

**核心结论：底子非常厚——近四成资产是现金，商誉仅1.25亿，典型的"现金奶牛＋轻负债"结构**

**资产负债表重构（2025年末）：**

| 资产端（钱投向哪） | 金额 | 占比 |
|:---|---:|---:|
| 货币资金 | 93.05亿 | 38.8% |
| 交易性金融资产（理财等） | 13.45亿 | 5.6% |
| 应收账款 | 22.48亿 | 9.4% |
| 存货 | 15.61亿 | 6.5% |
| 固定资产 | 40.54亿 | 16.9% |
| 无形资产 | 4.69亿 | 2.0% |
| 商誉 | **1.25亿** | **0.5%** |
| 其他资产 | 48.78亿 | 20.3% |
| **总资产** | **239.85亿** | 100% |

**关键发现：**
1. **现金类资产106.5亿，占总资产44%**——这是A股药企里罕见的"有钱"程度
2. **商誉仅1.25亿（0.5%）**：无历史并购包袱，不需要担心商誉减值爆雷
3. **固定资产40.54亿（16.9%）**：轻中资产模式，不像重资产药企（原料药大厂）那样被折旧压身
4. 固定资产/在建工程约42.9亿，2025年资本开支仅0.68亿（东财点评），扩张主要靠研发而非厂房——**经营主导型＋研发驱动型**

### 维度二：利润质量分析（面子）

**核心结论：核心利润率31%属于优秀水平，但营收停滞（120亿平台4年）+研发费用化率高，净利被压得喘不过气**

**核心利润计算（2025年度）：**
```
核心利润 = 120.20亿 - 40.99亿 - 35.81亿 - 5.98亿 = 37.42亿
核心利润率 = 37.42 / 120.20 = 31.13%
```

**从核心利润到归母净利的"三层损耗"（2025年度）：**

| 项目 | 金额 | 说明 |
|:---|---:|:---|
| **核心利润** | **+37.42亿** | 经营活动真本事 |
| 减：研发费用 | -9.38亿 | 费用化率约89%，全部当年计提 |
| 减：税金及附加 | -1.54亿 | 税费 |
| 加：财务费用（净收入） | +2.13亿 | 利息收入>利息支出，倒赚 |
| 加：投资收益＋其他收益等 | +1.42亿 | 理财收益＋政府补助 |
| 减：资产减值损失 | -1.09亿 | — |
| **＝营业利润** | **+29.46亿** | 与利润表吻合 |
| 加：营业外收支净额 | +0.06亿 | — |
| **＝利润总额** | **+28.62亿** | — |
| 减：所得税 | -4.51亿 | 有效税率约15.8% |
| **＝净利润** | **+24.11亿** | — |
| 减：少数股东损益 | -3.88亿 | 分给合资子公司伙伴 |
| **＝归母净利润** | **+20.23亿** | 归A+H股东 |

**关键发现：**
1. **核心利润率31.13%**——每100元营收赚31元核心利润，在综合药企里是第一梯队（对比：行业一般15-25%）
2. **研发费用9.38亿＋少数股东分走3.88亿**——这两项吃掉核心利润约1/3，是净利与核心利润差距的主因
3. 净利率16.8%、扣非归母净利20.09亿（+1.51%）——扣非微增，说明利润"干净"
4. 历史沿革：核心利润率2021年27.05%→2025年31.13%，**利润率在爬坡，但营收不涨，是"增收无望、提质有余"**

| 年份 | 营收 | 同比 | 归母净利 | 同比 | 核心利润率 | ROE |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| 2021 | 120.64亿 | +14.67% | 17.76亿 | +3.54% | 27.05% | 12.41% |
| 2022 | 126.30亿 | +4.69% | 19.09亿 | +7.53% | 28.69% | 12.78% |
| 2023 | 124.30亿 | -1.58% | 19.54亿 | +2.32% | 29.86% | 13.23% |
| 2024 | 118.12亿 | -4.97% | 20.61亿 | +5.50% | 32.71% | 13.83% |
| 2025 | 120.20亿 | +1.76% | 20.23亿 | -1.84% | 31.13% | 14.67% |

### 维度三：现金流质量分析（日子）

**核心结论：日子过得最滋润——净现比1.55，经营现金流连续三年30亿上下，赚的是真金白银**

| 指标 | 2025 | 2024 | 2023 |
|:---|:---:|:---:|:---:|
| 经营现金流净额 | **31.45亿** | 29.79亿 | 32.49亿 |
| 归母净利润 | 20.23亿 | 20.61亿 | 19.54亿 |
| **净现比（OCF/归母净利）** | **1.55** | 1.45 | 1.66 |
| OCF/核心利润 | 0.84 | 0.77 | 0.87 |
| 2026Q1经营现金流 | **8.17亿（+12.8%）** | — | — |

**关键发现：**
1. **净现比1.55**——每赚1元净利润，实际收进来1.55元现金，利润含金量极高
2. 2026Q1营收降9.7%但经营现金流**增长12.8%**，管理层原话"现金流是检验经营质量的试金石"——回款质量健康、渠道库存合理
3. 自由现金流角度：OCF 31.45亿－资本开支约0.68亿＝**自由现金流约30亿**，与分红（12.7亿）＋回购（5.8亿）合计18.5亿相比，**覆盖率>160%**，分红完全由内生造血支撑，不靠借钱
4. 注意：货币资金+理财共106.5亿，公司大量现金买结构性存款，投资/筹资现金流"毛额"巨大（理财买入卖出所致），但不影响经营现金流质量的判断

### 维度四：偿债能力分析

**核心结论：几乎零偿债压力——有息负债率仅12%，净现金77.8亿，账上现金是全部有息负债的3.7倍**

**资本结构重构（右端：钱从哪来，2025年末）：**

| 资金来源 | 金额 | 占比 | 类型 |
|:---|---:|:---:|:---|
| 经营负债（应付+合同负债等） | 55.69亿 | 23.2% | **造血** |
| 金融负债（短借21.2+长借7.5） | 28.69亿 | 12.0% | **输血** |
| 股东入资（股本+资本公积） | 11.59亿 | 4.8% | **输血** |
| 利润积累（留存收益等） | **127.29亿** | **53.1%** | **造血** |
| 少数股东权益 | 16.59亿 | 6.9% | — |
| **合计** | **239.85亿** | 100% | — |

**造血合计：55.69 + 127.29 = 182.98亿（76.3%）｜输血合计：28.69 + 11.59 = 40.28亿（16.8%）**

**关键发现：**
1. **76%的资金靠造血，只有17%靠输血**——这是格力、联通式的高质量结构，"天天靠输血的企业没底气，丽珠的底气就是这76%"
2. 利润积累127亿是最大资金来源——公司赚钱后不靠股东追加投入、不靠大举举债，靠利润滚存
3. **净现金77.8亿**（现金93.05+理财13.45-短借21.20-长借7.49），有息负债率仅12%
4. 2026Q1末净现金67.2亿（短借升至27.2亿，或因集采过渡期备货），仍无压力
5. 资产负债率35.2%，且其中约2/3是不付息的经营负债——负债"质量"很高

### 维度五：成长性分析

**核心结论：存量见顶、增量未起——营收连续4年卡在120亿，2026年是"新旧动能切换"的观察窗口**

| 指标 | 数值 | 评价 |
|:---|:---:|:---|
| 2025营收 | 120.20亿（+1.76%） | 停滞 |
| 2026Q1营收 | 28.71亿（-9.73%） | 承压 |
| 2026全年指引 | 收入小幅个位数下滑、利润力争正增长 | 弱 |
| 2026E一致预期净利 | 21.01亿（+3.85%） | 温和 |

**增长的三个看点（网上补充的经营信息）：**
1. **创新药兑现**：莱康奇塔单抗（国产首个IL-17A/F双靶点，银屑病NDA已获CDE优先审评、强直已完结III期）、重组人促卵泡激素、亮丙瑞林微球3M等2026年有望获批；阿立哌唑微球（全球首个）2026年执行国谈放量；曲普瑞林微球2026Q1收入同比**增长超3倍**
