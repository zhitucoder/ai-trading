## 二、产业链介绍：上游原料 → 中游冶炼 → 下游用钢

```
上游原燃料            中游钢铁冶炼            下游用钢
铁矿石（进口依赖）     长流程高炉（主导）        房地产（萎缩）
焦煤/焦炭              电炉短流程（政策扶持）     基建（下行）
废钢（资源化提升）     特钢/板材产线            制造业（接棒）
合金（镍/铬/钼等）                              汽车/船舶/家电/机械
```

### 2.1 上游：铁矿石与焦煤（决定成本）

- **铁矿石**：高度依赖进口（澳巴为主），供给宽松、价格中枢下移，但进口成本仍占钢材成本大头
- **焦煤/焦炭**：多轮涨价抬升冶炼成本，国际油价波动拉高物流运费——**成本端“两头挤压”**
- **废钢**：资源化率提升，电炉短流程获政策扶持，削弱原料单边推涨

### 2.2 中游：钢铁冶炼（利润核心区）

| 业态 | 特点 | 代表企业 |
|---|---|---|
| **长流程高炉（普钢）** | 规模大、成本竞争、受地产拖累 | 宝钢、鞍钢、河钢、华菱 |
| **电炉短流程** | 政策扶持、低碳、废钢驱动 | 沙钢、部分转型钢企 |
| **特钢** | 高壁垒、高端制造、盈利较好 | 中信特钢、抚顺特钢、久立特材 |
| **板材/硅钢** | 制造业用钢、板强材弱 | 宝钢、太钢不锈、首钢 |

### 2.3 下游：用钢（决定需求）

- **房地产（萎缩）**：新开工同比降超20%，螺纹/线材等长材需求长期承压——**最大拖累**
- **制造业（接棒）**：汽车/船舶/家电/机械/光伏支架/风电塔筒用钢稳步抬升，制造业用钢占比突破50%——**需求韧性来源**
- **出口**：直接出口受欧盟关税/碳税压制（2026年7月欧盟TRQ新规超配额关税翻倍至50%），间接出口（机械/汽车）仍有支撑

**一句话产业链逻辑**：**上游铁矿焦煤决定成本，中游冶炼决定利润（特钢>板材>长材），下游制造业接棒地产决定需求**。行业从“量增价涨”转向“量稳价震、品种分化”，投资逻辑从“吨钢市值”转向“单位碳排收益+特钢占比+重组弹性”。

## 七、增长逻辑与行业展望：底部反转的三大信号

### 7.2 中长期（2026-2030）：存量优化，三大主线

- **供给端出清（核心）**：反内卷治理+粗钢产量调控+产能置换新规+碳市场纳入钢铁——**供给约束制度化，行业从“规模驱动”转“效率/低碳/结构驱动”**
- **需求结构切换**：房地产用钢中枢下移、制造业用钢占比突破50%——**“建筑退坡、制造接棒”，板材/特钢受益**
- **高端化+低碳化**：高端特钢（轴承/齿轮/高温合金/取向硅钢）进口替代、电炉短流程+氢冶金获政策扶持——**特钢与低碳工艺是结构性机会**

3. **制造业接棒确认**：制造业用钢持续放量、板材利润扩大对冲长材萎缩

## 八、行业风险：五只黑天鹅

1. **地产深度下滑（最大）**：房地产新开工同比降超20%，长材需求底部遥遥无期，若地产继续探底，螺纹/线材钢企深度亏损延续。
2. **减产不及预期**：钢厂为保现金流不愿停炉，减产落地力度参差不齐，供给出清慢，低利润周期拉长。
3. **出口双重压制**：欧盟TRQ新规（超配额关税50%）+CBAM碳税，直接出口成本大涨，外需承压。
4. **原燃料成本上涨**：焦煤焦炭涨价+国际油价抬升物流成本，“两头挤压”压缩钢厂利润。
5. **碳成本超预期**：钢铁纳入碳市场，每吨钢碳成本预计+80-120元，高炉长流程边际利润被击穿风险。
