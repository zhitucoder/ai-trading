## 4. 统一数据对齐规则（核心逻辑）
由于各类数据原始频率不同，在月度时间轴上的呈现必须严格遵循下表，以确保图表的科学性与准确性：

| 指标类型 | 原始数据频率 | 在月度轴上的取值规则 | 图表呈现形式 |
| :--- | :--- | :--- | :--- |
| **原油价格**（WTI/布伦特） | 日度 | 取 **每月最后一个交易日** 的收盘价 | 连续折线（每月一个点） |
| **运价指数**（BDTI/BCTI等） | 日度 | 取 **每月最后一个交易日** 的收盘价 | 连续折线（每月一个点） |
| **个股股价**（所有公司） | 日度 | 取 **每月最后一个交易日** 的收盘价（前复权处理） | 连续折线（每月一个点） |
| **归母净利润**（所有公司） | 季度（财报披露） | 仅取 **3月、6月、9月、12月** 的月末值；**其余月份设置为 null** | 柱状图（ECharts自动跳过null值，仅在有数据的月份显示柱子） |

> **技术实现提示**：使用 ECharts 时，柱状图数据数组中非季报月份填入 `null` 或 `undefined`，图表会自动在该位置留空，不会错误地绘制“0”值柱体；折线图默认会在数据点之间连接，但遇到 `null` 时会自动断开，恰好符合利润数据只在季末出现的真实情况。

## 5. 交互与技术要求
- **图表库**：必须使用 **ECharts**（原生支持双Y轴、多类型图表混合、null值处理和DataZoom交互）。
- **交互细节**：
  - **图例**：点击图例可显隐对应的数据曲线。
  - **缩放**：启用 ECharts 的 `dataZoom` 滑块组件，允许用户拖动查看10年中的任意时间段。
  - **悬停提示（Tooltip）**：鼠标悬停时，需同时显示该月份对应的**油价/运价、净利润（如有）、股价**数值。
  - **加载状态**：切换Tab、切换油价品种或切换运价指数时，图表区域需显示 **Loading 动画**。
- **数据容错**：若某个月份某指标数据缺失，图表应优雅降级（显示断点或空位），不得报错或阻塞渲染。
- **响应式适配**：优先适配 **PC 端（1920×1080 及以上）**，确保图表清晰、文字可读，兼顾 1440×900 分辨率。
