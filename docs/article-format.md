# 财报分析文章格式规范

> 本文档记录了财报分析文章的写作与排版要求，后续所有文章按此规范执行。

---

## 一、写作规范

### 1.1 人称与署名
- **"浩哥"**
- 第一人称用"我"（浩哥）

### 1.2 分析框架命名
- "张新民教授'战略视角财务报表分析'框架" → **"AI蒸馏专家'战略视角财务报表分析'框架"**
- 文中所有"张新民"三字替换为**"AI蒸馏专家"**
- 框架名"战略视角财务报表分析"保留不动

### 1.3 文章开头三段式（必守）

文章正文（封面图后、趋势图前）固定为三段式结构：

**第一段 · 标题**：20字以内，用**问句/反差/数字**引发点击，避免平铺直叙的公司名+分析框架。

**第二段 · 钩子段**：100字以内，有数据、有文字，冲击用户；**必须以疑问句结尾**，勾起点击欲；不要列一堆数据，数据与叙述结合。
- 作用：提炼全文核心亮点，用反差/疑问/数字制造冲突

**第三段 · 自我介绍**：固定模板，`{公司名称}` 替换为实际公司名（行业分析改为"透视{行业}的行业画像"，其余不变）：
```
我是浩哥，用AI蒸馏专家"战略视角财务报表分析"框架，透视{公司名称}的六维画像。先看公司全貌，避免盲人摸象一叶障目——了解企业整体财务质量，才能做出理性判断。
```
（引号一律用中文引号""）

**示例（中海油服）：**
```
# 给中海油打工，一年赚40亿，账上躺着112亿现金——中海油服为什么被低估？

503亿营收，40亿净利，112亿现金。现金流是利润的2.78倍，但营收只增长4%。钱太多，增长太慢——这家公司为什么被低估？

我是浩哥，用AI蒸馏专家"战略视角财务报表分析"框架，透视中海油服的六维画像。先看公司全貌，避免盲人摸象一叶障目——了解企业整体财务质量，才能做出理性判断。
```

**示例（紫金矿业钩子段）：**
```
营收3490亿，净利638亿，ROE 25.7%，PE只有10倍。利润涨了38倍，股价只涨了13倍。市场为什么始终把它当周期股定价？
```

**示例（北化股份）：**
```
# 巨亏一年后净利翻倍，北化股份靠什么翻身？

2024年还在亏损，2025年净利干到2.6亿，2026年上半年预告再翻倍。账上躺着19亿现金，银行借款不足1亿。一场硝化棉涨价，让这家央企军工厂迎来翻身——靠价格能撑多久？

我是浩哥，用AI蒸馏专家"战略视角财务报表分析"框架，透视北化股份的六维画像。先看公司全貌，避免盲人摸象一叶障目——了解企业整体财务质量，才能做出理性判断。
```

### 1.4 标题规范（并入1.3，以20字为硬约束）
- 标题用**问句/反差/数字**引发点击，**20字以内**，避免平铺直叙的公司名+分析框架
- 例如：
  - `给中海油打工，一年赚40亿，账上躺着112亿现金——中海油服为什么被低估？`（32字，仅作示例参考，正式发布需精简）
  - `紫金矿业一年赚638亿，为什么PE只有10倍？`
  - `山东黄金一年赚66亿，为什么ROE只有10%？`
  - `巨亏一年后净利翻倍，北化股份靠什么翻身？`（20字，合规）

### 1.5 文章结构
1. **封面区**：标题 + 核心指标标签 + "浩哥 AI 分析"
2. **自我介绍**：按1.3第三段固定模板（透视{公司名}的六维画像）
3. **趋势图**：调用 `http://localhost:9000/api/report/trend/{stock_code}` 截图，放于基本画像前
   - 截图要求：窗口 1000×900px，裁剪至内容区无多余空白
   - 图下方居中标注说明文字：**营收-净利润-股价趋势图**
4. **基本画像**：公司业务定位 + 战略类型判断
3. **资产负债表重构**：经营/投资资产 + 经营/金融负债分类
4. **造血能力分析**：合同负债/核心指标
5. **核心利润拆解**：核心利润计算 + 利润结构分解
6. **三个匹配测试**：固定资产vs营收 / 营收vs核心利润 / 核心利润vsOCF
7. **关键风险信号**：应收账款/存货/商誉等
8. **综合诊断**：面子·日子·底子 + 最终结论
9. **文末注明**：系统生成 + GitHub地址 + 互动引导

### 1.6 核心利润计算公式（必读）

核心利润是AI蒸馏专家框架的核心指标，所有分析文章中首次出现时必须附上公式说明：

```
核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用
核心利润率 = 核心利润 / 营业收入 × 100%
```

核心利润反映**企业经营活动本身的真实盈利能力**，不含投资收益、政府补助、财务费用、资产减值、营业外收支等非经营或非经常性项目。核心利润与净利润的差异越大，说明利润中非经营成分越多。

### 1.7 指标计算公式（绕过损坏字段）
| 指标 | 计算方式 |
|------|---------|
| 核心利润率 | 核心利润 / 营业收入 × 100% |
| 净利润率 | 净利润 / 营业收入 × 100% |
| 合同负债/总资产 | fin_balance_sheet 直接取值 |
| ROE | fin_income.净利润 / fin_balance_sheet.净资产 × 100% |
| 资产负债率 | fin_balance_sheet.总负债 / fin_balance_sheet.总资产 × 100% |

## 二、排版规范

### 2.1 封面图（公众号头条 · 2.35:1）

**5行版式（必守，参考云铝股份封面）：**

| 行 | 内容 | 样式 |
|---|------|------|
| ① 顶部标签 | `浩哥 AI 分析` | 金色细边框圆角标签，26-30px |
| ② 主标题 | 公司名 + 核心看点（≤14字） | 白色加粗，关键数字金色 `#e2b714` 高亮，72px |
| ③ 分隔线 | 金色渐变横线 | 120-140px 宽 |
| ④ 副标题 | 核心反差/数据 | 金色 `#e2b714`，34px，多条用 `·` 分隔 |
| ⑤ 底标 | `{股票代码} · 赛道定位 · 2025年报+2026Q1` | 浅灰 `#8899aa`，22px，代码金色 |

- 背景色：**暗黑调** `#1a1a2e`（不要蓝色渐变）
- 尺寸：1800×766px（2.35:1，适配手机显示）
- 文字：**居中对齐**，padding 左右至少 280px
- 安全区：核心信息集中在中央766×766正方形区域内
- 保存：`/mnt/d/pic/{股票中文名称}_{股票代码}_cover.png`

### 2.1.1 短视频财经封面（16:9）

适用于抖音/视频号/B站/小红书短视频封面。

- 背景：**纯色深紫蓝黑** `#18192F`，**无图片、无纹理、无渐变**，全部文字居中垂直排版
- 尺寸：1920×1080px（16:9）
- 字体：黑体（`PingFang SC` / `Microsoft YaHei` / `Heiti SC` / `SimHei`）

**5行版式（自上而下）：**

| 行 | 内容 | 样式 |
|---|------|------|
| ① 顶部标签 | 深色圆角胶囊框 `#242741`，框内 `AI蒸馏专家 · 财报分析` | 金色 `#e2b714` 小字，28px，字间距6px |
| ② 公司名称 | 公司名，**画面视觉中心** | 超大号白色粗黑体 `#ffffff` 900字重，124px |
| ③ 核心slogan | 一句话核心观点/反差 | 大字号金色粗体 `#e2b714` 800字重，68px |
| ④ 业绩数据 | 多条用 `·` 分隔 | 中等字号浅灰 `#aab2cf`，44px，关键指标 `#ffd700` 高亮 |
| ⑤ 底部信息 | `{代码} · 赛道定位 · 财务指标`，用 `·` 分隔 | 小字号浅灰 `#7c86a6`，30px，代码浅蓝 `#8bbaff` 高亮 |

- 行间距（紧凑）：标签→名称 36px、名称→slogan 26px、slogan→数据 32px、数据→底部 44px
- 风格：极简科技风、干净高级、无多余装饰、文字清晰锐利、2D平面
- 保存：`/mnt/d/pic/{公司名}_视频封面_16x9.png`

### 2.2 配图处理
- **所有图片不走 imgbb 图床**
- 统一使用 **base64 data URI** 直接嵌入 markdown / HTML
- 格式：`![](data:image/png;base64,...)`

### 2.3 表格 → 截图
- 所有 markdown 表格和代码块中的结构化数据，**全部转为截图**（不留文本表格）
- 截图风格（暗调）：
  - 背景：`#1a1a2e`
  - 表头行：`#16213e` 背景，白色 `#ffffff` 加粗字体
  - 分隔线：`#0f3460`
  - 第一列（标签列）：亮色（`#8bbaff` 浅蓝 或 `#ffd700` 金色），加粗
  - 数值列：浅灰 `#e0e0e0`，重要值用金色或红色高亮
  - 说明文字：`#666` 或 `#888`
  - 奇数行：`#1a1a2e`，偶数行：`#1e1e36`
   - 底部注：灰色小字 `数据来源：ai_trading 财务数据库`
- **截图底部必须空出2行空白**（用于叠加水印）：在 `</tbody>` 前加2行 `<tr><td style="padding:4px 8px" colspan="10">&nbsp;</td></tr>`


### 2.4 代码块中的结构化数据
- 资产结构（经营/投资分类）、负债结构、利润拆解等
- 统一转换为暗调截图，规则同 2.3

### 2.5 生成公众号预览
- 工具：`wechat-copy.js <input.md> --preset "墨色书香"`
- 生成命令：
  ```
  cd analysis/
  node /home/rick/.claude/skills/wechat-article-typeset/wechat-copy.js "文件名.md" --preset "墨色书香"
  ```
- 输出：`article.preset.html` + 预览链接
- 图片全部 base64 嵌入后运行

## 三、文件管理

### 3.1 封面图片
- 保存到 `/mnt/d/pic/` 目录
- 文件名格式：`{股票中文名称}_{股票代码}_cover.png`
  - 例如：`荣盛石化_002493_cover.png`
- **必须为 PNG 格式**（不支持 JPG/WebP）
- 专题文章：保存到 `analysis/images/{主题简称}-cover.png`
  - 例如：`analysis/images/fee-cover.png`（财务费用专题）

### 3.2 分析文章
- 保存到 `analysis/` 目录
- 文件名：`{公司名}_{框架名}.md`
- 例如：`中国船舶_张新民视角分析.md`
