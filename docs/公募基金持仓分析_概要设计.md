## 三、预计算表设计（ads_ 开头，一次性计算）

### 3.1 ads_fund_stock_change — 个股季度环比

**用途**：每只股票相邻两个完整季度的持仓变化，所有个股分析的底层数据

```sql
CREATE TABLE ads_fund_stock_change (
  id INT AUTO_INCREMENT PRIMARY KEY,
  stock_code VARCHAR(10) NOT NULL,
  end_date VARCHAR(8) NOT NULL,          -- 当前季度截止日
  prev_end_date VARCHAR(8) NOT NULL,      -- 上一个季度截止日
  quarter CHAR(6),                        -- 当前季度标签
  fund_count INT,                         -- 当前基金数
  prev_fund_count INT,                    -- 上季度基金数
  fund_count_change INT,                  -- 基金数变化
  total_amount BIGINT,                    -- 当前持仓股数
  prev_total_amount BIGINT,               -- 上季度持仓股数
  amount_change BIGINT,                   -- 持仓股数变化
  amount_change_pct DECIMAL(10,2),        -- 持仓变化率(%)
  total_mkv DECIMAL(20,2),               -- 当前持仓市值
  prev_total_mkv DECIMAL(20,2),          -- 上季度持仓市值
  mkv_change DECIMAL(20,2),              -- 市值变化
  active_count INT,                       -- 当前主动基金数
  passive_count INT,                      -- 当前被动基金数
  active_ratio DECIMAL(5,2),             -- 主动基金占比(%)
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_stock_date (stock_code, end_date),
  KEY idx_end_date (end_date),
  KEY idx_change_pct (amount_change_pct)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**数据量**：约 30k 行（5500只股票 × 6个双年度）

---

### 3.2 ads_fund_sector_flow — 板块资金流向

**用途**：每个板块每季度的基金持仓净流入/流出，宏观分析的核心数据

```sql
CREATE TABLE ads_fund_sector_flow (
  id INT AUTO_INCREMENT PRIMARY KEY,
  sector_type VARCHAR(20) NOT NULL,       -- industry/concept/region
  sector_name VARCHAR(50) NOT NULL,       -- 板块名称
  end_date VARCHAR(8) NOT NULL,           -- 季度截止日
  quarter CHAR(6),
  stock_count INT,                        -- 板块内股票数
  total_fund_count INT,                   -- 板块内基金持仓总次数
  total_mkv DECIMAL(20,2),               -- 板块基金总持仓市值
  prev_total_mkv DECIMAL(20,2),          -- 上季度板块总持仓市值
  mkv_change DECIMAL(20,2),              -- 市值变化
  mkv_change_pct DECIMAL(10,2),          -- 市值变化率(%)
  avg_fund_count DECIMAL(10,1),          -- 平均每只股票被多少基金持有
  signal CHAR(1),                         -- A=加速流入 B=减速流出 C=减速流入 D=加速流出
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_sector_date (sector_type, sector_name, end_date),
  KEY idx_end_date (end_date),
  KEY idx_signal (signal)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**数据量**：约 6k 行（600板块 × 5个双年度 × 2类型 ~ 行业+概念）

### 3.3 ads_fund_stock_trend — 个股趋势评分

**用途**：单只股票被基金长期看好的综合评分

```sql
CREATE TABLE ads_fund_stock_trend (
  id INT AUTO_INCREMENT PRIMARY KEY,
  stock_code VARCHAR(10) NOT NULL,
  latest_end_date VARCHAR(8),             -- 最新季度
  trend_score INT,                        -- 趋势得分（-4~+4）
  trend_label VARCHAR(20),                -- 持续看好/偏好看好/中性/偏好看空/持续看空
  increase_quarters INT,                  -- 增持的季度数（0~4）
  decrease_quarters INT,                  -- 减持的季度数
  consecutive_increase INT,               -- 当前连续增持季度数
  latest_change_pct DECIMAL(10,2),        -- 最新季度变化率(%)
  fund_count INT,                         -- 当前基金数
  total_mkv DECIMAL(20,2),               -- 当前持仓市值
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_stock (stock_code),
  KEY idx_trend_score (trend_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**数据量**：约 5.5k 行（每只股票一行）

## 五、分析方法论（基于双季度数据）

### 5.1 资金流向计算

```
季度净流入市值 = 当前季度总持仓市值 - 上季度总持仓市值
季度净流入股数 = 当前季度总持仓股数 - 上季度总持仓股数
```

### 5.2 板块轮动信号

```
板块资金动量 = 近2~4个双季度净流入市值序列的斜率
相对强弱 = 本板块净流入占比 - 上季度净流入占比

信号判定：
  A（加速流入）：连续2个季度净流入，且本季度流入加速
  B（减速流入）：本季度仍净流入，但增速放缓
  C（减速流出）：本季度仍净流出，但流出放缓
  D（加速流出）：连续2个季度净流出，且本季度流出加速
```

### 5.3 个股趋势评分

```
过去4个双季度中：
  增持季度数 ≥ 3 → 趋势得分 +3（持续看好）
  增持季度数 = 2 → 趋势得分 +1（偏好看好）
  增持季度数 = 1 → 趋势得分 -1（偏好看空）
  增持季度数 = 0 → 趋势得分 -3（持续看空）

  连续增持 ≥ 2季度 → 额外 +1
  连续减持 ≥ 2季度 → 额外 -1

综合范围：-4 ~ +4
```

### 5.4 基金集中度变化

```
集中度 = 基金数量 × 平均每基金持仓市值

信号：
  基金数↑ + 仓位集中↑ → 抱团加强
  基金数↑ + 仓位集中↓ → 新资金分散进入
  基金数↓ + 仓位集中↑ → 少数基金加仓，多数撤退
  基金数↓ + 仓位集中↓ → 集体撤退
```

## 六、产品设计

### 6.1 页面结构

```
基金持仓分析
├── 1. 宏观总览
│   ├── 全市场基金持仓市值趋势（Q2/Q4双季度折线图）
│   ├── 本季度板块资金流向TOP20（正负柱状图）
│   ├── 板块调仓热力矩阵（行=板块，列=季度，颜色=增减）

│
├── 2. 板块轮动
│   ├── Tab切换：行业 / 概念 / 地区
│   ├── 板块资金流向排名（条形图，红涨绿跌）
│   ├── 点击板块 → 展开板块内个股明细
│   └── 筛选器：只看加仓/只看减仓
│
├── 3. 个股基金画像
│   ├── 股票搜索框
│   ├── 8季度基金持仓趋势柱状图
│   ├── 持股基金数量变化折线图
│   ├── 主动/被动基金占比变化
│   └── 趋势评分卡片
│
└── 4. 基金筛选
    ├── 筛选类型下拉
    │   ├── 基金持仓暴跌（>80%减仓）
    │   ├── 基金持仓暴增（>50%加仓）
    │   ├── 千家基金重仓（>1000只基金持有）
    │   └── 持续看好（连续≥2季度增持）
    └── 结果表格（点击跳转个股画像）
```

### 6.2 API 设计

```
GET  /api/fund/macro/overview
     → 全市场季度趋势、本季度板块流向

GET  /api/fund/sector/flow?sector_type=industry&quarter=26Q2
     → 板块资金流向排名

GET  /api/fund/sector/{sector_name}/stocks
     → 板块内个股明细

     → 个股基金持仓详情（8季度趋势）

     → 条件筛选结果
```

## 七、具体案例

### 案例1：板块资金流向排名（26Q2）

```
数据源：ads_fund_sector_flow

SELECT sector_name, mkv_change, mkv_change_pct, signal
FROM ads_fund_sector_flow
WHERE end_date = '20260630' AND sector_type = 'industry'
ORDER BY mkv_change DESC
LIMIT 20;

预期输出：
| 板块       | 市值变化(亿) | 变化率  | 信号 |
|-----------|------------|--------|------|
| 半导体     | +180       | +46%   | A    |
| AI算力     | +120       | +43%   | A    |
| 医药       | +50        | +12%   | B    |
| 白酒       | -30        | -8%    | C    |
| 地产       | -80        | -35%   | D    |
```

### 案例2：千家基金重仓+持续增持

```
数据源：ads_fund_stock_trend + stocks

SELECT t.stock_code, s.stock_name, t.fund_count, t.trend_label, t.total_mkv
FROM ads_fund_stock_trend t
JOIN stocks s ON t.stock_code = s.code
WHERE t.fund_count >= 1000
  AND t.trend_score >= 3
ORDER BY t.fund_count DESC;

预期输出：
| 代码     | 名称     | 基金数 | 趋势     | 持仓市值(亿) |
|---------|---------|--------|---------|------------|
| 600519  | 贵州茅台 | 2,200  | 持续看好 | 3,500      |
| 000858  | 五粮液   | 1,620  | 持续看好 | 1,200      |
| 300750  | 宁德时代 | 1,780  | 偏好看好 | 2,100      |
```

### 案例3：基金持仓暴跌80%+

```
数据源：ads_fund_stock_change + stocks

SELECT c.stock_code, s.stock_name, c.amount_change_pct, c.fund_count_change
FROM ads_fund_stock_change c
JOIN stocks s ON c.stock_code = s.code
WHERE c.end_date = '20260630'
  AND c.amount_change_pct < -80
ORDER BY c.amount_change_pct ASC;

预期输出：
| 代码     | 名称     | 持仓变化率 | 基金数变化 |
|---------|---------|----------|----------|
| 002XXX  | XX科技  | -92%     | -350     |
| 600XXX  | XX能源  | -85%     | -280     |
```
