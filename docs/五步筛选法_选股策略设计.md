# 五步筛选法——选股策略概要设计

> 基于紫金矿业10年财务复盘，提炼为可量化、可系统执行的五步筛选框架。目标是自动筛出"经营质量持续改善"的公司，排除80%的垃圾股。

---

## 一、策略概述

### 1.1 策略名称
五步筛选法（Five-Step Screen）

### 1.2 策略定位
**初筛工具**，非交易信号。用于从全市场5000+股票中快速筛出经营质量改善的候选池，再由估值/行业分析做二次筛选。

### 1.3 核心思想
> 传统选股看"ROE>15%是优秀公司"，这个框架看"ROE连续5年提升是好公司"。

**不是找"现在好的公司"，而是找"正在变好的公司"。**

---

## 二、五步筛选维度

### 步骤一：ROE趋势（权重30%）

**指标：** 净资产收益率（ROE）= 净利润 / 净资产 × 100%

**逻辑：** ROE绝对值高≠好公司（可能是高杠杆或一次性收益）。ROE连续提升=公司的资本回报效率在持续改善，这是经营质量提升的最核心信号。

**筛选规则：**
- 当前ROE > 3%（排除严重亏损公司）
- 最近3年（含当年预测）ROE同比提升的年数 ≥ 2年
- 加分项：最近5年ROE趋势线斜率 > 0

**数据来源：** `fin_income.净利润 / fin_balance_sheet.净资产 × 100%`

**紫金矿业案例：**
```
2016年ROE 8% → 2018年12% → 2020年12% → 2022年19% → 2025年26%
连续10年趋势向上，得分30/30
```

---

### 步骤二：现金流质量（权重25%）

**指标：** 经营现金流 / 净利润

**逻辑：** 利润是会计数字，现金是真实收入。OCF / 净利润 > 1 说明赚到的每一块钱都收到了现金。连续多年OCF > 净利润，说明利润质量高、回款能力强、有真金白银去扩张。

**筛选规则：**
- 最近3年经营现金流 > 净利润（每年都满足，或累计3年总和满足）
- 最近3年OCF / 净利润的平均值 > 1.0
- 排除：OCF为负的年份占比 > 50%

**数据来源：** `fin_cash_flow.op_cash_flow / fin_income.parent_net_profit`

**紫金矿业案例：**
```
2019年 OCF/净利=2.1x，2021年=1.3x，2023年=1.4x，2025年=1.2x
连续7年OCF>净利，得分25/25
```

---

### 步骤三：毛利率趋势（权重20%）

**指标：** 毛利率 =（营业收入 - 营业成本）/ 营业收入 × 100%

**逻辑：** 毛利率提升=产品定价权增强或成本优势扩大。毛利率提升+营收增长=利润爆发（经营杠杆效应）。

**筛选规则：**
- 最近3年毛利率同比提升的年数 ≥ 2年
- 最近1年毛利率 > 3年前毛利率
- 加分项：最近1年营收增速 > 10%时，利润增速 / 营收增速 > 2

**数据来源：** `（fin_income.operating_revenue - fin_income.operating_cost）/ fin_income.operating_revenue × 100%`

**紫金矿业案例：**
```
毛利率从2016年11.5%→2025年27.7%（翻倍有余），2026Q1达到36.3%
利润增速/营收增速在2025年=61.5%/15.0%=4.1倍，得分20/20
```

---

### 步骤四：核心利润检查（权重15%）

**指标：** 核心利润 = 营业收入 - 营业成本 - 销售费用 - 管理费用

**逻辑：** 核心利润 > 净利润 = 经营活动真实盈利能力很强，利润被财务费用/减值等非经营因素拖累——这是好公司被错误定价的机会。

**筛选规则：**
- 最近3年每年核心利润 > 净利润
- 最近1年核心利润 - 净利润的差值 > 3年前差值（趋势扩大）
- 核心利润本身为正

**数据来源：** `fin_income.operating_revenue - operating_cost - selling_expense - admin_expense`

**紫金矿业案例：**
```
2025年核心利润847亿，净利润638亿——核心利润比净利润多200亿
且这一差值持续多年扩大，得分15/15
```

---

### 步骤五：资产负债表健康度（权重10%）

**指标：** 负债率、现金占比、自由现金流

**逻辑：** 健康的资产负债表=逆周期扩张的弹药。当同行在低谷被迫卖资产时，财务健康的公司可以低价收购。

**筛选规则：**
- 资产负债率 < 65%（或最近3年持续下降）
- 货币资金 / 总资产 > 10%
- 最近3年经营现金流 > 资本开支（自由现金流为正）

**数据来源：** `fin_balance_sheet` + `fin_cash_flow`

**紫金矿业案例：**
```
负债率从60%+降至51.6%，现金655亿占总资产13%，OCF 754亿远大于资本开支
得分10/10
```

## 三、评分模型

### 3.1 评分公式

```
总分 = ROE趋势得分(30) + 现金流质量得分(25) + 毛利率趋势得分(20) 
     + 核心利润得分(15) + 资产负债表得分(10)
```

满分100分，每步单独打分。

### 3.2 量化评分细则

| 步骤 | 权重 | 满分条件 | 零分条件 | 中间值规则 |
|:---|:---:|:---|:---|:---|
| ROE趋势 | 30 | 连续3年ROE同比提升 | ROE连续2年下降 | 每满足1年加10分 |
| 现金流质量 | 25 | 3年OCF均>净利润，均值>1.2x | OCF<净利润 | 每满足1年加8分，均值加分 |
| 毛利率趋势 | 20 | 3年持续提升+利润增速/营收增速>2 | 毛利率持续下降 | 每满足1年加6分，弹性加分 |
| 核心利润 | 15 | 3年核心利润>净利润+差值扩大 | 核心利润<净利润 | 每满足1年加5分 |
| 资产负债表 | 10 | 负债率<60%+现金>10%+OCF>资本开支 | 3项均不满足 | 每满足1项加3分 |

### 3.3 分数区间含义

| 总分 | 评级 | 意义 | 操作建议 |
|:---:|:---:|:---|:---|
| 85-100 | ⭐⭐⭐ | 经营质量全方位优秀 | 候选池首选，直接进入估值分析 |
| 70-84 | ⭐⭐ | 多数维度达标，有改善趋势 | 进入候选池，需行业分析辅助 |
| 50-69 | ⭐ | 部分维度达标，但存在明显短板 | 关注短板能否改善 |
| <50 | — | 经营质量无明显改善 | 排除 |

## 四、SQL实现

### 4.1 核心查询（以2025年报为基准）

```sql
-- 五步筛选法核心查询（简化版）
WITH roe_data AS (
  SELECT stock_code, report_date,
         net_profit / total_equity * 100 AS roe
  FROM fin_income i
  JOIN fin_balance_sheet b USING(stock_code, report_date)
  WHERE report_date IN ('2025-12-31','2024-12-31','2023-12-31')
),
roe_trend AS (
  SELECT stock_code,
         SUM(CASE WHEN roe > LAG(roe) OVER(...) THEN 1 ELSE 0 END) AS roe_improve_years
  FROM roe_data
  GROUP BY stock_code
),
ocf_quality AS (
  SELECT i.stock_code,
         AVG(c.op_cash_flow / NULLIF(i.parent_net_profit,0)) AS ocf_ratio
  FROM fin_income i
  JOIN fin_cash_flow c USING(stock_code, report_date)
  WHERE report_date >= '2023-12-31'
  GROUP BY i.stock_code
  HAVING ocf_ratio > 1.0
)
SELECT *
FROM roe_trend r
JOIN ocf_quality o USING(stock_code)
-- ... 后续步骤同理
ORDER BY score DESC
LIMIT 100;
```

### 4.2 批处理策略

- **全市场扫描**：每季度财报出齐后运行一次
- **增量更新**：每日仅更新当日有财报发布的公司
- **结果输出**：写入 **`ads_five_step_screen`** 表（按 `ads_` 前缀命名规范）

### 5.1 紫金矿业回测

| 年份 | 得分 | 后续3年涨幅 | 说明 |
|:---:|:---:|:---:|:---|
| 2018 | ~55分 | **+320%** | ROE在提升但不高，现金流极好——买入时PE 65倍 |
| 2020 | ~70分 | **+180%** | 毛利率开始提升，核心利润突出 |
| 2022 | ~85分 | **+50%** | 五维度全部达标，但已涨了很多 |
| 2025 | ~95分 | 待验证 | 全方位领先，PE已从65倍压缩到14倍 |

| 股票 | 评分 | 亮点 | 短板 |
|:---|:---:|:---|:---|

## 六、策略的局限

### 6.1 适用范围
- ✅ 适用于：制造业、资源类、消费品等行业
- ❌ 不适用于：金融（银行/保险因杠杆特殊）、ST/重组股、上市不足3年的新股

### 6.2 信号滞后
- 财务数据每季度更新一次，评分变化滞后于股价
- 2018年评分55分时PE 65倍——信号早但需要信仰

### 6.3 周期股误判风险
- 紫金矿业在铜价暴跌时评分可能在1-2年内崩掉
- 高分≠永远涨，低分≠永远跌

## 七、与现有系统的集成

### 7.1 作为独立策略注册

在 `routers/screening.py` 中注册为新的策略ID `five_step_screen`，与前端的"五步筛选"卡片关联。

### 7.2 输出字段（写入 `ads_five_step_screen` 表）

```sql
CREATE TABLE ads_five_step_screen (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  stock_code VARCHAR(10) NOT NULL,
  stock_name VARCHAR(50),
  total_score DECIMAL(5,1) COMMENT '总分0-100',
  roe_score DECIMAL(5,1) COMMENT 'ROE趋势得分/30',
  ocf_score DECIMAL(5,1) COMMENT '现金流质量得分/25',
  margin_score DECIMAL(5,1) COMMENT '毛利率趋势得分/20',
  core_profit_score DECIMAL(5,1) COMMENT '核心利润得分/15',
  bs_score DECIMAL(5,1) COMMENT '资产负债表得分/10',
  roe_trend VARCHAR(20) COMMENT 'ROE: 提升/持平/下降',
  ocf_ratio DECIMAL(5,2) COMMENT 'OCF/净利',
  margin_current DECIMAL(5,1) COMMENT '最新毛利率%',
  margin_3y_ago DECIMAL(5,1) COMMENT '3年前毛利率%',
  debt_ratio DECIMAL(5,1) COMMENT '资产负债率%',
  score_grade VARCHAR(10) COMMENT '评级: A/B/C/D',
  update_date DATE COMMENT '数据日期',
  INDEX idx_score (total_score DESC),
  INDEX idx_code (stock_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 7.3 与Minervini/SEPA策略的区别

| 对比项 | 五步筛选法 | Minervini SEPA |
|:---|:---|:---|
| 侧重点 | 经营质量改善 | 价格动量+形态 |
| 数据源 | 财务数据 | 价格+成交量 |
| 信号频率 | 季度 | 日/周 |
| 适合 | 长期持有者 | 趋势交易者 |

## 八、后续优化方向

1. **行业中性化**：调整评分基准使其在不同行业间可比
2. **前瞻因子加入**：整合分析师预期、订单数据
3. **动态权重**：根据市场环境自动调整权重（如加息周期提高现金流权重）
4. **AI增强**：用历史数据训练打分模型，优化阈值
