# 达摩达兰估值模块设计概要

> 设计日期：2026-08-11 | 作者：ai_trading 系统
> 目标：以达摩达兰（Aswath Damodaran）"故事→数字→价值"框架，对全量A股（约5500只）做**价值估算**，与**当前市值**对比，挖掘**被低估**的股票。

---

## 0. 一句话方案

**用达摩达兰框架给每只A股算一个"内在价值"，和"当前市值"比价，按"低估程度 + 增长质量"打分排序，每天更新市值侧、每季度更新财务侧，中间用视图关联。**

- 财务侧（财报数据，一季度一变）→ `ads_dmdl_*` 静态预计算表
- 市场侧（股价市值，一天一变）→ `ads_dmdl_mkt_*` 每日快照表
- 关联 → `v_dmdl_valuation` 视图，**一张 SQL 直接输出"每只股票当前低估了多少"**

---

## 1. 达摩达兰框架落地（A股实用化）

### 1.1 框架核心（做什么）

达摩达兰估值三要素：**现金流、增长、风险**。对全市场批量估值，我落地为一个"**简化DCF + 相对估值交叉验证 + 增长质量检验**"的组合：

```
每只股票的内在价值（Intrinsic Value）
  = 现有资产价值（Assets in Place）
  + 增长资产价值（Growth Assets）

价值 vs 价格（市值）：
  → 被低估（undervalued）：内在价值 > 当前市值
  → 被高估（overvalued）：内在价值 < 当前市值
```

### 1.2 五步法（每只股票执行）

| 步骤 | 达摩达兰原话 | 落地到表 |
|------|-------------|---------|
| ① 讲故事 | "先讲这家公司未来会变成什么样" | 生命周期阶段分类（stage） |
| ② 定数字 | "把故事转成营收增长/利润率/再投资" | 正常化利润、增长率假设 |
| ③ 检验增长质量 | "ROC > 资本成本吗？增长创造价值吗？" | ROIC vs WACC |
| ④ 估值 | "现有资产 + 增长资产" | 简化DCF / 周期平均利润×倍数 |
| ⑤ 保持开放 | "估值随故事更新" | 季度重算 + 每日期价刷新 |

### 1.3 估值方法：三种引擎交叉验证

单一方法不可靠，我用**三套引擎**算出三个价值，取**合理区间**：

| 引擎 | 适用 | 逻辑 | 输出 |
|------|------|------|------|
| **E1 正常化利润×倍数** | 成熟/周期股 | 跨周期平均净利 × 行业合理PE | `val_eps_normal` |
| **E2 简化DCF** | 成长股 | 未来5年利润折现 + 终值 | `val_dcf` |
| **E3 净资产×PB修正** | 银行/地产/保险 | 净资产 × 行业合理PB | `val_bv` |

**最终价值 = 三引擎加权（按生命周期阶段给权重）**：
- 成长股：DCF权重高（50%）、PE法（30%）、PB法（20%）
- 周期股：正常化PE权重高（60%）、DCF（30%）、PB（10%）
- 金融股：PB权重高（60%）、PE（30%）、DCF（10%）

## 3. 数据表设计（DDL）

> 所有表和字段均带 COMMENT 注释，便于后续维护和查询理解。

### 3.1 `ads_dmdl_static` — 财务估值静态表（季度更新）

**只存财报衍生指标（一季度一变），不存任何依赖股价的字段。**

```sql
CREATE TABLE ads_dmdl_static (
  stock_code       VARCHAR(10) NOT NULL COMMENT '股票代码',
  stock_name       VARCHAR(50) COMMENT '股票名称',
  report_date      DATE COMMENT '财报期（季度末）',
  norm_profit_5y   DECIMAL(20,2) COMMENT '5年正常化利润=过去5年归母净利去极值后取中位数',
  ttm_profit       DECIMAL(20,2) COMMENT 'TTM归母净利（最新4季滚动）',
  invested_capital DECIMAL(20,2) COMMENT '投入资本=净资产+有息负债-现金及等价物',
  nopat            DECIMAL(20,2) COMMENT '税后经营利润=核心利润×(1-有效税率)',
  roic             DECIMAL(10,4) COMMENT '投入资本回报率=NOPAT/投入资本',
  wacc             DECIMAL(10,4) COMMENT '加权平均资本成本=Ke×E/(E+D)+Kd×D/(E+D)',
  roic_minus_wacc  DECIMAL(10,4) COMMENT 'ROIC-WACC，增长质量核心检验（>0则增长创造价值）',
  life_stage       VARCHAR(10) COMMENT '生命周期：growth/cycle/finance/turnaround/decline',
  growth_rate      DECIMAL(10,4) COMMENT '未来5年增长率假设（正常化）',
  -- 盈利质量护栏（防纸面利润/造假陷阱）
  net_cash_ratio   DECIMAL(10,4) COMMENT '净现比=经营现金流/归母净利（<0.5警示利润非现金）',
  ar_to_revenue    DECIMAL(10,4) COMMENT '应收/营收（>0.3警示收入靠赊销）',
  goodwill_to_equity DECIMAL(10,4) COMMENT '商誉/净资产（>0.2警示并购减值风险）',
  earnings_quality CHAR(1) COMMENT '盈利质量评级：A=合格 B=存疑 C=高风险',
  -- 三引擎估值
  val_eps_normal   DECIMAL(20,2) COMMENT 'E1正常化利润法估值=正常化利润×行业合理PE（元/股）',
  val_dcf          DECIMAL(20,2) COMMENT 'E2简化DCF估值=5年利润折现+终值折现（元/股）',
  val_bv           DECIMAL(20,2) COMMENT 'E3净资产法估值=归母净资产×行业合理PB（元/股）',
  -- 价值区间（达摩达兰铁律：给区间不给单值）
  val_low          DECIMAL(20,2) COMMENT '悲观情景价值（增长率下调/折现率上调）',
  val_high         DECIMAL(20,2) COMMENT '乐观情景价值（增长率上调/折现率下调）',
  val_final        DECIMAL(20,2) COMMENT '基准情景加权内在价值（元/股）',
  -- 风险扣分（便宜的股票便宜有理由）
  risk_penalty     DECIMAL(5,2) COMMENT '风险扣分0-30：ST/质押高/审计非标/商誉高/现金流差',
  updated_at       DATETIME COMMENT '本行更新时间',
  PRIMARY KEY (stock_code),
  KEY idx_roic (roic_minus_wacc),
  KEY idx_stage (life_stage),
  KEY idx_val (val_final),
  KEY idx_eq (earnings_quality)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='达摩达兰估值-财务静态层（季度更新，不含股价依赖字段）';
```

> **注**：
> 1. `margin_of_safety` 不放这里——它依赖市值（每天变），在视图里实时算。
> 2. 新增的**盈利质量护栏**（净现比/应收/商誉）防止把纸面利润当估值基础（康美/康得新教训）。
> 3. **价值区间** `val_low/val_high/val_final` 给悲观/乐观/基准三档，输出百分位而非单值。
> 4. **风险扣分** `risk_penalty` 用于过滤"低估值垃圾股"。

### 3.2 `ads_dmdl_mkt_daily` — 市场动态表（每日更新）

**只存股价/市值等每日变化字段，与财务静态层彻底解耦。**

```sql
CREATE TABLE ads_dmdl_mkt_daily (
  stock_code     VARCHAR(10) NOT NULL COMMENT '股票代码',
  trade_date     DATE        NOT NULL COMMENT '交易日期',
  close_price    DECIMAL(10,2) COMMENT '当日收盘价',
  total_shares   BIGINT COMMENT '总股本（低频变，随股本变动更新）',
  market_cap     DECIMAL(20,2) COMMENT '总市值=收盘价×总股本',
  pe_ttm         DECIMAL(10,2) COMMENT '市盈率TTM=市值/TTM归母净利',
  pb             DECIMAL(10,2) COMMENT '市净率=市值/归母净资产',
  dividend_yield DECIMAL(10,4) COMMENT '股息率',
  PRIMARY KEY (stock_code, trade_date),
  KEY idx_date (trade_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='达摩达兰估值-市场动态层（每日更新）';
```

### 3.3 `ads_dmdl_sector_val` — 行业估值基准表（每日更新）

**目的**：给每只股票提供"行业内的相对位置"（PE/PB 分位数），也作为 E1/E3 引擎的行业合理 PE/PB 基准。**数据库目前没有现成的行业估值表**，`ads_sector_latest` 只有总市值/总净利（可算行业整体PE），没有 PB、没有行业内分位数——所以新建此表。

```sql
CREATE TABLE ads_dmdl_sector_val (
  sector_code    VARCHAR(10) NOT NULL COMMENT '行业代码',
  sector_name    VARCHAR(50) COMMENT '行业名称',
  trade_date     DATE NOT NULL COMMENT '估值日期',
  stock_count    INT COMMENT '行业内股票数',
  -- 行业整体估值（市值加权）
  sector_pe      DECIMAL(10,2) COMMENT '行业PE=行业总市值/行业总净利',
  sector_pb      DECIMAL(10,2) COMMENT '行业PB=行业总市值/行业总净资产',
  -- 行业内分位数（中位数口径，更稳健）
  pe_median      DECIMAL(10,2) COMMENT '行业内个股PE中位数',
  pe_pctl_low    DECIMAL(10,2) COMMENT '行业内PE 25分位',
  pe_pctl_high   DECIMAL(10,2) COMMENT '行业内PE 75分位',
  pb_median      DECIMAL(10,2) COMMENT '行业内个股PB中位数',
  pb_pctl_low    DECIMAL(10,2) COMMENT '行业内PB 25分位',
  pb_pctl_high   DECIMAL(10,2) COMMENT '行业内PB 75分位',
  -- 行业基准（供 E1/E3 引擎用，可人工校准）
  fair_pe        DECIMAL(10,2) COMMENT '行业合理PE基准（默认=行业中位数，可调）',
  fair_pb        DECIMAL(10,2) COMMENT '行业合理PB基准（默认=行业中位数，可调）',
  PRIMARY KEY (sector_code, trade_date),
  KEY idx_date (trade_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='达摩达兰估值-行业估值基准（每日更新，提供行业内分位数）';
```

> **怎么算**：每日从 `ads_dmdl_mkt_daily` 取全市场 PE/PB，按 `stock_sectors` 归到一级行业，算行业整体 PE/PB + 行业内个股 PE/PB 的 25/50/75 分位数。**行业基准 `fair_pe/fair_pb` 默认取行业中位数，也可按达摩达兰"行业叙事"人工调整**（如新船周期顶部给造船业下调 fair_pe）。

### 3.4 关联视图 — 每只股票的"价值 vs 价格"

**动态字段（低估程度、评分）全部在视图里实时算，静态表和动态表各存各的。**

```sql
CREATE OR REPLACE VIEW v_dmdl_valuation AS
SELECT
  s.stock_code, s.stock_name, s.report_date,
  s.life_stage, s.roic, s.wacc, s.roic_minus_wacc,
  s.earnings_quality, s.risk_penalty,
  s.val_eps_normal, s.val_dcf, s.val_bv, s.val_low, s.val_high, s.val_final,
  m.trade_date, m.close_price, m.market_cap,
  m.pe_ttm, m.pb,
  -- 行业相对位置（PE/PB 在行业内处于什么分位）
  sv.sector_name, sv.sector_pe, sv.sector_pb,
  sv.pe_median, sv.pb_median,
  -- 内在价值区间（亿元）= 静态表存储的总额(元) / 1e8
  ROUND(s.val_low  / 1e8, 2) AS intrinsic_low,
  ROUND(s.val_high / 1e8, 2) AS intrinsic_high,
  ROUND(s.val_final / 1e8, 2) AS intrinsic_value,
  -- 低估程度 = 内在价值/市值 - 1（随市值每日变化）
  ROUND((s.val_final / 1e8 / NULLIF(m.market_cap,0) - 1) * 100, 2) AS margin_of_safety,
  ROUND((s.val_final / 1e8 / NULLIF(m.market_cap,0) - 1) * 100, 2) AS discount_pct,
  -- 综合评分 = 低估 + 增长质量 + 资本回报 − 风险扣分
  GREATEST(0,
    ROUND(
        (CASE WHEN s.val_final / 1e8 > m.market_cap THEN 50 ELSE 0 END)
      + (CASE WHEN s.roic_minus_wacc > 0 THEN 20 ELSE 0 END)
      + (CASE WHEN s.roic > 0.10 THEN 15 ELSE 0 END)
      + (CASE WHEN s.roic_minus_wacc > 0.05 THEN 15 ELSE 0 END)
      - COALESCE(s.risk_penalty, 0),
      0)) AS score
FROM ads_dmdl_static s
JOIN ads_dmdl_mkt_daily m
  ON s.stock_code = m.stock_code
LEFT JOIN ads_dmdl_sector_val sv
  ON sv.sector_code = (SELECT ss.sector_code FROM stock_sectors ss WHERE ss.stock_code = s.stock_code
                       AND ss.category='industry' LIMIT 1)
  AND sv.trade_date = m.trade_date
WHERE m.trade_date = (SELECT MAX(trade_date) FROM ads_dmdl_mkt_daily)
  -- 盈利质量护栏：存疑/高风险一律排除（防纸面利润陷阱）
  AND s.earnings_quality IN ('A','B');
```

> `intrinsic_value`（内在价值总额，亿元）与 `market_cap`（市值，亿元）口径统一后比较；`margin_of_safety` 和 `discount_pct` 是同一公式的两个别名（视图内实时计算，随市值每天变化），`discount_pct` 用于排序展示。`score` 已扣除 `risk_penalty`（0-30分），**默认过滤掉 `earnings_quality='C'` 的高风险股**（仅当你明确想看"便宜有理由"的股票时才放开）。

**设计要点**：
- `ads_dmdl_static` 一季度才更新（财报变了才重算估值），**不含任何市值依赖字段**
- `ads_dmdl_mkt_daily` 每天更新（价格天天变），**只含市值/价格字段**
- `ads_dmdl_sector_val` 每天更新行业基准与分位数，**给每只股票行业相对位置**
- 视图 `v_dmdl_valuation` 永远取"最新静态估值 × 最新市值 × 最新行业基准"，**三表彻底解耦，SQL查一下就有结论**

## 4. 计算逻辑（各指标怎么算）

### 4.1 正常化利润（E1的核心）

```
norm_profit_5y = 过去5个完整年报的归母净利，去掉最高和最低，取中间3年的中位数
```
- 剔除2018/2020这种极端年（如中船防务-18.7亿 / +36.6亿）
- 周期股必须用正常化利润，绝不用单年峰值或谷底

### 4.2 WACC — 加权平均资本成本（资本成本）

**WACC（Weighted Average Cost of Capital）**：公司为筹措所有资金（股东的钱 + 债主的钱）所付出的平均代价，即投资者（股权+债权）要求的平均回报率。它代表"这门生意至少要赚到这个回报率，才算没亏钱"。

```
WACC = Ke × E/(E+D) + Kd × D/(E+D)

其中：
Ke（股权成本）= rf + β × ERP          ← 股东要求的回报（CAPM模型）
  rf（无风险利率）= 10年期国债收益率（约2.0%）
  β（贝塔系数）  = 股票相对市场波动的敏感度，按行业给默认值
  ERP（股权风险溢价）= 5.5%           ← 中国市场股权溢价（达摩达兰常用）
Kd（债权成本）= 借款利率 × (1-税率)    ← 税后债务成本（利息可抵税）
E/(E+D) / D/(E+D) = 股权/债权占资本结构的权重
```

**本模块 WACC 参数表（全市场统一，可调）：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| rf 无风险利率 | 2.0% | 10年期国债收益率 |
| ERP 股权风险溢价 | 5.5% | 达摩达兰中国市场常用值 |
| β（按行业） | 银行0.8 / 消费0.9 / 制造1.0 / 医药1.0 / 科技1.2 / 地产1.3 | 行业默认，可调 |
| Kd 税前债务成本 | 4.0% | 全市场统一 |
| 有效税率 | 25%（高新企业15%） | 从财报所得税/利润总额推算 |

**举例（中船防务）**：rf=2%，β=1.0，ERP=5.5% → Ke=7.5%；Kd=4%×(1-25%)=3%；股权占85%、债权占15% → WACC≈6.8%。即**中船防务的投入资本至少要赚6.8%的回报，才等于覆盖它的资金成本**。

> **理解要点**：WACC 是估值的"折现率"，也是判断增长质量的"及格线"。同一笔投入资本，回报率超过 WACC 越多，创造的股东价值越大。

### 4.3 ROIC — 投入资本回报率（增长质量核心）

**ROIC（Return on Invested Capital）**：公司每一块钱投入资本（股东的钱+债主的钱）实际赚回来的回报率。它衡量的是**公司本身生意的盈利能力**，剔除了财务杠杆的影响。

```
投入资本 = 归母净资产 + 有息负债 − 现金及现金等价物
NOPAT    = 核心利润 × (1 − 有效税率)        ← 税后经营利润（不含利息和金融收益）
ROIC     = NOPAT / 投入资本
```

**各项含义：**
- **投入资本**：经营这门生意真正占用的钱 = 股东投的钱（净资产）+ 借来的钱（有息负债）− 闲钱（现金）。剔除现金是为了看"真正用于经营的资本"。
- **NOPAT**：扣掉税的营业利润（核心利润），不含利息支出（那是对债权人的回报）和投资收益（那是钱生钱，不是经营）。

**举例（中船防务2025）**：
```
投入资本 = 净资产216.9亿 + 有息负债48亿 − 现金139亿 ≈ 126亿
NOPAT    = 核心利润12亿 × (1-25%) ≈ 9亿
ROIC     ≈ 9 / 126 ≈ 7.1%
WACC     ≈ 6.8%（见4.2）
ROIC − WACC ≈ +0.3%   ← 增长大体打平资本成本，创造的价值有限
```

### 4.3.1 ROIC vs WACC — 增长质量检验（达摩达兰最锋利的刀）

**达摩达兰的核心判断标准：增长只有在 ROIC > 资本成本时才创造价值。**

| 情形 | 含义 | 估值影响 |
|------|------|---------|
| **ROIC > WACC** | 每投入1块钱，赚回的回报超过资金成本，**增长在创造价值** | 可给增长溢价（成长股估值） |
| **ROIC = WACC** | 回报恰好覆盖资金成本，**增长创造的价值为零** | 增长不值钱，按现有资产估值 |
| **ROIC < WACC** | 投入越多亏越多，**增长在摧毁价值** | 增长是负资产，估值要打折 |

**通俗类比**：WACC 是"借钱生意的利息率"，ROIC 是"生意本身的收益率"。
- 借100块利息5%（WACC=5%），生意赚回15%（ROIC=15%）→ 每多投入1块就多赚10块，**这个生意值得投**。
- 借100块利息5%，生意只赚回3% → 每多投1块就亏2块，**这个生意越做越亏，增长反而毁灭价值**。

**达摩达兰的提醒**：约70%的上市公司 ROIC 低于资本成本——**多数公司的增长在毁灭价值**。所以看一家公司"增长多快"之前，先看"增长的质量"——ROIC 是不是真的盖过了 WACC。

### 4.4 生命周期阶段（heuristic 分类）

| 判断条件 | 阶段 |
|---------|------|
| 行业是银行/证券/保险 → | `finance`（金融独立，见4.4.1） |
| 5年营收增速>15% 且 ROIC>10% → | `growth` |
| 营收增速 0-15% 且 ROE>8% → | `cycle`（多数制造） |
| 营收负增长 且 净利>0 → | `turnaround` |
| 连续亏损 或 净现金为负 → | `decline` |

#### 4.4.1 为什么金融股要独立成一类（不是普通生命周期阶段）

**一句话**：金融公司的"资产负债表结构"和所有其他行业**根本不同**——在金融股身上，资本成本（WACC）和投入资本（ROIC）这套工具**会失效**，必须用另一套估值语言。

**核心原因：金融公司把"债务"当原材料，而不是当资金来源。**

普通企业（制造业/消费/科技）的资产负债表逻辑：
```
钱从哪来（负债+权益）→ 投到哪去（厂房/设备/存货）→ 赚钱
↑ 负债是"融资手段"，越少越好
```
所以达摩达兰框架用 **WACC（资金成本）** 和 **ROIC（投入资本回报）** 衡量——投入资本 = 净资产+有息负债−现金，这个公式对普通企业成立。

但银行的资产负债表逻辑是**反的**：
```
储户存款（负债）→ 就是它的"存货"和"原材料" → 放贷赚利差
↑ 负债是"经营本身"，不是融资手段
```
- 银行的"投入资本"若按 `净资产+存款−现金` 算，数值巨大且失真——因为**存款是它做生意的原料，不是借来的钱**。
- ROIC 会严重失真（分母含天量存款），WACC 也无从谈起（银行的资金成本就是存贷利差，不是 CAPM 能算的）。
- 对保险/券商同理：负债端（保费/客户保证金）是经营基础，不是杠杆。

**达摩达兰的处理原则**：
1. **金融股不做"企业价值→DCF"**，只做**股权估值**（equity value）——直接估股东的钱，绕开资本结构。
2. **估值以净资产（PB）、ROE、股息折现（DDM）为主**——因为银行的净资产≈真实经营资本，PB 是最自然的锚。
3. **ROIC vs WACC 检验对金融股无意义**——改看 **ROE vs 股权成本（Ke）**：ROE 是银行股东的回报率，Ke 是股东要求的回报，两者对比才有意义。

**落到本模块的落地**：
- 金融股 `life_stage = finance`，三引擎权重切换为 **PB法60% + 正常化PE 30% + DCF 10%**（见1.3）
- 金融股不参与 ROIC-WACC 评分（该项记0分，靠 ROE>Ke 或 PB 低估来拿分）
- 金融股的 `norm_profit_5y` 仍可用（银行盈利相对稳定），但 `val_dcf` 权重极低

**一句话总结**：不是金融股"没有生命周期"，而是**估金融股的根本不能用"投入资本"这套尺子**——它们的负债是经营核心，只能用净资产/ROE/股息这把尺子量。所以必须独立分类，换尺子。

### 4.5 三引擎估值

**E1 正常化利润法**：
```
val_eps_normal = norm_profit_5y × 行业合理PE
行业合理PE：按一级行业给基准（消费25 / 医药30 / 制造15 / 化工18 / 银行6 / 科技35）
```

**E2 简化DCF**（两阶段）：
```
未来5年：利润按 growth_rate 增长，折现率 WACC
终值：第5年利润 × 永续倍数（= 1/(WACC - g)，g=3%）
val_dcf = Σ(第i年利润/(1+WACC)^i) + 终值/(1+WACC)^5
```

**E3 净资产法**：
```
val_bv = 归母净资产 × 行业合理PB
```

**加权**：按 life_stage 给权重（见1.3）。

**价值区间（不是单值）**：
```
val_final = 基准情景加权内在价值（默认参数）
val_low   = 悲观情景（growth_rate下调40%、WACC上调1个百分点）重算
val_high  = 乐观情景（growth_rate上调40%、WACC下调1个百分点）重算
```
输出用 `intrinsic_low / intrinsic_value / intrinsic_high` 三档，达摩达兰铁律——**给区间和百分位，不给单一精确值**。

### 4.6 低估程度 & 评分（视图实时计算）

**`margin_of_safety` 依赖市值（每天变），不落静态表，在 `v_dmdl_valuation` 视图里实时算：**

```
margin_of_safety = (内在价值总额 - 市值) / 市值     -- 内在价值总额=val_final/1e8，每日期价刷新自动更新
score（0-100）= 低估(50) + ROIC>WACC(20) + ROIC>10%(15) + ROIC-WACC>5%(15) − 风险扣分(0-30)
```

- `val_final` 存**内在价值总额（元）**，与 `market_cap`（亿元）换算：`val_final / 1e8` 即内在价值总额（亿元），视图里统一口径后比较
- 静态表存"内在价值总额（元）"，市值每天刷新后，视图自动重算低估幅度——**估值模型季度变，低估幅度天天变**
- **`score` 扣除 `risk_penalty`（见4.8），默认过滤 `earnings_quality='C'`（见4.7）**

### 4.7 盈利质量护栏（防纸面利润/造假陷阱）

**挖低估最大的风险不是估错，而是把纸面利润当估值基础。** 三个检验：

```
净现比      = 经营现金流 / 归母净利
应收/营收   = 应收账款 / 营业收入
商誉/净资产 = 商誉 / 归母净资产

评级规则：
  A（合格）  = 净现比≥0.5 且 应收/营收≤0.3 且 商誉/净资产≤0.2
  B（存疑）  = 上述任一项轻微超标（如净现比0.3-0.5）
  C（高风险）= 净现比<0.3 或 应收/营收>0.5 或 商誉/净资产>0.4，或为ST/审计非标
```

**落地**：视图默认只输出 A/B 级（`earnings_quality IN ('A','B')`）；C 级即使"低估"也隐藏——**康美药业、康得新当年都是"低估"陷阱，净现比和货币资金检验能拦住它们**。

### 4.8 风险扣分（便宜的股票便宜有理由）

**避免挖出一堆"低估值垃圾股"。** `risk_penalty`（0-30分）按以下叠加：

| 风险项 | 扣分 | 判定 |
|--------|------|------|
| ST / *ST | 15 | 股票名称含ST |
| 控股股东质押高 | 8 | 质押率>50%（如数据可得） |
| 商誉占比高 | 5 | 商誉/净资产>30% |
| 经营现金流为负且持续 | 4 | 连续2年净现比<0 |
| 营收/净利连续2年双降 | 3 | 陷入衰退 |

### 4.9 行业内相对位置（PE/PB 分位数）

**判断"便宜"不能全市场一刀切，要在行业内部比：**

```
pe_pctl = 该股PE在行业内所有个股PE中的百分位（越小越便宜）
pb_pctl = 该股PB在行业内所有个股PB中的百分位
```

- 数据来自 `ads_dmdl_sector_val`（每日算行业 PE/PB 的 25/50/75 分位）
- **辅助判断**：一只股全市场看"PE 8倍很便宜"，但若同行业全是 PE 5倍，它其实偏贵——**分位数比绝对值更能识别真低估**
- E1/E3 引擎的 `fair_pe/fair_pb` 默认取行业中位数，避免主观拍脑袋的行业基准

## 6. 输出结论：怎么用这张视图挖低估股

**一句话使用方式**：

```sql
-- 挖低估成长股（过滤C级高风险、过滤微型股、要求ROIC>WACC）
SELECT * FROM v_dmdl_valuation
WHERE score >= 60
  AND market_cap > 50
  AND earnings_quality IN ('A','B')
  AND life_stage IN ('growth','cycle')
ORDER BY discount_pct DESC
LIMIT 30;

-- 行业内的真低估（看分位数而非绝对PE）
SELECT * FROM v_dmdl_valuation
WHERE life_stage = 'cycle'
  AND pe_ttm < pe_median * 0.7   -- 显著低于行业PE中位数
  AND roic_minus_wacc > 0
ORDER BY discount_pct DESC;
```

- **`discount_pct > 0`** → 内在价值高于市值（被低估），越大越低估
- **`score >= 60`** → 既低估、增长又在创造价值（ROIC>WACC）、资本回报高、且扣除风险扣分后仍高
- **`earnings_quality IN ('A','B')`** → 默认过滤C级（净现比差/应收高/商誉高/ST）——**康美式陷阱在这里被拦截**
- **`pe_ttm < pe_median * 0.7`** → 行业内真便宜（低于行业中位数30%），比全市场绝对PE更可靠
- **`life_stage` 过滤** → 只看成长/周期拐点，避开"衰退/困境"假便宜

**达摩达兰的提醒（必须写进结论）**：
1. **低估 ≠ 会涨**——价格回归价值需要时间，"比你能保持偿付能力更久"
2. **便宜有便宜的理由**——大折价往往对应高风险（ST、诉讼、治理），`earnings_quality` 和 `risk_penalty` 就是用来过滤这些"便宜陷阱"的
3. **所有估值都有偏见**——我的正常化利润、WACC、行业PE都是假设，给你的是"我的故事和我的价值，Make it yours"
4. **行业分位比绝对PE重要**——一只股PE 8倍全市场看着便宜，若同行业全是5倍它其实偏贵；看 `pe_median/pb_median` 相对位置才是真低估

## 7. 风险与局限（诚实声明）

1. **A股特殊性**：政策市、涨跌停、壳价值、流动性差，达摩达兰框架基于成熟市场，需结合A股实际调整
2. **数据口径**：金融股、次新股、亏损股的正常化利润/DCF 会失真，以PB法和行业对比为主
3. **WACC参数敏感性**：无风险利率、ERP、β 是全局假设，变化会影响所有估值
4. **正常化利润对数据长度敏感**：上市<5年的次新股，正常化利润用TTM替代
5. **估值≠定价**：若市场在炒情绪/动量（军工重组、AI概念），估值工具失效——只能给出"安全边际"而非"涨跌预测"
