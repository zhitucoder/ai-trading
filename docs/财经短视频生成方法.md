# 财经短视频生成方法

> 文档日期：2026-08-13
> 适用场景：将公司/行业分析内容制作成手机竖屏财经短视频（1-2分钟），带配音
> 示例成品：`video/crrc/crrc-video/renders/crrc_zhongguozhongche_voice.mp4`（中国中车）

---

## 一、技术栈总览

| 环节 | 技术 | 作用 | 依赖 |
|:---|:---|:---|:---|
| 视频合成 | **HyperFrames** (v0.7.107) | 用 HTML 写视频，无头 Chrome 逐帧截图 + FFmpeg 编码 MP4 | node、无头 Chrome、ffmpeg |
| 动画 | **GSAP** (3.14) | 时间轴动画（数字滚动、文字飞入、转场） | 通过 CDN 引入 |
| 配音 | **edge-tts** (微软免费 TTS) | 中文语音合成 | Python + edge_tts 库 |
| 音视频编码 | **FFmpeg** (6.1) | MP3→M4A 转码、音视频合成 | 系统 ffmpeg |

**一句话**：`口播稿 → edge-tts(TTS) → 分场景音频` + `HTML/CSS/GSAP 场景 → HyperFrames render` → `FFmpeg 合成` → 竖屏 MP4（含音轨）。

全程本地生成，**不使用任何付费云服务或 API key**。

---

## 二、调用链（由哪个 skill 驱动）

本项目的视频生成由 **`general-video`（opencode 内置 skill）** 触发并主导：

```
用户请求「生成短视频」
   ↓
skill 加载：general-video（内置 skill，位于 opencode 技能库）
   ↓
路由判断：此场景属"多场景自定义合成 + 口播" → 走 general-video 工作流
   ↓
子技能（参考）：
  ├─ hyperframes-core（视频 HTML 契约：data-* 属性、时间线、媒体规则）
  └─ hyperframes-animation（动画规则：数字滚动、转场目录）
   ↓
工具调用：
  ├─ hyperframes（npm CLI，全局安装）→ 构建/校验/渲染
  ├─ edge-tts（Python 库）→ 生成配音
  └─ ffmpeg（系统工具）→ 编码合成
```

**skill 职责分工**：
- `general-video`：总入口，决定视频结构（场景、节奏、时长），调用 HyperFrames 工具链
- `hyperframes-core`：定义视频 HTML 的规范（root 尺寸、`data-start`/`data-duration`/`data-track-index`、`class="clip"`、audio 必须是 root 直接子元素）
- `hyperframes-animation`：提供动画技术（数字计数动画 `counting-dynamic-scale`、转场 `transitions/catalog.md`）

## 三、环境准备

### 3.1 安装 HyperFrames CLI（需 sudo）

```bash
sudo npm install -g hyperframes@0.7.107
# 验证
npx hyperframes --version   # 应输出 0.7.107
```

> 若报 `deprecated boolean@3.2.0` / `node-domexception` 警告，属正常，忽略即可。

### 3.2 检查系统依赖

```bash
hyperframes doctor
```
- ✅ 必须：Node.js、无头 Chrome（自动下载）、FFmpeg
- ⚠️ 可选：whisper-cpp（语音转写）、Kokoro TTS（本地配音）、MusicGen（背景音乐）——本项目不用

### 3.3 中文字体（关键）

无头 Chrome 默认不含中文字体，需确认系统有：
```bash
fc-list :lang=zh
```
本项目使用系统自带的 **WenQuanYi Micro Hei**（文泉驿微米黑）。在 `index.html` 中：
```css
@font-face {
  font-family: "WenQuanYi Micro Hei";
  src: local("WenQuanYi Micro Hei");
}
body { font-family: "WenQuanYi Micro Hei", sans-serif; }
```

## 四、制作流程

### 4.1 初始化项目（竖屏）

```bash
mkdir -p video/<公司>
cd video/<公司>
HYPERFRAMES_SKIP_SKILLS=1 hyperframes init <项目名> --example blank --resolution portrait --non-interactive
```
- `--resolution portrait` → 1080×1920 手机竖屏
- 生成 `index.html`（主合成文件）、`package.json`、`hyperframes.json`

### 4.2 编写场景（index.html）

核心结构：
```html
<div id="root" data-composition-id="main" data-start="0" data-duration="95"
     data-width="1080" data-height="1920">
  <!-- 场景1 -->
  <div id="scene1" class="scene" style="opacity:1">
    <div class="scene-inner">...画面元素...</div>
  </div>
  <!-- 场景2（初始隐藏） -->
  <div id="scene2" class="scene" style="opacity:0">...</div>
  ...
  <!-- 配音 audio（必须是 root 直接子元素） -->
  <audio id="voice-s1" src="audio/s1.m4a" data-start="0.5"
         data-duration="7.0" data-track-index="20" data-volume="1"></audio>
</div>

<script>
  window.__timelines = window.__timelines || {};
  const tl = gsap.timeline({ paused: true });
  // 动画：进入、数字滚动、转场
  tl.from("#s1-title", { opacity: 0, y: 60, duration: 0.7 }, 1.0);
  // 转场：场景1淡出+场景2淡入
  tl.to("#scene1", { opacity: 0, duration: 0.8 }, 6.0);
  tl.set("#scene1", { visibility: "hidden" }, 6.8);
  tl.fromTo("#scene2", { opacity: 0 }, { opacity: 1, duration: 0.8 }, 6.1);
  window.__timelines["main"] = tl;
</script>
```

**关键规则**（违反会导致静默 bug）：
- root 必须显式设 `width/height`（1080×1920），否则内容塌陷到左上角
- 每个带动画的元素要 `class="clip"` + `data-start` + `data-duration` + `data-track-index`
- **场景退出必须加 `visibility:hidden` 硬杀**（lint 强制），否则拖动时间线会重叠
- `<audio>`/`<video>` 必须直接挂 root，不能包在 div 里，否则无法解码
- 禁用 `Math.random()`/`Date.now()`（非确定性），用 seed
- 中文字体必须 `@font-face` 声明，否则回退西文字体

### 4.3 生成配音（edge-tts）

```python
import asyncio, edge_tts

VOICE = "zh-CN-YunjianNeural"  # 云健：沉稳男声，适合财经
RATE = "-5%"                    # 稍慢，清晰

SCENES = [
    ("s1", "你坐的高铁，可能是它造的。中国中车，全球轨道交通第一。"),
    ("s2", "一年营收两千七百多亿，净利一百三十多亿。……"),
    # 每段对应一个场景
]

async def gen(name, text):
    tts = edge_tts.Communicate(text, VOICE, rate=RATE)
    await tts.save(f"audio/{name}.mp3")

async def main():
    for name, text in SCENES:
        await gen(name, text)

asyncio.run(main())
```

可选音色：
- `zh-CN-YunjianNeural` 云健（男·沉稳）
- `zh-CN-YunxiNeural` 云希（男·年轻）
- `zh-CN-XiaoxiaoNeural` 晓晓（女·自然）
- `zh-CN-XiaoyiNeural` 晓伊（女·温和）

MP3 转 M4A（HyperFrames 解码更稳）：
```bash
ffmpeg -i audio/s1.mp3 -c:a aac -b:a 128k audio/s1.m4a -y
```

### 4.4 校验

```bash
cd <项目>
npx hyperframes check
```
- 目标：0 error、0 warning，Contrast 全部通过
- 若报中文字体失败 → 检查 `fc-list :lang=zh`，改用已安装字体
- 若报 emoji 对比度 → 用单色几何字符（◆●▲■）替代彩色 emoji

### 4.5 渲染

```bash
npx hyperframes render --fps 30 --quality standard --workers 4 -o renders/<名称>.mp4
```
- 输出：`renders/<名称>.mp4`
- 验证：`ffprobe -show_streams` 确认 1080×1920、30fps、有 audio 轨道

## 七、注意事项与坑

1. **sudo 装 npm 包会中断**：装 HyperFrames 要等 `added xxx packages` 出现，别中途切走
2. **中文字体是最大坑**：无头 Chrome 没中文字体 → 必须先 `fc-list :lang=zh` 确认，再用 `@font-face` + `local()` 声明
3. **emoji 对比度误报**：彩色 emoji 无法过 WCAG，改用单色几何字符
4. **场景退出必须 visibility:hidden**：lint 强制，否则拖动时间线场景重叠
5. **音频对齐**：配音时长要实测（`ffprobe -show_entries format=duration`），再填 `data-duration`，避免口型/画面错位
6. **渲染超时**：95 秒视频约需 2 分钟渲染（4 worker），命令用 `timeout 600` 包裹
