## 一、航运运价指数（波罗的海）

### 1.1 数据来源

| 数据 | 来源 | 获取方式 |
|---|---|---|
| BDTI / BCTI / BDI / BCI / BPI | 波罗的海交易所（Baltic Exchange） | **akshare** 免费接口 |

akshare 接口：
- `ak.macro_china_bdti_index()` → BDTI 原油轮运价（VLCC 主要参照）
- `ak.macro_shipping_bcti()` → BCTI 成品油轮运价
- `ak.macro_shipping_bdi()` → BDI 干散货综合
- `ak.macro_shipping_bci()` → BCI 好望角型
- `ak.macro_shipping_bpi()` → BPI 巴拿马型

> ⚠️ **集装箱运价（CCFI/SCFI）**：akshare 无接口，上海航运交易所官网历史数据需登录/订阅，当前**未入库**。如需中远海控（集运）运价分析，需另寻数据源。

### 1.2 数据库表（5 张）

过去 10+ 年波罗的海运价指数已入库，**每张表均带表注释、字段注释、update_time 自动时间戳**：

| 表名 | 指数 | 覆盖范围 | 行数 |
|---|---|---|---|
| `shipping_bdti` | BDTI 原油轮运价（VLCC参照） | 2001~2026 | 6009 |
| `shipping_bcti` | BCTI 成品油轮运价 | 2001~2026 | 6012 |
| `shipping_bdi` | BDI 干散货综合 | 1988~2026 | 9532 |
| `shipping_bci` | BCI 好望角型 | 1999~2026 | 6852 |
| `shipping_bpi` | BPI 巴拿马型 | 1998~2026 | 6815 |

### 1.3 表结构（以 `shipping_bdti` 为例，其余同构）

| 字段 | 类型 | 注释 |
|---|---|---|
| `id` | BIGINT UNSIGNED | 自增主键 |
| `index_code` | VARCHAR(10) | 指数代码（BDTI/BCTI/BDI/BCI/BPI） |
| `trade_date` | DATE | 交易日/报价日期 |
| `close_value` | DECIMAL(12,2) | 运价指数收盘值（点） |
| `pct_chg` | DECIMAL(10,4) | 较上一交易日涨跌幅(%) |
| `update_time` | DATETIME | 本行最后更新时间（自动） |

索引：`UNIQUE KEY uk_code_date (index_code, trade_date)`、`KEY idx_date (trade_date)`

### 1.4 下载脚本

**脚本**：`src/scripts/source/import_freight_index.py`

```bash
python src/scripts/source/import_freight_index.py            # 全量下载入库（幂等，可重复运行）
python src/scripts/source/import_freight_index.py --since 2024-01-01   # 只更新某日期之后的数据
```

**特点**：`INSERT IGNORE` 幂等写入，重复运行不会产生重复数据；自动建表并带表/字段注释。

### 1.5 运价与航运公司对应关系

| 运输市场 | 运价指数 | 对应上市公司 |
|---|---|---|
| 油运（原油/VLCC） | **BDTI** | 招商轮船(601872)、中远海能(600026) |
| 油运（成品油） | BCTI | 招商轮船（少量） |
| 干散货 | BDI / BCI / BPI | 招商轮船（散货船队） |
| 集装箱 | CCFI/SCFI（未入库） | 中远海控(601919) |

**核心结论**：招商轮船、中远海能股价/利润与 BDTI 强相关（月度相关 r≈0.84 / 0.77），BDTI 是油运股定价主变量。

### 2.2 hk_* — 港股数据（Tushare Pro）

| 表 | 内容 | 接口文档 |
|---|---|---|
| `hk_basic` | 港股列表（代码/名称/上市日/币种等） | doc_id=253 |
| `hk_daily` | 港股日线行情（OHLC/涨跌幅/成交量额） | doc_id=192 |
| `hk_income` | 港股利润表（科目长表） | doc_id=389 |
| `hk_balancesheet` | 港股资产负债表（科目长表） | doc_id=390 |
| `hk_cashflow` | 港股现金流量表（科目长表） | doc_id=391 |
| `hk_fina_indicator` | 港股财务指标（宽表） | doc_id=388 |

- **代码格式**：Tushare 港股代码必须 5 位补零 + `.HK`，如 `00883.HK`（用户输入 `0883` 脚本会自动补零）
- **三张财报表为"科目长表"**：每行一个财务科目（`ind_name` 科目名 + `ind_value` 科目值），主键 `(ts_code, end_date, ind_name)`
- **hk_fina_indicator 为宽表**：每股指标/盈利质量/同比增长等指标，主键 `(ts_code, end_date, report_type)`
- **幂等**：所有表带 UNIQUE 约束 + `INSERT ... ON DUPLICATE KEY UPDATE`，重复运行零重复
- **同步断点**：`hk_sync_state` 记录增量续传位置（如 `hk_daily_last_date`）与历史进度（`hk_daily_his_{ts_code}`）

**同步策略（hk_daily）**
- 历史数据：按 `ts_code` 逐个股票下载，按 15 年时间窗分页（单次接口上限 5000 行），每个窗口完成后写断点，中断可续传
- 增量数据：按 `trade_date` 逐日下载全港股行情，从断点日期次日起续传，只保留跟踪股票（`DEFAULT_CODES`）的行情行
- 接口限频（当前账号 hk_daily 为 1次/小时）：脚本遇到限频自动等待 1 小时后重试，不中断整体进度

**更新命令**
```bash
python src/scripts/source/import_hk_tushare.py --all                      # 列表+历史行情+财报
python src/scripts/source/import_hk_tushare.py --basic                    # 仅港股列表
python src/scripts/source/import_hk_tushare.py --daily-his                # 历史行情（按股票，断点续传）
python src/scripts/source/import_hk_tushare.py --daily-inc                # 增量行情（按日期，断点续传）
python src/scripts/source/import_hk_tushare.py --financial                # 财报（利润表/资产负债/现金流/指标）
python src/scripts/source/import_hk_tushare.py --codes 00883.HK --daily-his   # 指定股票历史行情
```

**数据管理页一键更新**（`POST /api/data/update-hk-*`，后台运行）
- `update-hk-basic` — 港股列表
- `update-hk-daily` — 行情·每日（增量，mode 参数可切换 his 历史）
- `update-hk-financial` — 财报·季度
- 状态查询：`GET /api/data/hk/status`

> ⚠️ **权限注意**：`hk_income / hk_balancesheet / hk_cashflow / hk_fina_indicator` 为 Tushare 单独开通权限的接口，当前账号无权限（报「您没有接口访问权限」），需在 Tushare 平台为该 token 开通；`hk_daily` 当前账号限频 1次/小时。
