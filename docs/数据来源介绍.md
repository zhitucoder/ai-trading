## 一、航运运价指数（波罗的海）

### 1.1 数据来源

| 数据 | 来源 | 获取方式 |
|---|---|---|
| BDTI / BCTI / BDI / BCI / BPI | 波罗的海交易所（Baltic Exchange） | **akshare** 免费接口 |

akshare 接口：
- `ak.macro_china_bdti_index()` → BDTI 原油轮运价（VLCC 主要参照）
- `ak.macro_shipping_bcti()` → BCTI 成品油轮运价
- `ak.macro_shipping_bdi()` → BDI 干散货综合
- `ak.macro_shipping_bci()` → BCI 好望角型
- `ak.macro_shipping_bpi()` → BPI 巴拿马型

> ⚠️ **集装箱运价（CCFI/SCFI）**：akshare 无接口，上海航运交易所官网历史数据需登录/订阅，当前**未入库**。如需中远海控（集运）运价分析，需另寻数据源。

### 1.2 数据库表（5 张）

过去 10+ 年波罗的海运价指数已入库，**每张表均带表注释、字段注释、update_time 自动时间戳**：

| 表名 | 指数 | 覆盖范围 | 行数 |
|---|---|---|---|
| `shipping_bdti` | BDTI 原油轮运价（VLCC参照） | 2001~2026 | 6009 |
| `shipping_bcti` | BCTI 成品油轮运价 | 2001~2026 | 6012 |
| `shipping_bdi` | BDI 干散货综合 | 1988~2026 | 9532 |
| `shipping_bci` | BCI 好望角型 | 1999~2026 | 6852 |
| `shipping_bpi` | BPI 巴拿马型 | 1998~2026 | 6815 |

### 1.3 表结构（以 `shipping_bdti` 为例，其余同构）

| 字段 | 类型 | 注释 |
|---|---|---|
| `id` | BIGINT UNSIGNED | 自增主键 |
| `index_code` | VARCHAR(10) | 指数代码（BDTI/BCTI/BDI/BCI/BPI） |
| `trade_date` | DATE | 交易日/报价日期 |
| `close_value` | DECIMAL(12,2) | 运价指数收盘值（点） |
| `pct_chg` | DECIMAL(10,4) | 较上一交易日涨跌幅(%) |
| `update_time` | DATETIME | 本行最后更新时间（自动） |

索引：`UNIQUE KEY uk_code_date (index_code, trade_date)`、`KEY idx_date (trade_date)`

### 1.4 下载脚本

**脚本**：`src/scripts/source/import_freight_index.py`

```bash
python src/scripts/source/import_freight_index.py            # 全量下载入库（幂等，可重复运行）
python src/scripts/source/import_freight_index.py --since 2024-01-01   # 只更新某日期之后的数据
```

**特点**：`INSERT IGNORE` 幂等写入，重复运行不会产生重复数据；自动建表并带表/字段注释。

### 1.5 运价与航运公司对应关系

| 运输市场 | 运价指数 | 对应上市公司 |
|---|---|---|
| 油运（原油/VLCC） | **BDTI** | 招商轮船(601872)、中远海能(600026) |
| 油运（成品油） | BCTI | 招商轮船（少量） |
| 干散货 | BDI / BCI / BPI | 招商轮船（散货船队） |
| 集装箱 | CCFI/SCFI（未入库） | 中远海控(601919) |

**核心结论**：招商轮船、中远海能股价/利润与 BDTI 强相关（月度相关 r≈0.84 / 0.77），BDTI 是油运股定价主变量。

### 2.1 crude_oil_daily — WTI与布伦特原油日线

| 字段 | 类型 | 说明 |
|---|---|---|
| variety | VARCHAR(10) | 品种: WTI / Brent |
| trade_date | DATE | 交易日期 |
| open_price | DECIMAL(10,2) | 开盘价(美元/桶) |
| high_price | DECIMAL(10,2) | 最高价(美元/桶) |
| low_price | DECIMAL(10,2) | 最低价(美元/桶) |
| close_price | DECIMAL(10,2) | 收盘价(美元/桶) |
| volume | BIGINT | 成交量(手) |
| position | BIGINT | 持仓量(手) |
| settlement_price | DECIMAL(10,2) | 结算价(美元/桶) |
| source | VARCHAR(20) | 数据来源(akshare_sina) |
| update_time | DATETIME | 更新时间(自动维护) |

- WTI 数据范围: 1996-09-09 ~ 至今（主力连续）
- Brent 数据范围: 2016-09-08 ~ 至今（主力连续）
- 更新命令: `python src/scripts/source/import_crude_oil.py`（增量）/ `--force`（全量重建）/ `--since 2026-01-01`（指定日期起）
