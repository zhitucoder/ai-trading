# 画像筛选：基金持仓增减序列（列式）+ 派生统计 设计方案

## 1. 需求

基于 `ads_stock_fund`（个股×季度基金持仓预计算表）新增筛选指标，加入画像筛选页：

- 每个**完整披露季度**（Q2 半年报 / Q4 年报，`report_type='F'`）相对上个完整季度计算**持股数量增减**：增=+1，减=-1，一个股票一行、各季度一列。
- 各完整披露季度**持仓基金家数**逐季一列（`fc21Q2…fc26Q2`），列表展示最近两个完整季度（25Q4、26Q2）家数。
- 派生统计列（固化，供筛选直接使用）：
  - 最近 8 个两季度增量中 **+1 的个数** `recent8_up`
  - 最近 8 个两季度**净增数** `recent8_net`（= 2×recent8_up − 8）
  - 最近 6 个两季度 +1 个数 `recent6_up`
  - 最近 4 个两季度 +1 个数 `recent4_up`
  - 最长连续增长(增量=1)季度数 `max_consec_growth`
  - 最长连续减少(增量=-1)季度数 `max_consec_decline`
  - 最近 2/4 完整季度持仓基金家数均值 `recent2q_fund_count` / `recent4q_fund_count`
  - 最近 1 个完整季度(最新Q2/Q4)持仓基金家数 `recent1q_fund_count`
  - 最近 1 个完整季度家数 相对上一完整季度 的同比% `recent1q_fund_growth`（26Q2 vs 25Q4，单季对单季）
  - 最近 8 完整季度持股量均值 `recent8q_amount`

> 仅用 **Q2（0630）与 Q4（1231）**——这两个报告期披露全部持仓；Q1/Q3 只披露前十大重仓（`report_type='Q'`），不参与趋势统计。

---

## 2. 数据源与口径

- 主表：`ads_stock_fund`（22 季度，2021Q1–2026Q2，88,470 行）
- 参与统计的完整披露点（11 个）：`21Q2, 21Q4, 22Q2, 22Q4, 23Q2, 23Q4, 24Q2, 24Q4, 25Q2, 25Q4, 26Q2`
- **持股数量** = `total_amount`；**持仓基金数** = `fund_count`
- **增量定义**：`dX = sign(amount(X) - amount(prev完整点))`，+1 / −1；首个完整点（21Q2）无前值 → 无增量列。
- **缺失季度口径**：所有统计按**全局固定报告期对齐**（21Q2…26Q2，11 个完整披露点）。某股票在某个完整披露期**无持仓记录**（如 26Q2 无基金持仓）→ 该期家数/持股量按 **0** 处理，增量与同比照常计算（0 vs 上期，通常为 -1 / 负增长），**不得**用上一期顶替。

当前 11 个完整点 → **10 个增量区间**：

| 增量列 | 区间 | 增量列 | 区间 |
|---|---|---|---|
| d21Q4 | 21Q2→21Q4 | d24Q4 | 24Q2→24Q4 |
| d22Q2 | 21Q4→22Q2 | d25Q2 | 24Q4→25Q2 |
| d22Q4 | 22Q2→22Q4 | d25Q4 | 25Q2→25Q4 |
| d23Q2 | 22Q4→23Q2 | d26Q2 | 25Q4→26Q2 |
| d23Q4 | 23Q2→23Q4 | | |

**最近 8 个两季度** = 最新 8 个增量区间（`d23Q2` 至 `d26Q2`）。

## 3. 表设计：`ads_stock_fund_trend`

```sql
CREATE TABLE ads_stock_fund_trend (
  stock_code           VARCHAR(10) NOT NULL PRIMARY KEY COMMENT '股票代码',
  -- 增量列：每完整季度(Q2/Q4)一列，相对上个完整季度 1=增 -1=减
  -- 从 d21Q4 开始，每半年动态新增（compute 时检测缺列自动 ALTER 补齐）
  d21Q4 TINYINT, d22Q2 TINYINT, d22Q4 TINYINT, d23Q2 TINYINT, d23Q4 TINYINT,
  d24Q2 TINYINT, d24Q4 TINYINT, d25Q2 TINYINT, d25Q4 TINYINT, d26Q2 TINYINT,
  -- 各完整披露季度持仓基金家数（逐季一列）
  fc21Q2 INT, fc21Q4 INT, fc22Q2 INT, fc22Q4 INT, fc23Q2 INT,
  fc23Q4 INT, fc24Q2 INT, fc24Q4 INT, fc25Q2 INT, fc25Q4 INT, fc26Q2 INT,
  -- 派生统计列
  recent8_up          INT COMMENT '最近8个两季度增量中+1个数',
  recent8_net         INT COMMENT '最近8个两季度净增数(2×recent8_up-8)',
  recent6_up          INT COMMENT '最近6个两季度增量中+1个数',
  recent4_up          INT COMMENT '最近4个两季度增量中+1个数',
  max_consec_growth   INT COMMENT '最长连续增长(增量=1)季度数, 0=无',
  max_consec_decline  INT COMMENT '最长连续减少(增量=-1)季度数, 0=无',
  recent2q_fund_count INT COMMENT '最近2个完整季度持仓基金家数均值',
  recent4q_fund_count INT COMMENT '最近4个完整季度持仓基金家数均值',
  recent1q_fund_count INT COMMENT '最近1个完整季度(最新Q2/Q4)持仓基金家数',
  prev1q_fund_count  INT COMMENT '上一个完整季度持仓基金家数',
  recent1q_fund_growth DECIMAL(10,2) COMMENT '最近1季度家数同比%=(recent1q_fund_count-prev1q_fund_count)/prev1q_fund_count×100, prev1q=0时NULL(单季对单季: 26Q2 vs 25Q4)',
  recent8q_amount     DECIMAL(20,4) COMMENT '最近8个完整季度持股量均值(股)',
  prev2q_fund_count   INT COMMENT '上一个两季度(最新2完整点之前的再往前2个完整点)家数均值',
  recent2q_fund_growth DECIMAL(10,2) COMMENT '最近两季度家数增长率%=(recent2q_fund_count-prev2q_fund_count)/prev2q_fund_count×100, prev2q=0时NULL',
  update_time         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
                      ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  KEY idx_r8up (recent8_up),
  KEY idx_r8net (recent8_net),
  KEY idx_r6up (recent6_up),
  KEY idx_r4up (recent4_up),
  KEY idx_mcg (max_consec_growth),
  KEY idx_mcd (max_consec_decline),
  KEY idx_r2g (recent2q_fund_growth)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4
  COMMENT='个股基金持仓季度增减序列(列式+1/-1)+派生统计(画像筛选预计算, 源=ads_stock_fund)'
```

**设计要点**
- 列式增量（±1）信息无损：任意窗口/规则均可用 SQL 现算，无需改表。
- 派生统计列固化：`recent8_up >= N`、`max_consec_growth >= N` 直接过滤，带索引。
- 每股一行（~5.5k 行），窄列值 1 字节，存储可忽略。
- 每半年新增增量列：`compute_stock_fund_trend()` 先 `SHOW COLUMNS` 检测，缺列即 `ALTER TABLE ADD COLUMN dXXXX TINYINT`，并重算派生列。

## 4. 计算实现（compute_ads.py 新增 Step 6）

```python
def ensure_trend_columns(cur):
    # 现有增量列，如 d23Q4；新季度出现则 ALTER 补齐
    # (SHOW COLUMNS FROM ads_stock_fund_trend) -> 需要列集合
    # for 缺列: ALTER TABLE ads_stock_fund_trend ADD COLUMN dXXXX TINYINT

def compute_stock_fund_trend(conn, cur, log):
    ensure_trend_columns(cur)  # 建表后首次全量、后续增量补列
    cur.execute("SELECT stock_code, end_date, report_type, fund_count, total_amount
                 FROM ads_stock_fund WHERE report_type='F' ORDER BY stock_code, end_date")
    groups = {}   # stock_code -> [ {quarter, amount, fund_count} ] 升序
    for r in rows: groups.setdefault(...).append(...)

    rows_out = []
    for code, pts in groups.items():
        # 增量序列
        deltas = []            # [(d列名, ±1)]
        for i in range(1, len(pts)):
            diff = pts[i].amount - pts[i-1].amount
            deltas.append((dname(pts[i].quarter), 1 if diff >= 0 else -1))
        # 最近8个两季度 = 最新8个增量
        recent8 = deltas[-8:]
        recent8_up = sum(1 for _, v in recent8 if v == 1)
        recent8_net = 2 * recent8_up - len(recent8)
        recent6_up = sum(1 for _, v in deltas[-6:] if v == 1)
        recent4_up = sum(1 for _, v in deltas[-4:] if v == 1)
        # 最长连续
        max_cg = max_consec(deltas, 1)
        max_cd = max_consec(deltas, -1)
        # 家数/持股均值（按全局固定报告期对齐，缺失季度填 0）
        aligned = [(q, fc_map.get(q, (0, 0))[0], fc_map.get(q, (0, 0))[1]) for q in FULL_QUARTERS]
        fc_vals = [v[1] for v in aligned]   # 各季度家数逐季一列
        recent1q_count = round(fc(pts[-1]))   # 最近1个完整季度(最新点)
        prev1q_count = round(fc(pts[-2])) if len(pts) >= 2 else 0          # 上一个完整季度
        r1q_growth = (recent1q_count - prev1q_count) / prev1q_count * 100 if prev1q_count > 0 else None  # 单季同比
        recent2q_count = round(mean(fc for recent_pts[-2:]))
        recent4q_count = round(mean(fc for recent_pts[-4:]))
        recent8q_amt  = mean(amt for recent_pts)
        # 上一个两季度家数均值 + 增长率%
        prev2q_count = round(mean(fc for recent_pts[-4:-2]))
        growth = (recent2q_count - prev2q_count) / prev2q_count * 100 if prev2q_count > 0 else None
        rows_out.append((code, *[dict(deltas).get(col) for col in D_COLS], *fc_vals, recent8_up, ...,
                         recent1q_count, prev1q_count, r1q_growth, prev2q_count, growth))
    cur.executemany("INSERT ... ON DUPLICATE KEY UPDATE ...", rows_out)
    conn.commit()
```

- drop 列表追加 `'ads_stock_fund_trend'`；`log('Step 6/6: ads_stock_fund_trend ...')`；返回值追加 `'stock_fund_trend': n`。
- 全量扫描 `report_type='F'` 一次（约 5 万行内存分组），`executemany` UPSERT，耗时 < 5s。

## 5. 画像筛选接口（profile.py）

### 5.1 SearchRequest 新增字段

```python
fund_recent8_up_min: Optional[int] = None   # 最近8个两季度 增≥N
fund_recent8_net_min: Optional[int] = None  # 最近8个两季度 净增≥N
fund_recent6_up_min: Optional[int] = None   # 最近6个两季度 增≥N
fund_recent4_up_min: Optional[int] = None   # 最近4个两季度 增≥N
fund_consec_growth_min: Optional[int] = None  # 最长连增≥N
fund_consec_decline_min: Optional[int] = None # 最长连减≥N
recent2q_fund_count_min: Optional[int] = None
recent2q_fund_count_max: Optional[int] = None
recent4q_fund_count_min: Optional[int] = None
recent4q_fund_count_max: Optional[int] = None
recent1q_fund_count_min: Optional[int] = None
recent1q_fund_count_max: Optional[int] = None
recent8q_amount_min: Optional[float] = None   # 亿股
fund_holding_growth_min: Optional[float] = None  # 最近1季度家数同比% ≥ (26Q2 vs 25Q4)
fund_holding_growth_max: Optional[float] = None  # 最近1季度家数同比% ≤
```

### 5.2 查询组装

任一字段命中 → `JOIN ads_stock_fund_trend ft ON ft.stock_code = p.stock_code`，条件如：

```python
conditions.append('ft.recent8_up >= %(fund_recent8_up_min)s')
conditions.append('ft.max_consec_growth >= %(fund_consec_growth_min)s')
conditions.append('ft.recent1q_fund_growth IS NOT NULL AND ft.recent1q_fund_growth >= %(fund_holding_growth_min)s')
conditions.append('ft.recent1q_fund_growth IS NOT NULL AND ft.recent1q_fund_growth <= %(fund_holding_growth_max)s')
```

SELECT 追加展示列（`recent8_up, recent8_net, max_consec_growth, max_consec_decline, recent2q_fund_count, recent4q_fund_count, recent8q_amount`）。排序白名单加入 `recent8_up / recent8_net / max_consec_growth / recent4q_fund_count / recent8q_amount`。
