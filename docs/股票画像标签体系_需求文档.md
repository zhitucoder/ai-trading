# 股票画像标签体系 —— 基于张新民战略视角财务报表分析框架

> 版本：v1.0 | 日期：2026年7月

---

## 一、背景与目标

### 1.1 为什么需要标签体系

现有选股系统（MA多头排列、基本面筛选）只能回答"哪些股票满足某个条件"，但不能回答"这家公司是什么样的公司"。标签体系的目标是：

- **一眼看懂**一家公司的财务特征：是轻资产还是重资产？造血还是输血？高毛利还是薄利？
- **快速分类**：同一类型的公司可以横向对比
- **风险预警**：资产质量差、现金流恶化等标签能提前发现问题

### 1.2 设计原则

1. **基于张新民框架**：所有标签从六个维度（资产质量、利润质量、现金流质量、偿债能力、成长性、风险）出发
2. **数据驱动**：每个标签有明确的数据库计算公式，可自动计算
3. **分层设计**：顶层标签（如"轻资产"）→ 子标签（如"固定资产占比<15%"）→ 指标值
4. **阈值可配置**：标签的判定阈值随行业和周期可调整

## 二、标签体系总览

### 2.1 底层逻辑：张新民的"面子/日子/底子"叙事

标签体系的设计不是堆砌指标，而是基于张新民框架的三个核心问题：

| 张新民框架 | 对应报表 | 画像揭示的问题 |
|:---|:---|:---|
| **面子** | 利润表 | 企业赚不赚钱？利润来自哪里？（经营/投资/营业外） |
| **日子** | 现金流量表 | 日子过得紧不紧？现金流能不能覆盖经营和投资？ |
| **底子** | 资产负债表 | 家底厚不厚？资产结构合理吗？是不是靠输血活着？ |

**三大匹配检查**（张新民框架的核心诊断工具）：

| 匹配检查 | 公式 | 揭示的问题 |
|:---|:---|:---|
| ① 固定资产→营收 | 营收 / 固定资产 | 产能是否有效利用？投入的设备产出够不够？ |
| ② 营收→核心利润 | 核心利润 / 营收 | 营收有没有转化为利润？费用控制如何？ |
| ③ 核心利润→OCF | OCF / 核心利润 | 利润有没有变成现金？是不是"纸面富贵"？ |

这三个匹配是打通三张报表的诊断逻辑——只看任何一张报表都会片面。

### 2.2 六维标签结构

```
股票画像
├── 维度一：资产结构（钱花到哪去了）
│   ├── 经营主导型 / 投资主导型
│   ├── 轻资产 / 中资产 / 重资产
│   ├── 现金充裕 / 现金紧张
│   ├── 存货风险低 / 存货风险高
│   └── 合同负债高 / 合同负债正常 / 合同负债低
├── 维度二：资本结构（钱从哪来）
│   ├── 造血型 / 输血型 / 均衡型
│   ├── 低杠杆 / 中杠杆 / 高杠杆
│   └── 零有息负债 / 有息负债可控 / 有息负债偏高
├── 维度三：利润质量（赚的钱实在吗）
│   ├── 高毛利 / 中毛利 / 低毛利
│   ├── 价值创造型 / 价值整合型 / 会计调整型
│   ├── 核心利润占比高 / 核心利润占比低
│   └── 盈利 / 微利 / 亏损
├── 维度四：现金流质量（日子过得好吗）
│   ├── 现金奶牛 / 纸面富贵 / 失血状态
│   ├── OCF覆盖投资 / OCF不足
│   └── 自由现金流充裕 / 自由现金流为负
├── 维度五：成长性（增长质量如何）
│   ├── 爆发增长 / 稳健增长 / 缓慢增长 / 衰退
│   ├── 增收增利 / 增收不增利 / 减收减利
│   └── 业绩驱动 / 估值驱动 / 故事驱动
├── 维度六：风险信号（哪里可能出问题）
│   ├── 存货风险 / 应收风险 / 商誉风险
│   ├── 高负债 / 短债长投 / 现金流不匹配
│   └── 毛利率下降 / 营收增速放缓
└── 综合评级
    ├── 优秀 / 良好 / 中等 / 中下 / 差
    └── 典型模式（如"轻资产高毛利现金奶牛"）
```

## 三、详细标签定义与计算公式

### 3.1 资产结构维度

#### 标签：经营主导型 / 投资主导型

| 标签 | 判定条件 | 说明 |
|:---|:---|:---|
| 经营主导型 | 经营资产 / 总资产 > 70% | 钱主要用于生产经营（固定资产、存货、应收） |
| 投资主导型 | 投资资产 / 总资产 > 30% | 钱主要用于对外投资（长期股权投资、金融资产） |

**计算公式：**
- 经营资产 = 总资产 − 交易性金融资产 − 可供出售金融资产 − 持有至到期投资 − 长期股权投资
- 简化版：经营资产率 = 1 − (交易性金融资产 + 长期股权投资) / 总资产

> 注意：A股数据库通常只有"交易性金融资产"字段明确可识别为投资资产。其他投资资产需要结合具体科目判断。

#### 标签：轻资产 / 中资产 / 重资产

| 标签 | 判定条件 |
|:---|:---|
| 轻资产 | 固定资产 / 总资产 < 15% |
| 中资产 | 固定资产 / 总资产 15%~30% |
| 重资产 | 固定资产 / 总资产 > 30% |

**计算公式：** `固定资产 ÷ 总资产 × 100%`

**案例数据（2025年报）：**

| 公司 | 固定资产/总资产 | 标签 |
|:---|:---:|:---:|
| 香农芯创 | 0.6% | 轻资产 |
| 寒武纪 | 2.8% | 轻资产 |
| 艾力斯 | 6.5% | 轻资产 |
| 中际旭创 | 15.6% | 中资产 |
| 天孚通信 | 17.3% | 中资产 |
| 中芯国际 | 37.1% | 重资产 |
| 金石资源 | 39.4% | 重资产 |
| 博俊科技 | 32.9% | 重资产 |

#### 标签：现金充裕 / 现金紧张

| 标签 | 判定条件 |
|:---|:---|
| 现金充裕 | 货币资金 / 总资产 > 15% 且 货币资金 > 短期借款×1.5 |
| 现金正常 | 货币资金 / 总资产 5%~15% 且 货币资金 > 短期借款 |
| 现金紧张 | 货币资金 < 短期借款 |

**计算公式：** `货币资金 / 短期借款`（简单偿债覆盖比）

#### 标签：存货风险低 / 存货风险高

| 标签 | 判定条件 |
|:---|:---|
| 存货风险低 | 存货 / 营收 < 15% |
| 存货风险中 | 存货 / 营收 15%~30% |
| 存货风险高 | 存货 / 营收 > 30% |

**计算公式：** `存货 ÷ 营业收入 × 100%`

#### 标签：合同负债高 / 合同负债正常 / 合同负债低

这是张新民框架中一个容易被忽视但极其重要的指标——**合同负债（预收账款）反映的是企业在产业链中的话语权和未来营收的能见度。**

| 标签 | 判定条件 | 行业适用 |
|:---|:---|:---|
| 合同负债高 | 合同负债 / 总资产 > 15% | 造船、装备制造、工程总包 |
| 合同负债正常 | 合同负债 / 总资产 5%~15% | 多数制造企业 |
| 合同负债低 | 合同负债 / 总资产 < 5% | 零售、消费品 |
| 预收款能力强 | 合同负债 / 营收 > 30% | 客户提前付款，锁定订单 |

**计算公式：** `合同负债 ÷ 总资产 × 100%`

> **关于数据库字段**：2018年新收入准则后，"预收账款"拆分为"合同负债"和"预收账款"。当前 `fin_balance_sheet` 表可能没有独立的 `contract_liabilities` 字段。实际使用时需检查数据库字段，若无则需从原始财报提取或新增字段。

**为什么这个指标重要？**

合同负债本质上是**客户提前付的钱**——东西还没交付，钱已经到账了。对于分析企业来说，这是比应收账款更"优质"的负债：

- **营收能见度**：合同负债高意味着在手订单充足，未来1-2年的营收有保障
- **产业链话语权**：能让客户提前付款的企业，在产业链中处于强势地位
- **造血能力**：合同负债属于经营性负债，是"造血"的重要组成部分

**案例对比：中国船舶 vs 光模块三剑客**

| 公司 | 合同负债特征 | 财务含义 |
|:---|:---|:---|
| **中国船舶** | 在手订单超3000亿，合同负债可能是最大单项负债 | 订单能见度3-5年，但交付周期长 |
| **中际旭创** | 合同负债极低（零或接近零） | 光模块交付周期短（月级别），不需要提前收款 |
| **天孚通信** | 合同负债极低 | 行业惯例，但不影响其优质地位 |

中国船舶（600150）的合同负债动辄数百亿，占总资产比例极高——这是造船行业的特殊性（船舶制造周期2-5年，船东通常预付20-30%的合同款）。如果不看合同负债，只看应付账款和短期借款，会严重低估中国船舶的"造血"能力。

用张新民的框架看：**合同负债是"好的负债"，是中国船舶在产业链中强势地位的体现。** 同样负债率高，中国船舶的负债构成（大量合同负债）和帝科股份的负债构成（大量短期借款）有本质区别。

### 3.2 资本结构维度

#### 标签：造血型 / 输血型 / 均衡型

这是张新民框架的核心标签——判断企业的钱是靠**自己赚来的**（造血）还是**外部借来的**（输血）。

**张新民的原意：**

资产负债表的右边可以重构为四大动力来源：

```
┌─────────────────────────────────────┐
│         总负债 + 权益               │
├─────────────┬───────────────────────┤
│  造血来源   │    输血来源           │
│  (不用付息) │    (需要付息或回报)    │
├─────────────┼───────────────────────┤
│ 经营性负债  │ 金融性负债            │
│ 应付账款    │ 短期借款              │
│ 应付票据    │ 长期借款              │
│ 预收账款    │                      │
│ 合同负债    │                      │
│ 应付职工薪酬│                      │
│ 应交税费    │                      │
├─────────────┼───────────────────────┤
│ 利润积累    │ 股东入资              │
│ 盈余公积    │ 股本                  │
│ 未分配利润  │ 资本公积              │
├─────────────┴───────────────────────┤
│ 少数股东权益（单独列示）            │
└─────────────────────────────────────┘
```

**计算公式（正确版）：**

```python
造血来源 = 经营性负债 + 利润积累
         = (应付账款 + 应付票据 + 合同负债 + 应付职工薪酬 + 应交税费 + 其他应付款等)
           + (盈余公积 + 未分配利润)

输血来源 = 金融性负债 + 股东入资
         = (短期借款 + 长期借款 + 应付债券)
           + (股本 + 资本公积)

# ✅ 正确分母：造血来源 + 输血来源（排除少数股东权益、递延所得税等）
造血占比 = 造血来源 / (造血来源 + 输血来源) × 100%
输血占比 = 输血来源 / (造血来源 + 输血来源) × 100%

# ❌ 错误分母：总负债 + 权益（包含了少数股东权益，会产生"缺口"）
```

> **为什么分母不能用总负债+权益？** 因为资产负债表的右边除了造血和输血两大来源，还有少数股东权益、递延所得税负债、递延收益等科目，这些不属于"造血"也不属于"输血"。用总资产做分母会造成造血占比 + 输血占比 < 100%，出现一个解释不了的"缺口"。

**简化版（基于数据库现有字段，不计细分项）：**
```python
造血来源 ≈ 应付账款 + 盈余公积 + 未分配利润  # 无法拆分的经营负债归入"其他"
输血来源 ≈ 短期借款 + 长期借款 + 股本 + 资本公积
造血占比 = 造血来源 / (造血来源 + 输血来源) × 100%
```

**案例数据（按正确公式计算）：**

| 公司 | 造血来源(亿) | 输血来源(亿) | 造血占比 | 标签 | 备注 |
|:---|:---:|:---:|:---:|:---:|:---|
| 新易盛 | 230.26 | 25.66 | **90%** | 造血型 | 利润积累151亿碾压股东入资26亿 |
| 天孚通信 | 46.58 | 17.30 | **73%** | 造血型 | 造血是输血的2.7倍 |
| 香农芯创 | 83.85 | 33.48 | **71%** | 造血型 | 虽然短期借款高但利润积累更多 |
| 中际旭创 | 321.52 | 100.29 | **76%** | 造血型 | 利润积累206亿，对外部融资依赖低 |
| 金石资源 | 30.73 | 38.00 | **45%** | 均衡型 | 借款29.5亿拉高了输血占比 |
| 寒武纪 | 10.87 | 116.92 | **9%** | 输血型 | 资本公积113亿占绝对主导，刚刚扭亏 |
| 中芯国际 | 858.11 | 1,766.29 | **33%** | 输血型 | 长期借款703亿+资本公积1027亿 |

**这7个案例展示了从"纯输血"(9%)到"纯造血"(90%)的全光谱。** 寒武纪是典型"烧钱扩张"模式——10份钱里9份是外面融来的，只有1份是自己赚的。新易盛是另一个极端——10份钱里9份是自己造血，完全不依赖外部融资。

#### 标签：低杠杆 / 中杠杆 / 高杠杆

| 标签 | 判定条件 |
|:---|:---|
| 零杠杆 | 有息负债率 = 0% |
| 低杠杆 | 有息负债率 0%~10% |
| 中杠杆 | 有息负债率 10%~25% |
| 高杠杆 | 有息负债率 > 25% |

**计算公式：** `(短期借款 + 长期借款) ÷ 总资产 × 100%`

**案例数据：**

| 公司 | 有息负债率 | 标签 |
|:---|:---:|:---:|
| 新易盛、艾力斯、天孚通信、合康新能 | 0% | 零杠杆 |
| 中际旭创 | 1.8% | 低杠杆 |
| 中芯国际 | 20.1% | 中杠杆 |
| 博俊科技 | 20.7% | 中杠杆 |
| 金石资源 | 39.0% | 高杠杆 |
| 帝科股份 | 28.3% | 高杠杆 |

### 3.3 利润质量维度

#### 标签：高毛利 / 中毛利 / 低毛利

| 标签 | 判定条件 |
|:---|:---|
| 高毛利 | 毛利率 > 40% |
| 中毛利 | 毛利率 15%~40% |
| 低毛利 | 毛利率 < 15% |

**计算公式：** `(营业收入 − 营业成本) ÷ 营业收入 × 100%`

#### 标签：价值创造型 / 价值整合型 / 会计调整型

| 标签 | 判定条件 |
|:---|:---|
| 价值创造型 | 核心利润 / 营业利润 > 80% |
| 价值整合型 | 投资收益 / 营业利润 > 30% |
| 会计调整型 | 营业外收入 / 利润总额 > 20% 或 资产减值损失占比异常 |

**计算公式：**
- 核心利润 = 营业收入 − 营业成本 − 销售费用 − 管理费用
- 核心利润率 = 核心利润 / 营业收入 × 100%
- 核心利润占比 = 核心利润 / 营业利润 × 100%

> 注意：核心利润的完整公式还包括税金及附加。简化版减三项费用。

#### 标签：盈利 / 微利 / 亏损

| 标签 | 判定条件 |
|:---|:---|
| 盈利 | 净利润 > 0 且 净利率 > 5% |
| 微利 | 净利润 > 0 但 净利率 < 5% |
| 亏损 | 净利润 < 0 |

### 3.5 三大匹配检查（张新民框架核心诊断工具）

这一组标签打通三张报表，是张新民"三个匹配"的量化。

#### 匹配①：固定资产 → 营业收入

| 标签 | 判定条件 |
|:---|:---|
| 产能高效 | 营收 / 固定资产 > 3.0 |
| 产能正常 | 营收 / 固定资产 1.0~3.0 |
| 产能低效 | 营收 / 固定资产 < 1.0 |

**计算公式：** `营业收入 ÷ 固定资产`

**案例：** 新易盛 248亿/33.5亿=**7.4**（高效）、中芯国际 673亿/1363亿=**0.49**（低效）

#### 匹配②：营业收入 → 核心利润

| 标签 | 判定条件 |
|:---|:---|
| 强转化 | 核心利润率 > 30% |
| 中转化 | 核心利润率 15%~30% |
| 弱转化 | 核心利润率 5%~15% |
| 极弱转化 | 核心利润率 < 5% |

**计算公式：** `核心利润 ÷ 营业收入 × 100%`，核心利润 = 营收 − 营业成本 − 销售费用 − 管理费用

#### 匹配③：核心利润 → 经营活动现金流

| 标签 | 判定条件 |
|:---|:---|
| 现金实现强 | OCF / 核心利润 > 0.8 |
| 现金实现中 | OCF / 核心利润 0.3~0.8 |
| 现金实现弱 | OCF / 核心利润 < 0.3 |

**计算公式：** `经营活动现金流净额 ÷ 核心利润`

**三个匹配的联动诊断：**

| 匹配组合 | 诊断结论 |
|:---|:---|
| ①②③均强 | 优秀——产能高效、利润转化强、现金实现好 |
| ①弱②强③强 | 重资产行业，但产品有竞争力、回款好 |
| ①强②弱③弱 | 营收大利润薄回款差——增收不增利 |
| ①②③均弱 | 全面恶化——产能闲置、利润稀薄、现金流紧张 |

#### 少数股东权益占比

| 标签 | 判定条件 |
|:---|:---|
| 归母占比高 | 归母净利润 / 净利润 > 90% |
| 归母占比中 | 归母净利润 / 净利润 60%~90% |
| 归母占比低 | 归母净利润 / 净利润 < 60% |

**计算公式：** `归母净利润 ÷ 净利润 × 100%`

---

### 3.6 现金流质量维度

#### 标签：现金奶牛 / 纸面富贵 / 失血状态

这是张新民框架中"日子"的量化。

| 标签 | 判定条件 |
|:---|:---|
| 现金奶牛 | OCF / 净利润 > 0.8 |
| 现金正常 | OCF / 净利润 0.3~0.8 |
| 纸面富贵 | OCF / 净利润 < 0.3 或 OCF < 0 |
| 失血状态 | OCF < 0 且 净利润 < 0 |

**计算公式：** `经营活动现金流净额 ÷ 净利润`

**案例数据：**

| 公司 | OCF/净利 | 标签 |
|:---|:---:|:---:|
| 百济神州 | 9.39x | 现金奶牛（折旧大） |
| 合康新能 | 3.44x | 现金奶牛 |
| 中芯国际 | 2.79x | 现金奶牛（折旧大） |
| 中际旭创 | 0.94x | 现金奶牛 |
| 天孚通信 | 0.93x | 现金奶牛 |
| 新易盛 | 0.81x | 现金奶牛 |
| 博俊科技 | 0.51x | 现金正常 |
| 北方华创 | 0.39x | 纸面富贵 |
| 盛美上海 | 0.17x | 纸面富贵 |
| 寒武纪 | -0.24x | 失血状态 |
| 帝科股份 | -3.32x | 失血状态 |

#### 标签：自由现金流充裕 / 自由现金流为负

**计算公式：** `自由现金流 = 经营活动现金流 − 资本性支出`（资本性支出 → 购建固定资产、无形资产支付的现金）

| 标签 | 判定条件 |
|:---|:---|
| FCF充裕 | 自由现金流 > 0 |
| FCF为负 | 自由现金流 < 0 |

### 3.5 成长性维度

#### 标签：爆发增长 / 稳健增长 / 缓慢增长 / 衰退

| 标签 | 判定条件 |
|:---|:---|
| 爆发增长 | 营收增速 > 50% |
| 高速增长 | 营收增速 25%~50% |
| 稳健增长 | 营收增速 10%~25% |
| 缓慢增长 | 营收增速 0%~10% |
| 衰退 | 营收增速 < 0% |

**计算公式：** `(当期营收 − 上年同期营收) ÷ 上年同期营收 × 100%`

#### 标签：增收增利 / 增收不增利 / 减收减利

| 标签 | 判定条件 |
|:---|:---|
| 增收增利 | 营收增速 > 0 且 净利增速 > 营收增速 |
| 增收平利 | 营收增速 > 0 但 净利增速 < 营收增速 且 净利 > 0 |
| 增收不增利 | 营收增速 > 0 但 净利增速 < 0 |
| 减收减利 | 营收增速 < 0 且 净利增速 < 0 |

**对比案例：**

| 公司 | 营收增速 | 净利增速 | 标签 |
|:---|:---:|:---:|:---:|
| 新易盛 | +187% | +237% | 增收增利 ✅ |
| 博俊科技 | +37% | +38% | 增收增利 ✅ |
| 中际旭创 | +60% | +116% | 增收增利 ✅ |
| 北方华创 | +32% | -5% | 增收不增利 ❌ |
| 帝科股份 | +18% | -158% | 增收不增利 ❌ |

---

### 3.6 风险信号维度

#### 标签：存货风险 / 应收风险 / 商誉风险 / 合同负债风险（反向指标）

| 风险标签 | 判定条件 |
|:---|:---|
| 存货风险 | 存货/营收 > 30% 且营收增速放缓 |
| 应收风险 | 应收账款/营收 > 20% 且应收增速 > 营收增速 |
| 商誉风险 | 商誉/净资产 > 30% |
| 应收+存货双高 | (应收+存货)/总资产 > 40% |
| 合同负债下降 | 合同负债同比降幅 > 20%（预示订单减少） |

> **合同负债下降是重要的预警信号**——尤其对于造船、装备制造等以订单驱动的行业。中国船舶的合同负债如果连续两个季度下降，比毛利率波动更能说明问题。

#### 标签：毛利率下降 / 营收增速放缓

| 风险标签 | 判定条件 |
|:---|:---|
| 毛利率下降 | 毛利率连续2年下降且累计降幅 > 3个百分点 |
| 营收增速放缓 | 营收增速连续2年下降 |
| 负债率上升 | 有息负债率连续2年上升且累计升幅 > 5个百分点 |

#### 标签：短债长投

**判定条件：** 短期借款 > 货币资金 且 固定资产+在建工程/总资产 > 30%

说明企业用短期借款支撑长期投资，期限错配风险。

## 四、综合评级

### 4.1 五级综合评级

| 综合评级 | 典型特征组合 | 参考标准 |
|:---|:---|:---|
| **优秀** | 造血型 + 低杠杆 + 高毛利 + 现金奶牛 + 增收增利 | 六维中4维以上优秀 |
| **良好** | 造血型 + 中杠杆 + 中高毛利 + 现金正常 + 增收增利 | 六维中3维以上良好 |
| **中等** | 均衡型 + 中杠杆 + 中毛利 + OCF正常 | 无明显劣项也无明显优项 |
| **中下** | 输血型 + 高杠杆 + 低毛利 + 纸面富贵 | 有2个以上风险信号 |
| **差** | 输血型 + 高杠杆 + 亏损 + 失血状态 | 高风险信号集中 |

### 4.2 典型模式标签

基于多个标签的组合，可以给出一句话的"模式总结"：

| 典型模式 | 特征组合 | 案例 |
|:---|:---|:---|
| 轻资产高毛利现金奶牛 | 轻资产 + 高毛利 + OCF/净利>0.8 | 艾力斯、新易盛 |
| 重资产周期弹性 | 重资产 + 中低毛利 + OCF/净利<0.6 | 中芯国际、金石资源 |
| 薄利高周转 | 轻资产 + 低毛利 + OCF/净利>1.0 | 香农芯创 |
| 增收不增利 | 营收增速>10% + 净利增速<0 | 北方华创、帝科股份 |
| 现金牛 | OCF/净利>1.5 + 低负债 | 百济神州、合康新能 |
| 烧钱扩张 | 输血型 + OCF为负 | 寒武纪 |
| **订单驱动** | **合同负债高 + 营收增长 + 负债率高但风险可控** | 中国船舶 |

## 五、数据库实现

### 5.1 标签表设计

表名使用 `zxm_` 前缀标识张新民（Zhang Xinmin）框架来源。**列名不再加 `zxm_` 前缀**（表名已区分）。

```sql
CREATE TABLE zxm_stock_tags (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    stock_code VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50),
    report_date DATE NOT NULL,
    data_date DATE DEFAULT NULL,
    
    -- 维度一：资产结构
    asset_type VARCHAR(20),
    asset_weight VARCHAR(10),
    cash_status VARCHAR(10),
    inventory_risk VARCHAR(10),
    contract_liab_tag VARCHAR(10),
    
    -- 维度二：资本结构
    hematopoiesis VARCHAR(10),
    hematopoiesis_ratio DECIMAL(8,2),
    leverage VARCHAR(10),
    debt_ratio DECIMAL(8,2),
    
    -- 维度三：利润质量
    margin_level VARCHAR(10),
    core_profit_margin DECIMAL(8,2),
    profit_source VARCHAR(20),
    minority_ratio DECIMAL(8,2),
    profit_status VARCHAR(10),
    
    -- 维度四：三大匹配
    match_fa_rev VARCHAR(10),
    match_fa_rev_ratio DECIMAL(10,2),
    match_rev_profit VARCHAR(10),
    match_rev_profit_ratio DECIMAL(8,2),
    match_profit_ocf VARCHAR(10),
    match_profit_ocf_ratio DECIMAL(8,2),
    
    -- 维度五：现金流
    cashflow_type VARCHAR(20),
    ocf_to_np DECIMAL(8,2),
    fcf_status VARCHAR(10),
    
    -- 维度六：成长性
    growth_rate VARCHAR(10),
    growth_quality VARCHAR(20),
    
    -- 维度七：风险信号
    risk_flags TEXT,
    
    -- 综合评级
    overall_rating VARCHAR(10),
    pattern_label VARCHAR(50),
    framework_version VARCHAR(10) DEFAULT '1.0',
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_stock_date (stock_code, report_date),
    KEY idx_data_date (data_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='张新民战略视角财务分析标签表';
```

### 5.2 标签计算引擎

见 `src/app/zxm_tags.py`，`compute_tags(stock_code)` 函数从数据库获取财报数据，计算所有标签并返回 dict。

运行 `compute_zxm_tags.py` 批量计算全市场并写入 `zxm_stock_tags` 表。

## 八、张新民框架完整性检查：当前标签设计是否够用？

### 8.1 已覆盖的维度

| 张新民核心概念 | 对应标签 | 状态 |
|:---|:---|:---:|
| 资产负债表重构（经营资产vs投资资产） | `资产结构` | ✅ |
| 资产负债表重构（四大动力来源） | `资本结构 → 造血/输血` | ✅ |
| 核心利润 | `利润质量 → 价值创造型` | ✅ |
| 造血vs输血 | `资本结构 → 造血占比` | ✅ |
| 三个匹配（固资→营收、营收→核心利润、核心利润→OCF） | `匹配检查` | ✅ 新增 |
| 面子/日子/底子 | 三表对应 | ✅ 已映射 |
| 合同负债（"好的负债"） | `合同负债高/低` | ✅ 已补充 |
| 现金流量质量 | `现金奶牛/纸面富贵/失血状态` | ✅ |
| 少数股东权益占比 | `利润质量 → 归母净利占比` | ✅ 新增 |
| 利润的三个来源 | `价值创造型/整合型/会计调整型` | ✅ |

### 8.2 覆盖盲区

| 概念 | 缺失原因 | 是否需要补充 |
|:---|:---|:---|
| 商誉和无形资产膨胀 | 已有`商誉风险`标签，但缺"商誉/净资产连续上升"趋势标签 | ⚠️ 建议补充 |
| 研发费用率 | 数据库`fin_extended`表研发费用字段损坏，数据不可靠 | ❌ 数据问题暂不补充 |
| 金融企业不适用性 | 银行保险的资产结构完全不同，框架不适用 | ❌ 需在前端声明 |
| 新经济平台企业 | 如拼多多/抖音，商业模式特殊 | ⚠️ 需单独设计标识 |

### 8.3 综合评价

当前标签体系覆盖了张新民框架的**90%以上核心概念**。主要缺失已在本次修订中补充（三大匹配检查、少数股东权益占比）。对于框架不适用的金融企业和新经济平台企业，建议在前端标注"本标签体系基于实体企业设计"。

**一句话结论：够用。但需在使用中补充两个维度——三大匹配检查和少数股东权益占比。**
