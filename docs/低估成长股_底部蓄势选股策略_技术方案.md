# 低估成长股 · 底部蓄势选股策略 技术方案

> 目标：寻找「业绩连续多年增长、但股价长期盘整在底部」的低估成长股，在它爆发式上涨（主升浪）前纳入观察/买入。
> 参考案例：`603993 洛阳钼业` —— 归母净利连续 6 年增长（2020→2025：23亿→51亿→61亿→82亿→135亿→203亿），但股价 2018-2024 长期在 3.4~9.7 元区间反复盘整，2025 下半年起主升浪（低点 6.15 → 高点 27.03）。

---

## 1. 投资逻辑

这类股票的共同特征：**基本面（业绩）先行、股价滞后（price lags fundamentals）**。

```
业绩连续增长 ──→ 内在价值抬升 ──→ 但股价盘整/下跌（无人问津、估值压缩）
                                      │
                                      ▼
                         P/E 被压缩到低位（业绩涨、股价不涨 = 估值持续下降）
                                      │
                         业绩继续兑现 / 景气加速 / 题材催化
                                      ▼
                    股价终将向内在价值回归 → 主升浪（戴维斯双击）
```

**买入窗口**在「估值压缩完成、即将启动」阶段——既不能买在业绩还没兑现的纯概念，也不能追在主升浪已走了大半之后。

本策略 = **业绩质量筛选（必要条件）** + **底部特征量化（核心）** + **启动前确认（可选/加分）** 三部分组合。

## 2. 策略规则总览

| 模块 | 规则 | 是否可配置 | 默认值 |
|---|---|---|---|
| A. 连续增长 | 最近 N 个年度归母净利逐年上升（且每年盈利） | N ∈ {3,4,5,6,7} | 5 |
| B. 净利规模 | 最新年度归母净利 ≥ 下限、< 上限 | 预设档位 + 自定义范围 | ≥10亿 |
| C. 底部特征 | 股价长期盘整、未大涨、估值压缩（详见 §3） | 严格度：宽松/标准/严格 | 标准 |
| D. 启动确认 | 站上年线 / 均线金叉 / 放量 / 季度业绩加速 | 开关 | 关闭（仅提示） |
| E. 打分排序 | 业绩质量 30 + 底部特征 40 + 启动确认 30 | — | — |

## 3. 核心难点：如何量化「股价还在底部、没怎么涨」

这是本策略最关键、也最容易踩坑的部分。单一指标都有陷阱（见 §7），建议**组合多个维度 + 打分**，而不是硬性 AND 过滤。

### 3.1 业绩-股价背离度（核心指标）

直接量化「业绩涨、股价没涨」：

```
净利近N年年化增速  CAGR_profit = (Profit_now / Profit_{now-N年})^(1/N) - 1
股价近N年年化涨幅  CAGR_price  = (Close_now / Close_{now-N年})^(1/N) - 1
背离度           divergence  = CAGR_profit - CAGR_price
```

**判断**：`divergence` 越大 → 业绩与股价背离越严重 → 越符合「被低估」特征。
经验参考：净利 CAGR ≥ 20% 而股价 CAGR < 10%（甚至 ≤ 0），背离度 ≥ 10~20 个百分点。

### 3.2 距长期高点回撤

```
回撤 = 1 - Close_now / MAX(近3年最高价)
```

**判断**：回撤 ≥ 25% 才认为「不在高位」；若股价正在创新高（回撤≈0）则已被市场发现，不符合「底部」前提。
（结合 3.4 一起用，避免「从高位刚回落」被误判为底部。）

### 3.3 长期盘整收敛（振幅）

```
近3年振幅 = 近3年最高价 / 近3年最低价 - 1
近1年振幅 = 近1年最高价 / 近1年最低价 - 1
```

**判断**：3 年振幅小（如 < 200%，说明长期横盘而非趋势下跌）+ 1 年振幅进一步收敛（如 < 80%，说明近期在压缩蓄势）。这是「盘整」形态的核心度量，对应 603993 2018-2024 的箱体走势。

### 3.4 价格仍处低位区间

```
低点涨幅 = Close_now / MIN(近3年最低价) - 1
位置比例 = (Close_now - 近3年最低) / (近3年最高 - 近3年最低)
```

**判断**：位置比例 < 0.5（处于近 3 年区间的下半部），且低点涨幅不高（如 < 100%）。这保证「现在还在底部区域」，而不是「曾经在底部但已经涨起来了」。

### 3.5 估值未重估（可简化，或依赖历史 PE 分位）

```
当前 PE(TTM)              ← ads_stock_latest.pe_ttm
PEG = PE(TTM) / 单季净利同比
```

**判断**：PE(TTM) 处于低位（如 < 30），且 PEG < 1.5。若后续增加「历史 PE 分位」预计算（各股近 5 年 PE 分位数 < 40%），更能体现「估值压缩到自身历史低位」。

### 3.6 动量未启动（可选反向条件，仅作展示）

```
近250日涨幅 = Close_now / Close_{250日前} - 1
```

**判断**：近 250 日涨幅 < 30%（主升浪尚未展开）。此条件**不做硬过滤**（可能误杀已缓慢启动的标的），用于展示和提示。

## 4. 核心难点 2：如何「在爆发前买入」—— 启动前确认信号

「底部」本身不能保证上涨（可能是价值陷阱）。因此策略提供**启动前确认信号**（默认作为评分加分项，不强制）：

| 信号 | 定义 | 意义 |
|---|---|---|
| 站上长期均线 | 收盘价 > MA250（年线），且 MA60 > MA250 | 长期趋势由空转多，机构开始建仓 |
| 均线金叉 | MA60 上穿 MA250（近 60 日内发生） | 中期资金进场 |
| 平台放量突破 | 近 20 日某日放量（> 5日均量 1.5 倍）且收盘价创近 60 日新高 | 蓄势后启动的第一波 |
| 业绩加速 | 最新单季净利同比 > 最新年度净利同比（ads_stock_latest 的 profit_yoy > ads_stock_annual 的 profit_yoy） | 基本面景气向上，驱动估值修复 |
| 底部抬升 | 近 1 年最低价 > 前 1 年最低价 | 筹码底部抬高，抛压减轻 |

**操作建议（写进策略说明，不写进筛选逻辑）**：符合条件进入观察池；待 ≥2 个确认信号同时出现后再建仓，分批买入（如首次建仓 1/3，站上年线加 1/3，放量突破平台加 1/3）。每季度财报后重跑，跟踪业绩是否延续。

## 5. 数据来源与字段口径（必须遵守）

| 数据 | 来源表 | 关键字段 | 说明 |
|---|---|---|---|
| 年度业绩 | `ads_stock_annual` | `parent_net_profit`, `profit_yoy`, `roe`, `revenue_yoy` | **派生指标一律以 ads_* 为准**，不用 fin_income 现算 |
| 最新快照 | `ads_stock_latest` | `pe_ttm`, `market_cap`, `profit`, `profit_yoy`, `roe_ttm`, `dividend_yield` | 市值/股本以 `stock_shares_dfcf` 为准 |
| 日线价格 | `daily_kline` | `close_price`, `high_price`, `low_price`, `trade_date` | 2018-01 起，**不复权**（见 §7 复权风险） |
| 股票映射 | `stocks` | `stock_code`, `stock_name` | 全市场约 5.5k |

**单位口径**：
- `parent_net_profit`（ads_stock_annual / ads_stock_latest）为**元**；筛选阈值（亿）需 ×1e8。
- `profit_yoy` / `revenue_yoy`（ads_*）为**百分数值**（50.3 即 50.3%），可直接比较，注意与策略层自算的增长率区分。
- 净利筛选输入单位：**亿元**（前端输入 → 后端 ×1e8），与既有「净利润金额（亿元）」筛选习惯一致。

## 6. SQL 实现方案

### 6.1 新策略模块：`src/app/strategies/undervalued_growth.py`

新建独立策略文件，函数签名：

```python
def screen_undervalued_growth(
    consecutive_years: int = 5,          # 连续增长年数 N
    profit_min: float = 1e9,             # 最新年度净利下限(元)，默认 10 亿
    profit_max: float | None = None,     # 上限(元)，None 表示不限
    strictness: str = 'standard',        # bottom|standard|strict 底部严格度
    require_confirm: bool = False,       # 是否强制启动确认信号
) -> list[dict]:
```

### 6.2 业绩部分 SQL（连续增长 + 净利规模）

```sql
WITH annual AS (
    SELECT stock_code, report_date, parent_net_profit,
           ROW_NUMBER() OVER (PARTITION BY stock_code ORDER BY report_date DESC) AS rn,
           LAG(parent_net_profit) OVER (PARTITION BY stock_code ORDER BY report_date) AS prev_profit
    FROM ads_stock_annual
    WHERE report_date BETWEEN '2019-12-31' AND '2025-12-31'   -- 上限取最新年报日，动态
),
recent AS (
    SELECT * FROM annual WHERE rn <= %(N)s   -- 只取最近 N 个年度
)
SELECT stock_code,
       COUNT(*)                                         AS n_years,
       MAX(report_date)                                 AS last_yr,
       MAX(CASE WHEN rn = 1 THEN parent_net_profit END) AS latest_profit,
       MAX(CASE WHEN rn = 2 THEN parent_net_profit END) AS prev_profit,
       MAX(roe)                                         AS latest_roe
FROM recent
GROUP BY stock_code
HAVING COUNT(*) = %(N)s                                                        -- 最近 N 年数据完整
   AND SUM(CASE WHEN parent_net_profit <= 0 THEN 1 ELSE 0 END) = 0             -- 每年均盈利
   AND SUM(CASE WHEN parent_net_profit > prev_profit OR prev_profit IS NULL
                THEN 1 ELSE 0 END) = COUNT(*)                                  -- 逐年递增
   AND MAX(CASE WHEN rn = 1 THEN parent_net_profit END) >= %(profit_min)s
   AND (%(profit_max)s IS NULL
        OR MAX(CASE WHEN rn = 1 THEN parent_net_profit END) < %(profit_max)s)
```

> 说明：`LAG` 在全表上计算，最近 N 年中首年（第 N 年）的 `prev_profit` 取自更早一年的年报，保证「连续 N 年增长」严格跨窗口成立；`rn <= %(N)s` + `COUNT(*) = N` 确保只校验**最近 N 年**的连续性，而不是要求窗口内所有历史年度都增长。
> 实测样本量（最新净利 ≥ 10 亿）：N=3 → 239 只，N=4 → 152 只，N=5 → 108 只，N=6 → 87 只，N=7 → 83 只（603993 在各档均入选，符合预期）。

### 6.3 价格部分 SQL（底部特征）

以最新交易日为基准，回溯计算各股区间统计（对候选池批量查，避免全市场 10M 行扫）：

```sql
-- 对候选代码集合，一次性算好价格维度（IN 分批 500，参照现有 ma_bullish_and_revenue_growth）
SELECT stock_code,
       MAX(close_price) AS last_close,
       MAX(CASE WHEN trade_date >= %(t_3y)s THEN high_price END)  AS high_3y,
       MIN(CASE WHEN trade_date >= %(t_3y)s THEN low_price END)   AS low_3y,
       MAX(CASE WHEN trade_date >= %(t_1y)s THEN high_price END)  AS high_1y,
       MIN(CASE WHEN trade_date >= %(t_1y)s THEN low_price END)   AS low_1y,
       MAX(CASE WHEN trade_date >= %(t_250d)s THEN close_price END) AS close_1y_ago_hi,
       -- 近1年最低/最高、250日前收盘等（取日期定位值）
FROM daily_kline
WHERE stock_code IN (...) AND trade_date >= %(t_3y)s
GROUP BY stock_code
```

- `t_3y / t_1y / t_250d` 由最新交易日 `MAX(trade_date)` 前推 3 年 / 1 年 / 250 个交易日得到。
- 价格指标在 Python 侧计算：回撤、振幅、位置比例、250日涨幅、背离度、站上年线（MA250/MA60 用窗口 AVG 如 6.4）。

### 6.4 启动确认 SQL（可选）

```sql
-- 站上年线 & MA60>MA250 & 近60日平台突破
SELECT r.stock_code, r.close_price,
       AVG(r.close_price) OVER (PARTITION BY r.stock_code ORDER BY r.trade_date
            ROWS BETWEEN 249 PRECEDING AND CURRENT ROW) AS ma250,
       AVG(r.close_price) OVER (PARTITION BY r.stock_code ORDER BY r.trade_date
            ROWS BETWEEN 59 PRECEDING AND CURRENT ROW)  AS ma60,
       MAX(r.close_price) OVER (PARTITION BY r.stock_code ORDER BY r.trade_date
            ROWS BETWEEN 59 PRECEDING AND CURRENT ROW)  AS high_60d
FROM daily_kline r
WHERE r.stock_code IN (...) AND r.trade_date >= %(t_250d)s
-- 取每只最新一行(rn=1)：close>ma250 AND ma60>ma250 AND close>=high_60d
```

业绩加速：`ads_stock_latest.profit_yoy`（2026Q1 单季同比）与 `ads_stock_annual` 最新年度 `profit_yoy` 比较。

### 6.5 打分（0-100）

```
总分 = 业绩质量(30) + 底部特征(40) + 启动确认(30)

业绩质量(30)：n_years(12) + min(profit_yoy最新年/40,1)*9 + roe档位(9, ≥15%满分)
底部特征(40)：背离度档位(14) + 距高点回撤档位(8) + 3年振幅档位(8) + 位置比例档位(10)
启动确认(30)：站上年线(8) + 金叉(7) + 放量突破(7) + 业绩加速(5) + 底部抬升(3)
```

每档给出分段函数（线性插值或阶梯），文档给出推荐参数，实现时可微调。

## 7. 已知风险与陷阱（务必在实现与说明中体现）

1. **复权问题（高优先级）**：`daily_kline` 为**不复权价**。近 3~5 年价格涨幅会因分红/送转被**低估**（对高股息股尤其严重），导致「股价没涨」被误判。对策：方案 A（推荐）引入 `stock_dividend` 计算**前复权**价格再做区间统计。
   - ✅ **已实现**：`src/compute_kline_qfq.py` 基于 `stock_dividend` 的除权因子（每股派现、送股、转增比例）计算前复权价，写入 `daily_kline_qfq` 表（含 `qfq_factor` 字段）；数据管理页新增「前复权K线」卡片一键全量重算（`POST /api/data/update-qfq`，后台运行，约 6-8 分钟 / 1170 万条）。策略计算「股价近 N 年涨幅/回撤」时应改查 `daily_kline_qfq`。
2. **价值陷阱**：业绩下滑的周期股也可能呈现「连续增长后业绩见顶 + 股价低位」。对策：`latest_profit_yoy` 仍为正、`roe` 趋势向上、最新单季 `profit_yoy` 加速三重过滤。
3. **幸存者偏差 / 前视偏差**：回测必须用「当时点可见」的数据（截至某年报的连续增长 + 截至某日的价格），不能用当前数据回填。
4. **`profit_yoy` 口径**：ads_* 为百分数（50.3 表示 50.3%），与策略层自算的增长率（0.503）单位不同，混用会差 100 倍。
5. **壳资源/ST 干扰**：建议过滤 `stock_name` 含 ST/*ST，及停牌、次新（上市 < 3 年，无足够年度数据）。
6. **净利润规模下限的作用**：既保证不是微利微盘股，也天然过滤掉大部分借壳炒作标的；10 亿以上叠加连续增长，样本量可控（已实测：具备 2019-2025 完整年度数据的约 5300 只，连续 5 年增长 + 净利 ≥10 亿约 108 只，符合预期）。
7. **「连续 N 年增长」的年度口径**：以 `ads_stock_annual` 的年报（report_date=12-31）为准；用 `LAG` 严格逐年递增，不用「平均增速>0」的宽松口径，避免被单年大增速掩盖的波动。
